# 惠惠三造型：Codex美术制作与立绘差分接入规格

**作者2026-11-05确认：会将此前获批准的“惠惠三套服装”设定图与本实装包一并交给Codex，用来制作游戏立绘与差分。**

## 1. 身份参考与前置

1. **必须实际收到、检查并加载作者提供的那张参考图。** 该图是星见AU身份、五官、发型、年龄感、体型和三套服装的唯一主要视觉锚点；本ZIP只附文字Character Bible，**没有**图片本体。
2. 用参考图保持：16岁的自然比例与年龄感、深棕色短发及刘海、红眼睛、开朗但并非幼态的神情。不得生成成年化、幼态化或外貌漂移的另一名人物。
3. 服装设定必须优先遵循图像原样。文字仅作防错核验，**不能覆盖附件实际颜色、细节和剪裁**。
4. 如当前Codex环境不提供合适的绘图／抠图／透明立绘工具，先完成逻辑接入，列出需要作者导入的图片清单，**不得无参考凭文字冒充完成美术**。

## 3. 立绘与差分技术要求

- 输出角色透明背景立绘，按实际Godot VN素材规格统一画布、高度、脚部基线、缩放锚点与遮罩；文件路径和命名应**在检查现有目录后确定**，本文件不虚构。
- 三套主立绘可使用不同但自然的站姿、重心与手势，表现“接待员／学生／普通少女”的身份转换；脸、头身比与角色识别保持稳定。
- **表情差分与其所属服装的主立绘必须精确对齐**，可使用眼睛、眉毛、嘴部及面部局部差分。切换时角色不能跳位、缩放抖动或凭空变成另一张脸。制作“表达不同”所需的差分，不机械复刻先前系列图片的分镜骨架。
- 控制屏幕中立绘的比例：从相识09:00到日间前台可用白色接待服；临近17:00校服仅在M07首见和之后已解锁事件中展示；私服不可随机混入工作日前台。
- M07中的初次校服展示可以用一般换装／进出场立绘呈现；**不需要人物更衣过程的额外CG**。
- 所有图片内容必须保持16岁未成年人正常校园与工作情境，没有裸露、成人向、手术患者装束或医疗操作画面。

## 4. 交付验收

1. 提供每套服装的基础立绘及表情差分文件清单，说明使用哪张用户参考图与哪种生成／编辑方法。
2. 在Godot实际演示至少：前台相识中性→得意、普通怪谈中性→狐疑、M07工作制服→JK切换、五点友好告别、私服基础展示。
3. 核对所有差分的人物身份、五官、头发、头身比例、服装细节，确保不发生AI生成中的角色漂移。
4. 缺失美术资源时应报告“剧情逻辑已接入、立绘待参考图／生产”，不能把图像进度虚报为完成。
