# 惠惠互动触发、服装、随机播放与持久状态 V2

**本文件优先于来源 V1 中的所有随机概率、时段范围、前置变量名与抽取建议。** 以下是行为合同，具体 Godot API / save schema 必须由 Codex 检查仓库后映射。

## 1. 三层内容、两个入口

| 层级 | 内容 | 首选 Hook | 限额 |
| --- | --- | --- | --- |
| 正式相识 | 02 一份短 VN | **阿库娅正式相识后首个周一09:00自动排程；冲突则下个工作日09:00** | 一生一次 |
| Micro-Events | 03 的48普通＋22季节节日条目 | 在岗时每天首次主动交谈；日期和伙伴条件过滤 | 正常每日最多一条 |
| Ambient Barks | 04 的30条轻量对白 | 当天微事件后再次点击，或无合格长事件时 | 可反复，最近5条避重 |
| 五点偶遇 | Micro-Events 的特定下班条目 | 玩家有空且在大厅／前台／医院出口，惠惠实际接近下班 | 首次 JK 一次性；以后低概率／冷却 |

“工作日”以**惠惠实际在岗**为准。默认普通周一至周五；不得盲目在周末、学校假日或请假日生成。**17:00准时离岗**是 Canon，但**09:00上班时刻未锁定**。

### 正式相识的自动排程（2026-11-05 作者确认，最高优先）

1. **解锁条件：** 坂口已**完成**水城阿库娅的正式相识事件。仅有阿库娅已出现、已传闻、人物已注册不算。
2. **首次目标：** 在该完成时刻**之后**的第一个周一09:00。若星期一在09:00前已完成阿库娅相识，可在**当天09:00**触发；若09:00已经过去，则目标为**下一个周一09:00**。星期日完成则接下来的周一09:00。
3. **自动触发：** 在目标时间检查坂口和VN舞台是否空闲，若可用则自动切至一楼前台播放 `02`；**无需点击惠惠，也不应从普通对话池抽选**。如游戏不支持分钟精度，优先挂接已有“工作日09:00／早晨开始”的等效节点，并在实装报告中说明。
4. **冲突顺延：** 如果当日09:00正有手术（包括Advanced Day2）、固定剧情、其他不可中断演出、角色／场景无法切换，**不打断、不抢占、不强迫玩家离开现有事件**。保持 pending；下一次候选是**第二个工作日09:00**（通常星期二），而不是再等一整周。若仍冲突则按工作日逐日顺延；周末和确实不在岗日跳过。**不在当天10:00或晚上补播**。
5. **优先级与存档：** 自动相识优先于惠惠普通Micro，但低于已经进行的手术和固定VN。持久保存阿库娅完成时间、所排定的首个周一、`pending/completed`语义（使用工程真实存档结构）。只有整场播放完毕才标记惠惠已相识。重载不能双播或遗失待执行事件。
6. **相识当天：** 不再投放普通日间长Micro；**当天17:00也先不投放首次JK M07**，让玩家至少过一个工作日再看到她的学生造型；下一个合格离岗机会保证M07。
7. **相识之前：** 惠惠可作为背景接待存在，或在既有联合事件中短暂露脸，但不提供随机交谈、不触发M07、不出现在攻略／医护系统。**不因首次点击触发Intro。**

### 每日顺序

1. 未正式相识：若已到达排程时刻，自动相识调度器处理；玩家点击惠惠**不能**代替定点自动事件，普通随机互动不可用。
2. 已相识且今日尚未播放长微事件，且**不是相识当天**：第一次主动交谈优先选择临近到期的节日／年度里程碑，随后普通季节，最后普通随机事件。
3. 一条长事件完整结束才将当天标记为“已用”；同日再点击只播放短 Bark。
4. 玩家没有来找惠惠：不自动播放、不预先消耗。错过节日不阻塞主线。
5. 第一次互动恰好是离岗瞬间：先检查首次JK或合格五点特殊；播放后占用当天长事件额度。若当天先前已经聊过，允许低概率出现额外一条五点短事件；每次离岗过程最多一条。

## 2. 五点校服事件

- 惠惠在离岗时换成批准的深蓝西装、白衬衣、酒红色领结、百褶裙和书包；换装通过玩家可见旁白体现。
- 第一次遇见她换装且主角空闲时，**保证**播放 M07；完成前不得先出现 R25、M19、M22、M27 或 L17–L20 的 JK 差分。
- M07结束才记录“首次JK已见”，永不重复。友好称赞及一条街的顺路同行不是 Sunday Date：**绝不改变惠惠或坂口的任何好感度、Familiarity、Charm、Clinical Presence、声望、货币或其他数值**。即使复用了可攻略人物的离院同行UI，也须绕过奖励／关系结算处理器。
- 此后五点长事件建议**30%概率**，全局冷却初始为**8个实际在岗工作日**（作者可在体验后调整）。候选 R25、M19、M22、M27；每个下班过程至多一条。
- 若不触发长事件，且玩家在出入口主动交谈，可抽 L17–L20；随后惠惠正常离岗。
- 坂口正在 Surgery Runner / Advanced Day2 / 固定 VN / 其他不可打断事件时，**不触发、不强制中断、不把惠惠留到夜间，也不当天补演**。下一合格工作日再尝试。
- 如果工程只有“白天／傍晚／下班动作”而无分钟级时钟，使用现有“离岗机会”语义，不新建第二套时钟。

## 4. 普通微事件抽取与冷却

- 普通池：M01–M20、R01–R28；其中 M07、M19、R25 为五点槽；M06 因明确提到星期五半价战，只在**星期五临近下班**合格。
- **先按主题组抽、再从组中选版本**，避免“医院怪谈”因为有很多变体而获不合理的多倍概率。
- 优先未见事件；已见事件默认间隔至少**7个实际在岗工作日**；最近两条同主题降低权重。
- 伙伴事件未解锁时不参与抽选，不要求先播完全部70条再循环；新角色解锁后自动进入可用池。
- 候选因冷却太少时逐步放宽，但仍优先避开昨天和同主题连播。
- 全部互动不消耗医疗行动单位、不奖励医疗数值／关系数值／金钱。

## 5. Ambient Barks（30条）

- L01–L16 在岗日间普适，**但L08明确是下午两点至三点困意**，应在下午语义时段出现；没有上午/下午判断能力时先排除L08，不能上午照播。L17–L20 只在首次JK（M07）完成后的离岗机会出现。L21–L30 依月份／季节过滤；**L25明确说“下午三点”**，也须在下午语义时段出现。
- 季节映射：L21春4—5月、L22梅雨6月、L23盛夏7月、L24晚夏8月、L25初秋9月、L26深秋10—11月、L27初冬12月上旬、L28隆冬12月下旬—1月、L29晚冬2月、L30学年末3月。
- 不保存永久 consumed；从合格短对白中避开最近5条；当季文本可获约两倍权重。
- 一拍 UI 只播放惠惠主台词；两拍 UI 还播放原稿指定的坂口回应。没有新角色入场、地图转换和状态奖励。

## 7. 保存语义

以下是需要持久化的含义，**不是要求原样建立的新字段名**：

- 阿库娅正式相识的完成时间、惠惠自动相识的首周一目标、待执行／完成语义；惠惠正式相识完成；首次JK事件完成；
- 最近一次日间长事件所在的游戏日；事件ID已见／上次播放日；
- 每个游戏年份的节日组播放记录；
- 最近一次五点长事件的实际工作日序号；
- 最近5条短对白历史（保存可选，但存档恢复时应避免连重）；
- VN中途恢复的已有工程机制，不能重复结算。

任何交互都不能启用惠惠的 Relationship、Familiarity、Date、Free H、H、Staff-as-Patient、患者池、Surgery Runner、医护队伍或技能奖励。

## 8. 行为伪代码（非 Godot API）

~~~
每天09:00检查惠惠自动相识排程：
  阿库娅正式相识完成 且 未排首周一 -> 计算相识完成之后首个周一09:00
  今日是目标首周一 或 顺延工作日，且相识尚未完成：
    若坂口/场景被更高优先级事件占用 -> 保留pending，安排下个在岗工作日09:00；return
    否则 -> 自动播放Intro；结束才写已相识；占用今日长事件额度；return

玩家主动点击惠惠：
  惠惠今日已离岗 -> 当前地点不提供她的前台交互
  否则若正式相识未完成 -> 不提供Micro/Bark；return
  否则若当前为离岗机会、玩家空闲：
    若今天刚完成Intro -> 惠惠正常去夜校，不播M07；return
    首次JK未见 -> 播放 M07；完成后记录并占用今日长事件；return
    五点长事件冷却已过 且 概率命中 -> 从当前可用五点池选择一条；return
    今日微事件已消费 -> 播放 L17–L20 中一条；return
  否则若今日微事件未消费：
    先选合格的到期节日／年度里程碑，再选普通季节或普通事件
    完整播放后提交当日消耗与年度组记录；return
  否则 -> 从当前合格Barks中选一条最近5条之外的；return

时间推进至17:00：
  惠惠正常离岗，与玩家是否来前台无关。
  不自动弹出剧本、不干扰手术、不将五点事件硬排到深夜。
~~~

没有日／月日系统时，先复用项目已有时间与季节状态；如果无法准确提供节日日期，Codex须报告采用的等价窗口或向作者提出明确问题，不自行创造平行世界日历。
