# 氷上冴子 — 医护接入与 Lv0 实装交付说明（V1）

## 交付定位

此包是**可交给 Codex 映射工程的内容包**，不是已经通过代码校验的 `data/staff` 运行时 Bundle。

四个文件：

1. `HOSHIMI_HIKAMI_SAEKO_STAFF_PROFILE_AUTHORING_V1.json`：24岁、六项能力、岗位可用性、初始关系、登场时间和后续设计 Gate。
2. `HOSHIMI_HIKAMI_SAEKO_DIALOGUE_AUTHORING_V1.json`：完整中英日常工作台词、编队及术后回应、8种危机×2严重度×3次尝试、个人护士、4个生活地点、下班同行、术前说明4句。
3. `HOSHIMI_HIKAMI_SAEKO_LV0_CODEX_READY_V1.md`：正式相识事件《请不要说以后》的分段执行稿。
4. 此说明文件。

## Codex 实施任务

- 从既有护士的可运行数据及 `staff_minimal_requirements(3).md` 映射真实字段；不要把作者 JSON 中的说明文字当作运行时字段，也不要猜测 `actor_id`、enum、对话索引和资源名。
- 她的自然部门是内科，但普通护士可用于病房、器械护士、巡回护士及个人护士。默认工作地点以护士站为主，病房、休息室、天台按现有常规随机地点规则。不要为「潜入调查」增加独立职业、角色限制或专业能力惩罚。
- 日常护理语料为中英对照，包含八类完整危机报告，共48条。对照现行护理危机分型注册；注意 `generic_instability` 不是失血报告，不自行新增 `blood_loss` 危机类型。
- 术前说明为 `open/insert_a/insert_b/close` 四段；个人护士的各诊断结果、术后、交班、编队、院内闲聊及下班同行都应按已有相邻角色格式实现，不能只接入 `profile` 而忽略对白。
- Lv0 **游戏开局满六个日历月后**才触发：最早第七个月在护士站的安全剧情时段。确切年月日运算与 event queue 参考工程已存在的相识触发器。当天错过需要待触发，不会永久失联。
- Lv0初始 `met=false, level=0, familiarity=0`。**播放完全部台词才 `met=true`**，解锁基本交流和医护编队；不自动升Lv1、不奖励好感度或声望、不揭露委托人。
- Lv1–Lv5 观察类 Gate 是用户认可的方向，但未写正式事件、未查证计数接口，不要创建空事件自动通过，也不能降低后期高门槛。未实装的公开教学／四处H应保留为未来开发依赖。
- ×1.2 熟悉度倍率的乘法先后及取整方式请从游戏现有系统推导，无法确认时回报，而不是定一个新的 rounding rule。
- 全部 VN 事件中禁用中途存档，结束后按既有规则恢复。
- 立绘身份与画风须以用户最初上传的原作人物参考图为准；目前资产路径待查，本文不宣称任何图已经制作或挂载。

## QA 验收清单

1. 六项数值在0–100区间，年龄是明确整数24，倍率为数值1.2。
2. 所有工作状态、个人护士、术前4句、岗位分配／术后、休息室／天台／病房／护士站、下班同行内容都有可用中英语言条目。
3. 八个危机种类全部具有正常／严重，第一次、第二次、第三次的**独立实词**，共48条；与护理工作台词类别正确绑定。
4. Lv0 在游戏未满六个月、尚未相识时不可见；满期能被正常触发；阻塞剧情时可排队；完成后不能再次触发。
5. Lv0每句对白原文、标点、说话人及顺序不变；「坂口：『……』」不是空文本，也不是可删的节奏占位。
6. 弘子排好的是**明天早班**，而不是「立即加入术中」；玩家获得正常护士编队权限是在这场正式相识结束后。
7. 任务末了，Codex报告注册位置、实际actor_id、运行时数据映射、资源缺口和测试结果；不得只返回「已完成」而没有验证依据。
