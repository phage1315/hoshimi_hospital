## 对 Codex 的实施任务

请先审计当前游戏的 doctor/staff schema、内部角色注册、御堂江美子六维能力值、手术医生助手邀请、主刀权限、麻醉模式选项、语言资源以及地图人物排班。完成以下最小工作：

1. 注册或复用已存在的武見妙角色身份，按相同于现有医护的数据结构加载中英文对白；不要新造内部 ID、字段或错误的岗位枚举。
2. 六项建议能力为 **Surgery 94 / Diagnostics 90 / Teamwork 73 / Patient Care 60 / Instrument Handling 93 / Calmness 95**。**这些数值尚待作者确认。** 真正已确认的是 Surgery 与御堂不相上下、Teamwork 略低而不是孤狼、Calmness 和临床判断很强。实际御堂数值不同或与该约束冲突时，列出比对和建议修改，不要无声落库。
3. 武見属于已在医院的医生，但当前尚未与坂口正式认识。**初始保持 `met=false`、Relationship Lv0、Familiarity 0**；不把她提前放进地图交互或手术邀请清单。本批可以准备相识后数据与岗位挂钩，但**不能自动设为可攻略或可编队**。
4. 正式相识（另行制作的 Lv0 完成）之后，开放**医生助手**；明日香禁止她在常规手术中担任**主刀**。这两个资格不可混为一个全局 `surgery_disabled` 开关。此批不提供 Lv0 解锁事件，也不强行改变当前解锁状态。
5. 她作为实际助手上台后，坂口选择**无麻醉**→明显高兴，选择任意有麻醉方式（包括局部、区域、全身）→意兴阑珊。一次选择只作一次反应；危机时依然敏锐、称职。**不得**改动能力值、手术结果、危机判定、声望或关系收益，也不豁免原本的无麻醉声望后果。
6. 地下研究室是未来 Lv0 结束后的主要活动地点；偶尔出现于手术室、休息室、天台。此批可以注册不可见的后续地点候选，**不能**打开地下室入口或实现隐藏→锁定→可入的地图状态转换；该工作保留给 Lv0 定稿。
7. 医生助手的泛用危机台词不能抢占器械护士／巡回护士专属播报。仅按现有医生助手语音入口映射；若没有适当的触发钩子，报告具体缺口。
8. 禁止提前制作 Lv1–Lv5、Staff-as-Patient、七瀬恋 Lv5 特殊双台、Live Surgical Anatomy、个人 H 场所及夜间 H Runner。
