# 一、 30天返场支线总控结构与调度规范

## 1. 剧情定位与解锁门槛（Gate & Calendar Protection）

本支线并非独立攻略线，也不是已出版漫画的终局庆功宴，而是玩家同时将 **深山佳織** 与 **藤崎詩織** 推进至中段关系后解锁的**跨路线群像奖励长线（Cross-Route Bonus Arc）**。此时《星见医院物语》刚处于构思与实地摸底阶段。

```yaml
event_arc_id: ayako_return_hoshimi_manga
title: 星见医院物语
arc_type: cross_route_bonus_residency

unlock_requirements:
  - miyama_02_manga_artist_wrong_patient_completed == true   # 对应彩子 Bible 中的 ayako_wrong_surgery_completed，Codex 统一读取工程现有深山 Lv2 完成标记
  - ayako_shiori_reconnected == true                         # 彩子与藤崎已在深山 Lv2 重逢
  - relationship_doc_rei >= 3                                # 深山佳織 Relationship ≥ Lv3
  - relationship_shiori >= 3                                 # 藤崎詩織 Relationship ≥ Lv3
  - days_since_wrong_surgery >= 180                          # 距深山 Lv2 事故至少满 180 天（下半年）
  - current_date <= Month_11_Day_01                          # 最晚触发截止日：2月1日（含当日）
  - special_event_in_progress == false
```

### 关键日历与剩余天数保护规则
- **最晚触发保护（2月1日截止）**：游戏主流程于 3月31日结束（3月30–31日为终章叙事日）。为确保 30 天取材驻留有充足时间完整走完，**本支线的回访开场事件最晚于 Month 11 首日（2月1日，含当日）触发**。若玩家在 2月2日及以后才凑齐双 Lv3 或满 180 天条件，本周目不再开启本支线。
- **驻留期跨月延续**：只要回访开场在 **2月1日及以前** 成功触发，后续的 4 个固定周事件、随机短互动及离院事件均正常推进至完成，不受 2月1日开场截止锁拦截（距 3月29日尚有近 60 天缓冲空间，足以吸收任何日程顺延）。

## 2. 日程消耗、触发时段与「入列保留」顺延契约（重要工程规范）

- **体量与不吞排班原则**：本支线包含的所有节点（回访开场、4 个每周固定剧情、满月离院事件、10 个随机短偶遇）均为 **15–30 分钟游戏内体量的短事件**，**绝不消耗整日排班**，不影响玩家当日的常规手术、门诊或周日约会。
- **优先触发时段分配**：
  1. **早间开场（`09:00`）或下班时段（`17:00–18:00`）优先**：回访开场、Week 2 角色草图抓包、Week 3 旧友叙旧、Week 4 分镜展示及离院归还制服，统一优先排在 `09:00` 或 `17:00–18:00`，最大程度避免切割玩家日间工作流。
  2. **日间工作时段（`12:00–16:00`）**：仅分配给需要医院日间真实运转氛围的事件（如 Week 1《真正的护士工作》跟随护士巡视交接，以及部分日间走廊／诊室外随机偶遇）。
- **固定周事件的「入列保留（Sticky Queue）」顺延契约**：
  - 四个固定周事件（Week 1–4）与离院事件在代码中**严禁写成过期的闭区间判断**（例如严禁写成“仅当 `6 <= residency_day <= 8` 时才允许触发 Week 1”），否则一旦连续三天被手术或主线剧情占用就会导致后续整条支线永久卡死。
  - 正确工程语义为 **`earliest_arm_day`（最早入列日）＋ 前置节点已完成**：
    - `Week 1`：`residency_day >= 6` 时进入待执行队列（`armed`）；
    - `Week 2`：`residency_day >= 13` 且 `Week 1` 已完成时入列；
    - `Week 3`：`residency_day >= 20` 且 `Week 2` 已完成时入列；
    - `Week 4`：`residency_day >= 27` 且 `Week 3` 已完成时入列；
    - `离院事件`：`residency_day >= 30` 且 `Week 4` 已完成时入列。
  - **一旦事件进入待执行队列，即使 `residency_day` 已经超过名义周窗口（甚至因连续顺延超过第 30 天），该事件也必须一直保留在队列中，直至找到空闲对应时段成功播放为止**；同一日最多播放 1 个固定节点，严格按 `开场 → Week 1 → Week 2 → Week 3 → Week 4 → 离院` 顺序依次推进。

## 3. 叙事分寸与跨卷出场角色相识门槛统一规范

1. **彩子的三十天认识递进（避免开场提前剧透结论）**：
   - **Day 1（开场）**：彩子作为成熟职业漫画家，凭直觉判断出编辑提议的“纯靠猎奇手术噱头”撑不起长篇连载，并敏锐预感到星见医院藏着比上次乌龙开腹更丰富的题材，但**此时她尚未确定长篇真正的切入点与核心主题**，速写本仍是待填满的状态。
   - **Week 1–3（驻留观察）**：通过跟班护理日常、描摹怪人医生群像、看见老友藤崎詩織的变化，一点点摸清这座医院的温度。
   - **Week 4（成果落点）**：直到最后一个月尾声拿出第一话分镜时，才自然呈现出“把清晨交班、贩卖机热咖啡与鲜活的人放在奇观手术之前”的最终创作答案。
2. **公共场合恋情保密与路线防剧透**：多人同场的公共剧情中，所有角色均严守职场同事／旧友分寸（包括公共场合统一称呼『坂口医生』，不暴露私密昵称或恋情，不搞争风吃醋修罗场）；仅在 Week 3 彩子离场后的两人独处片刻，为 `relationship_shiori >= 4` 预留轻量含蓄默契差分。不引用藤崎个人线未锁定的具体病例。
3. **全四卷统一的出场角色门槛分级（供 Codex 统一处理极端存档）**：
   - **第一类：支线解锁自带必识角色**（深山佳織、藤崎詩織、城宮明日香、七瀬恋、朝倉美幸）—— 因深山 Lv2 事故及双 Lv3 前置已 100% 覆盖此五人，固定事件与保底随机池无需额外检查 `met`。
   - **第二类：本院常驻核心医护**（御堂江美子、阿尔托莉雅、石神千鹤、水城阿库娅、神宮寺成美、南条小夜香、杉村弘子、本庄萌恵、岩崎留美、米田栞、飯村真奈美）——
     - 在 **固定周事件（Week 1 石神千鹤、Week 2 御堂江美子与阿尔托莉雅）** 中：**不设 `met` 阻塞锁，亦不拆写额外剧情分支**（半年后进度绝大多数存档均已相识；若遇极端未相识存档，作为医院管理层在公共走廊／休息室正常实名露面即可，**不自动改写其个人路线的正式相识 `met` 或 `Lv0` 状态**）。
     - 在 **可选随机短互动池（Vol.4 Ambient 02 / 04 / 05 / 06 / 07 / 08）** 中：因随机池本身为非必看抽取，保留对应角色的 `met == true` 抽取前置——认识谁才抽谁的日常小剧场，极端存档自动由 4 条零门槛保底偶遇承接。
   - **第三类：中后期特殊条件相识角色**（御園芹香、遥凑）—— 在 Week 2 画稿点评中采用 `if met == true` 轻量条件句包裹，未相识时自动跳过对应两句台词。
   - **第四类：明确排除角色** —— **武見妙**（高难隐藏）、**狩谷めぐみ**（12月去向变动）、**氷上冴子**（半年调入且定位打磨中）全程不纳入本支线。

## 【Scene A — 意外消息：条件反射的警惕】

**【场景】** 星见医院·医生休息室（兼病历讨论角，房门半敞）  
**【时间】** 工作日上午 09:00  
**【在场角色】** 坂口隆司、藤崎詩織；随后深山佳織入场；末尾片桐彩子于门外探头登场  
**【服装状态】**  
- 坂口隆司、藤崎詩織、深山佳織：日常医生白大褂（藤崎佩戴素雅发箍，深山内搭急诊刷手服）  
- 片桐彩子：成年漫画家常服（Outfit A：宽松浅紫开衫、白色内搭、高腰长裤、斜挎鼓鼓囊囊的大号帆布画材包）

**【玩家可见正文】**

上午九点刚过，早交班后的走廊渐渐安静下来。

医生休息室里，坂口隆司刚把一份跨科随访记录递还给藤崎詩織，顺手将两杯刚倒好的温红茶放在小圆桌上。

藤崎詩織接过茶杯，端正地合上文件夹，唇边带着一抹温和从容的笑意：

藤崎詩織：「谢谢你，坂口医生。有你刚才补上的那几条术后观察要点，下午跟进起来就省心多了。」

坂口隆司：「举手之劳。看你今天难得没把日程排满，上午没有门诊？」

藤崎詩織：「嗯，特意把九点这一小段空出来了。今天有一位提前约好的客人要来院里办手续——」

话音未落，放在桌面上的智能手机轻轻震动了两下。

藤崎詩織低头点亮屏幕看了一眼，眉眼微弯地抬起头：

藤崎詩織：「真巧，她说已经进一楼大厅、正在上电梯了。」

坂口隆司端起茶杯随口问道：「院外的会诊专家？」

就在这时，抱着一摞急诊留观夹路过门口的深山佳織脚步微微一顿，原本要走过去的身影停在半敞的门边，顺口接了一句：

深山佳織：「九点钟往这边走的访客……该不会是哪家医药代表走错楼层了吧？」

藤崎詩織转过头看向深山，眨了眨眼，语气平静得像在报天气预报：

藤崎詩織：「不是医药代表哦。深山医生和坂口医生应该也都还记得她——是彩子，片桐彩子。」

休息室里的空气，肉眼可见地凝固了一秒。

坂口隆司手里的茶杯停在半空：「……片桐彩子？」

深山佳織原本放松的肩膀瞬间绷直，几乎是条件反射般低头翻开了手里的今日排班表，眉头一下子锁紧了：

深山佳織：「等一下。我今天上午和下午都没有排胃部手术，急诊那边也没有收名叫片桐彩子的患者——她来医院干什么？」

坂口隆司放下茶杯，面色微妙地接道：「距离上次那场事故都过去半年多了吧……她居然还敢踏进星见医院的大门？该不会又在楼下遇到了哪个『超级热心的人』，正准备换身衣服搞什么新型沉浸式取材吧。」

深山佳織眼神一凛，转身就要往门外走：「我现在给四楼护士站打个内线电话，让七瀬把更衣室和手术区走廊看紧一点——绝对不能再让她摸到患者腕带。」

藤崎詩織看着两人如临大敌的架势，忍不住掩唇轻笑出声：

藤崎詩織：「两位先冷静一点啦。彩子今天不是挂号来看病的，也不是偷偷溜进来的——她一周前就已经通过我向院长室递交了正式申请，今天是光明正大来办手续的。」

坂口隆司挑了挑眉：「正式申请？被我们误开了一刀，没把星见医院拉进黑名单就已经够不可思议了，她还申请回来做什么？」

「——当·然·是回来继续画漫画啦！！」

一道元气满满、中气十足的女声突然从半敞的休息室门框边冒了出来。

三人同时转头看去。

只见门边探出一颗扎着标志性银紫色高束发的脑袋。二十五岁的片桐彩子背着一只塞得鼓鼓囊囊的帆布大画包，一双亮晶晶的眼睛弯成月牙，正朝屋里的三人用力挥手：

片桐彩子：「早安呀，詩織！还有坂口医生、深山医生——好久不见！刚才在门外听见你们讨论要不要锁四楼更衣室，我可全都听见了哦！」

深山佳織盯着门口活蹦乱跳的彩子，上下打量了她整整两秒，确认她身上穿的是正常的浅紫色开衫和长裤、脚上也好好穿着运动鞋，这才缓缓吐出一口气：

深山佳織：「……至少今天穿的是你自己的衣服。」

片桐彩子挺起胸膛，笑嘻嘻地迈步走进休息室：「那当然啦！再怎么说我也不会在同一个地方摔倒两次嘛！」

**【选择：久别重逢的第一句招呼】**  
*性质：轻量角色扮演选项；展现半年后重逢的熟稔吐槽感，不影响后续分支。*

- **选项 A：「半年不见，看你这么有精神我就放心了。」**
- **选项 B：「先确认一下，手腕上没戴奇怪的条码腕带吧？」**

---

**【选项 A 回应】**

坂口隆司看着神采奕奕的彩子，不由得失笑：「半年不见，看你这么有精神我就放心了。肚子上的刀口早就彻底恢复了吧？」

片桐彩子拍了拍自己平坦的腰腹，笑得一脸灿烂：「完全恢复啦！连疤痕都淡得差不多了，现在熬夜赶稿连画三十页分镜都不带喘气的！」

---

**【选项 B 回应】**

坂口隆司目光落在她的手腕上，一本正经地确认道：「欢迎回来，片桐小姐。不过保险起见先确认一下——今天手腕上没戴什么来历不明的条码腕带吧？」

片桐彩子「噗哧」一声笑了出来，大方地撸起两边袖口转了一圈：「干干净净！只有一块手表和一根扎头发的皮筋，两位大医生尽管放心检查！」

## 【Scene B — 她这次为什么回来：《星见医院物语（暂定）》】

**【场景】** 星见医院·医生休息室  
**【时间】** 紧接上一幕  
**【在场角色】** 片桐彩子、坂口隆司、深山佳織、藤崎詩織  
**【服装状态】** 同上一幕。桌面摊开一本少女漫画月刊样刊与一本崭新的硬壳速写本。

**【玩家可见正文】**

寒暄过后，片桐彩子把肩上沉甸甸的帆布包放到圆桌旁，「哗啦」一声拉开拉链，献宝似的先掏出了一本印刷精美的少女漫画杂志样刊，推到了三人面前。

片桐彩子：「锵锵——！上次出院以后，我把住院那几天的手术台视角和恢复体验融进了一个架空医院短篇里，上个月刚刊登出来，结果读者问卷拿了当期第二名哦！」

坂口隆司有些意外地拿起样刊：「哦？恭喜啊。我还担心你会把『采风漫画家惨遭乌龙开腹』画成纪实揭黑连载呢。」

片桐彩子连忙摆手：「怎么可能那么画嘛！真把误抓患者画出来，不仅编辑部法务要头疼，詩織和你们也会很困扰吧？我画的是正统少女漫画短篇——女主角是因为突发急腹症被推进手术室的普通女孩！」

站在旁边的深山佳織原本松了一口气，顺手探头往坂口翻开的那一页扫了一眼。

下一秒，深山佳織的表情彻底冻住了。

只见跨页分镜的正中央，画着一盏巨大的手术室无影灯。灯下站着一位戴着外科口罩、眼神冷若冰霜的黑发年轻女医，手里稳稳捏着一把闪闪发亮的手术刀，头顶的对话框里一字不差地印着一行冷酷台词——

> **『现在慌没有医疗价值。』**

而在那格旁边，还站着一位眉目沉稳的年轻男助手，正用极其平静的口吻对台上的女主角补刀：

> **『先把你安全缝回去。』**

坂口隆司沉默了两秒：「……这句台词怎么看着这么眼熟。」

深山佳織额角微不可察地跳了一下，伸出修长的手指按住杂志页面，冷冷抬眼看向彩子：

深山佳織：「片桐小姐。你管这个叫『完全架空』？」

片桐彩子双手合十，笑眯眯地试图蒙混过关：「哎呀，细节修饰、艺术加工啦！而且深山医生你不知道，读者来信里人气最高的就是这位『面无表情拿刀的冰山女医』哦！好几个读者写信来说『这种天塌下来都不眨一下的酷姐医生简直帅呆了』呢！」

藤崎詩織端着红茶在旁边忍俊不禁：「我拿到样刊的时候也吓了一跳呢。虽然没有点名道姓，但认识深山医生的人只要看一眼那个握刀的眼神，大概三秒钟就能认出来。」

深山佳織把视线移开半寸，轻哼了一声：「……我当时只是在陈述基本的临床常识，没打算给你提供少女漫画耍帅台词。」

片桐彩子嘿嘿一笑，收起样刊，紧接着又从包里抱出一本足有三指厚、侧边刚贴上几张空白彩色索引贴的硬壳速写本，「啪」地按在了桌面上。

片桐彩子：「不过呢，杂志编辑看这个短篇反响好，问我要不要干脆趁热打铁，把它扩写成一部正式的长篇医院连载——最好每话都来一台稀奇古怪的离谱大手术！」

坂口隆司挑眉看向她：「听起来很符合杂志社的商业套路。你答应这么画了？」

片桐彩子摇了摇头，手指轻轻点着速写本封面，露出了职业创作者特有的敏锐神情：

片桐彩子：「我回去试着列了两页大纲就停笔啦。光靠猎奇手术噱头的话，画个两三话读者新鲜感一过就腻了，根本撑不起真正的长篇连载，我自己也画不过瘾嘛。」

她哗啦翻开速写本——里面绝大多数纸页还是崭新的空白，唯独扉页正中央，用醒目的紫色马克笔大大方方写着一行暂定企划名：

> **《星见医院物语（暂定）》**

片桐彩子双手撑着桌沿，眼睛亮晶晶地环视三人：

片桐彩子：「至于真正的长篇到底该拿什么当主轴……老实说，我现在也还在摸索呢！毕竟上次来星见医院，我前半程在手术台上睡得迷迷糊糊，后半程又只能老老实实躺在病床上养刀口，连住院部走廊都没走完半圈。」

她指了指扉页下方寥寥几笔勾出来的初期印象涂鸦，语气越说越兴奋：

片桐彩子：「可光是住院那几天隔着病房门听见的动静、还有你们几位轮流来查房时的样子，我的漫画家直觉就一直在疯狂报警——这家医院里绝对还藏着好多我没来得及看到的宝藏题材！所以与其关在画室里凭空瞎编，我干脆向编辑部申请了一个月的实地取材期，先跑回来从头到尾看个明白！」

深山佳織低头瞥见扉页角落里仅有的几个火柴人初期印象图，眉头又是一皱：「……等一下。就算只是初期印象备忘，为什么代表我的这个小人，脑袋顶上要画三块冰碴？」

片桐彩子理直气壮：「那是上次住院留下的第一印象符号嘛！你看旁边坂口医生的小人，我还专门标了『看起来像正常人，但吐槽意外很毒』的待核实备注呢——说不定观察一个月以后还会再升级哦！」

坂口隆司：「……谢谢你的高评价，这句备注其实完全不必升级。」

藤崎詩織笑着看了一眼腕表，温和地提醒老同学：「好了彩子，再把扉页翻下去，深山医生怕是第一天就要把你的新速写本没收了。跟明日香院长约好的时间快到了，我们先去院长室办正式手续吧？」

片桐彩子猛地一拍脑门：「啊，对对对！今天最重要的任务是去领城宮院长的正式许可！」

深山佳織把怀里的急诊文件夹往桌上整齐一放，干脆利落地站起身：

深山佳織：「我也一起去。」

片桐彩子眨了眨眼：「诶？深山医生不忙吗？」

深山佳織面无表情地拉开门：「从这里走到院长室要经过两道楼梯口和一部直通四楼手术区的电梯。在亲眼看着你办完正规访客手续之前，我不放心让你一个人在走廊里自由活动。」

坂口隆司也笑着站起身：「既然这样，我也一起去见证一下吧。」

## 【Scene C — 院长办公室：三十天取材许可】

**【场景】** 星见医院·院长办公室  
**【时间】** 上午 09:15  
**【在场角色】** 城宮明日香、片桐彩子、坂口隆司、深山佳織、藤崎詩織  
**【服装状态】** 明日香着整洁干练的院长白大褂／职业装，其余四人同上一幕。

**【玩家可见正文】**

院长办公室里阳光充足。

二十三岁的年轻院长城宮明日香坐在宽大的办公桌后，手里正拿着彩子提前寄来的那份《长期漫画取材企划申请书》，神情专注地翻完最后一页，随后抬起头，看向整整齐齐站在桌前的四个人。

城宮明日香：「欢迎再次光临星见医院，片桐小姐。看来深山医生和坂口医生今天护送得非常严密，一路上没有再遇到什么来历不明的『热心指路人』吧？」

片桐彩子不好意思地吐了下舌头：「哈哈……上次真的给城宮院长添了天大的麻烦！所以这次我可是老老实实提前一周走正规流程申请的！」

城宮明日香唇角微扬，拿起桌上的院长印章，干脆利落地在申请表底部盖下红印：

城宮明日香：「企划书我看过了，很有趣。即日起，我正式批准你在星见医院进行为期三十天的驻留取材。」

她将盖好章的许可单推到桌前，竖起三根纤细的手指，用简练清晰、带着几分城宮式冷幽默的口吻交代规矩：

城宮明日香：「规矩很简单，只记三条就好。第一，只准进入许可单划定的公共区域与指定临床观察区，旁观工作或访谈医护前必须征得当事人同意；第二，所有涉及患者的素材必须彻底匿名化，没有院方和患者本人的双重许可，不准直接打扰患者；第三——也是最重要的一条，严禁触碰任何医疗设备、严禁实施任何医疗行为，更不准让任何人误以为你是真正的医护人员。」

片桐彩子立刻挺直腰板，右手举到耳边，神色认真得像在宣誓：

片桐彩子：「我保证遵守！这一次我绝对、绝对不会再脱光衣服穿患者袍，也绝对不会再光着脚混进四楼手术室躺上手术台了！」

旁边的深山佳織淡淡补了一句：「还有，陌生人递过来的患者腕带也不准往手腕上套。」

片桐彩子用力点头：「绝对不套！！」

城宮明日香满意地弯起眼睛，合上文件夹站起身，走到办公桌侧后方的衣柜前：

城宮明日香：「很有精神。不过，医院毕竟不是旅游景点——如果让你每天穿着便服、背着这么大的画包在病房和诊室走廊里转来转去，住院患者看到陌生人一直盯着周围写写画画，难免会觉得不安。」

说着，明日香从衣柜里捧出一只早已准备好的白色长方礼盒，放到会客茶几上轻轻打开。

盒子里整整齐齐叠放着一套剪裁合体、浆洗得挺括洁白的**星见医院传统连衣裙式护士制服**，最上面还端端正正摆着一顶同色系的**传统白色护士帽**与一双白色护士软底鞋。

片桐彩子眼睛「唰」地一下亮了起来：「哇啊——！！这是星见医院的护士制服？！连护士帽都有？！」

城宮明日香提起制服领口展示了一下腰部流畅的剪裁线条，语气里透出几分藏不住的自家制服审美自豪感：

城宮明日香：「尺码是我拜托藤崎医生按你的身高估算的。换上这套本院制服，你在走廊里做记录的时候就不会显得突兀刺眼了——去隔壁的小更衣间试试看合不合身吧？」

片桐彩子激动得一把抱起制服盒子，脸上再次露出了半年前那种中了头奖般的灿烂表情：

片桐彩子：「Lucky——！！城宮院长太懂我了！我这就去换！！」

坂口隆司看着她一溜烟钻进附属更衣间的背影，忍不住小声对明日香说道：「城宮院长……你刚才第三条规矩不是才刚说『不准让任何人误以为她是真正的医护人员』吗？直接给她发全套护士服和护士帽真的没问题？」

城宮明日香神秘地眨了眨眼，从办公桌抽屉里慢条斯理地摸出了另一件东西背在身后，笑而不语：

城宮明日香：「放心吧，坂口医生。防误认的保险措施，我已经做好万全准备了。」
