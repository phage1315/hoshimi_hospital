# 术中准备互动 v1

麻醉方案确定后、正式索取手术刀前，所有术式共用四个准备节点：

1. **体位摆放与固定**：保护肩、肘、髋和足跟等受压点，将四肢调整到术式需要的角度并使用安全固定带。
2. **留置导尿**：保护隐私并按无菌原则置管，用于长时间手术中的膀胱引流和尿量监测。
3. **术野消毒**：复核切入部位，从切口中心向外涂布消毒液并等待干燥。
4. **切口划线**：依据术前定位和解剖标志，用无菌皮肤标记笔复核切口走向。

每项实际操作和患者回应各占一个页面。回应页面只有继续按钮，进入下一项操作时会清空上一段对白，避免患者反应与下一项手术选项混在一起。

## 麻醉状态

- **全身麻醉**：没有患者台词，显示客观操作记录和“无意识反应”的说明。
- **局部麻醉、硬膜外麻醉**：患者轻度害怕或不安，但继续配合。
- **无麻醉**：患者在每项准备中明确抗拒。首次选择无麻醉仍保留一次重新选择麻醉的机会；坚持后才进入四项准备。

四项准备仅改变演出与耗时，不改变手术结果、数值或分支。无麻醉分支把“坚持不麻醉”与准备后的“开始手术”拆成两个动作，确保流程顺序为：确认决定 → 四项准备 → 命令开始手术 → 器械传递。

## 性格对白

每名患者在 `reaction_variants` 中提供八组对白：四项操作分别包含 `_awake` 与 `_none` 两种状态，每组 2–3 个变体。运行时按患者、反应节点和事件序号稳定选取变体，因此存档重放不会随机换句。

当前四名患者共配置 64 条准备对白，保持各自说话方式：

- 音羽響子偏向询问依据、步骤和正常感觉。
- 二ノ宮紗智子更犹豫，也更在意暴露和隐私。
- 高卷杏表达直接，压力下更容易显出急躁和抗拒。
- 奥寺美纪语气克制、正式，倾向要求确认后继续配合。

后续 CG 可直接挂在四个操作 action id 上：`operative_positioning`、`urinary_catheterization`、`skin_disinfection`、`incision_marking`。
