# Staff-as-Patient / Lv5 交付清单

现行核验：2026-11-01。新增可作为患者的医护、开放其 Lv5 患者资格时，须逐项检查；不能仅凭剧情或普通患者素材齐全就宣称全部完成。

## 作者与数据交付

- 明确角色 ID、患者资格前置、关系／称呼上下文、允许术式和首次术后 callback。沿用当前患者注册接口，不复制普通诊疗流程。
- 提供患者专属正文与反应覆盖，标清说话人、顺序、首次／重复条件；提供英文或授权忠实翻译。不得自行补写缺失正文。
- 病房、准备、手术台头像、全麻过场等普通患者资源按实际 profile 引用逐项检查。Staff-as-Patient 不进入普通检查流程，不因此强制增加检查立绘。
- 用户指定的 NSFW CG 按明确映射导入；可选 CG 与必需资源分开登记，不用占位图冒充已完成。

## 必交的四种全麻手术台图

| 映射键 | 用途与构图 | 当前状态 |
|---|---|---|
| `abdominal` | 仰卧腹部手术；铺巾后露出腹部窗口 | 小夜香、芹香已完成 |
| `chest` | 仰卧胸部手术；参照用户 SFW 覆盖，胸部覆盖，仅露中央胸骨区域 | 小夜香、芹香已完成 |
| `lateral` | 侧卧位胸部手术；露侧胸术区，其余身体覆盖 | 小夜香、芹香已完成 |
| `prone` | 俯卧位露背；头部有支撑，其他区域覆盖 | 两人已完成，未来术式储备 |

统一要求：独立 PNG 横图、人物辨识度与既有立绘一致、闭眼全麻表现、手术帽与呼吸设备、铺巾及明确体位。保持原比例显示，不裁切；建议沿用本批 **1672×941** 或更高的近 16:9 分辨率。这四张可全部采用 SFW 表现。

当前目录：`assets/characters/advanced_staff_patient_v1/<actor_id>/<pose>.png`。
登记表：`data/advanced_surgery/staff_patient/assets.json`（路径、来源、SHA-256）；术式映射：`procedure_poses.json`。新增术式必须显式指定体位，不能拿另一角色或错误体位图片兜底。
