# 标题画面改版 · 2026-11-01

依据用户提供的背景、布局示意及本轮修改要求实装。

## 当前实现

- 标题改为“星见医院”，英文为 Hoshimi Hospital；采用用户指定宣传语及忠实英文译文。
- 移除标题页的日期 HUD、旧 01/02/03 阶段说明。“春日序章”放到新游戏后的章节卡，之后进入原有序章。
- 单列四入口：继续游戏、开始新游戏、读取存档、医院导览。继续游戏选择最近保存的有效 JSON 槽位；无存档时禁用并聚焦新游戏。读取失败仍显示原有错误，不绕过存档验证。
- 底部语言、设置、退出；设置支持全屏/窗口及现有对白自动播放速度。
- Debug 构建提供开发者菜单及 F10，保留测试存档生成器和事件测试中心；Release 构建隐藏入口。
- 短版非商业声明始终同时显示中文、英文和日文。首次启动显示完整三语声明，另提供使用声明入口重新查看。
- 首次声明确认版本与全屏偏好保存在 user://title_preferences.cfg；不属于玩家存档。关闭而未确认时，下次启动仍显示。语言与自动播放速度复用现有偏好接口。
- 背景使用用户提供的走廊图，原文件逐字节复制到 assets/backgrounds/title/spring_corridor.png，SHA-256 一致。运行时增加左暗右亮渐变；没有生成或编辑图片。
- 主要实现集中在 godot/ui/title_view.gd；原有序章正文、玩家存档格式及安全边界未修改。
