# 无菌服立绘包 v1

## 用途

本包用于手术室内术前职责确认与术中医护发言。现有五名医护各包含 `neutral`、`focused`、`worried`、`warm` 四种透明背景状态，共 20 张。

运行时使用独立的 `sterile/*` 服装键。原有 `scrubs/*` 刷手服资源继续保留，未来需要区分巡回护士时无需重制旧素材。

## 视觉规则

- 青绿色长袖圆领无菌手术袍，腰部系带，袖口收紧。
- 双手与手腕由白色无菌手套完整覆盖。
- 手术帽完全包住头发，保留口罩。
- 透明 alpha 背景，不带手术室矩形底图。
- 表情和姿势沿用各人物原有差分，以眼神和眉形传达变化。

## 文件布局

`assets/characters/sterile_pack_v1/<角色 ID>/<表情>.png`

角色 ID：`doc_aoi`、`doc_rei`、`nurse_haru`、`nurse_rin`、`nurse_yui`。

## 生成方式

模式：`precise-object-edit`。每张图同时引用对应人物的刷手服差分作为身份、姿势与表情基准，以及用户提供的无菌手术袍修改图作为服装基准。生成提示明确要求长袖、圆领、收紧袖口、腰带、无菌手套、完全包发、保留口罩和透明背景。
