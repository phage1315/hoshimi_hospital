# 卧姿患者对话立绘构图准则

本准则适用于剧情对话和普通医疗流程中的病床、担架车与手术台患者立绘。

- 病床与担架车：默认构图从头部到肩膀／上胸。保留少量枕头、病号服、床缘或覆盖单，用来说明患者处于卧姿；不显示整张床、大面积被单、腿部或脚部。
- 手术台：默认构图从手术帽顶端到颈部和裸肩。无菌单可以完全不入镜；不得为了表现铺巾而缩小面部。
- 同一场景的表情差分必须保持画布、头部尺寸、位置、肩线、枕头和镜头角度一致，只改变表情和极轻微的表情相关姿态。
- 对话立绘以表情可读性为第一目标。全身体位、铺巾范围、术野和可点击热区由独立 CG 或互动图表现。
- 妇科检查椅、触诊和其他需要身体区域交互的画面不受本准则限制，继续使用专用互动素材。

折川皐月 Lv3 的 `preop_patient`、`or_table_awake` 与 `postop_patient` 是首批按本准则制作的运行时素材。
