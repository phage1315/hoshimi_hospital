## 当前优先约束（2026-09-21）

用户要求所有角色使用年轻成年女性形象，不采用年上或中年女性素材。本轮统一游戏年龄20—29岁：神宮寺成美27、深山佳織28、七瀬恋26、中井美佳26、朝倉美幸24、音羽響子22、二ノ宮紗智子25、高卷杏21、奥寺美纪24。二ノ宮紗智子的早期年上候选已弃选，替换为年轻成年女性参考图。今后候选素材也按此筛选；历史来源年龄仍保留事实，不因游戏设定而篡改。

使用来源角色素材时，游戏显示名与来源角色姓名保持一致，方便辨识与追踪授权状态；内部 ID 保持稳定。游戏对白中的第三人称统一使用女性代词“她／她们”。

参考 1990 年代末至 2000 年代初日式 PC VN 的静态背景、人物半身立绘与大幅对话框。当前采用低饱和蓝绿、暖白文本、浅金细边框。画布 1280×800，下方留出对话区。

人物素材与第一批四张医院背景已经接入。背景放在 `assets/backgrounds/v1`，人物以角色 ID / 服装 / 表情组织，实际渲染资源映射放在 visuals 中。尚未制作的地点继续使用原生二维几何背景作为回退。

十三张医院背景已经覆盖标题、序章、医院导览、全部地点和工作日结束转场，并包含医院天台、外科主任办公室与医院夜景。后续背景制作可转向时间与剧情差分，例如黄昏病房、夜间走廊、术后恢复区和雨天窗景。

## 用户指定的手术着装视觉要求

以下为本项目的美术设定，适用于后续生成、编辑和图片验收：

- 年轻女性医护戴手术帽时，头发必须完全收进帽内；不得露出刘海、鬓发、后颈碎发或垂在帽外的长发／马尾。通过脸部、眼睛和眼镜等特征保持人物辨识度，不以露发代替。
- 站在无菌术台旁的医生、助手与护士统一穿长袖圆领无菌手术袍，袖口收紧，并戴覆盖手腕的无菌手套；短袖 V 领服装定义为刷手服，不再用于术台旁职责确认画面。
- 原型阶段的手术团队确认画面全部采用无菌状态，包括巡回护士，以减少岗位切换带来的素材组合复杂度。刷手服素材保留，未来细分巡回护士时可重新启用。
- 患者在手术台上必须戴手术帽。侧发、长发和后发收进帽内，但允许在前额保留整齐、适量的标志性刘海，以维持自然感和人物辨识度；这一例外只适用于患者，不改变医护人员完全收发的要求。身体由无菌单遮盖，同时露出裸露的肩膀和腿；脸部可见。
- 手术服、帽子、口罩和患者铺单状态，在同场景的表情差分中保持一致。

这些要求记录用户期望的画面，不作为所有术式通用的临床着装标准。五名现有医护的无菌服基础图与 focused、worried、warm 差分已经按本次要求制作；后续新增角色也应遵守同一提示词与验收标准。

### 手术台患者镜头
采用从患者上方俯视的仰卧视角。患者与手术台背景透视一致，不使用站立或坐姿构图；表情差分保持镜头和身体位置固定。脸部需要在底部对话框之外清楚可见。

## 非手术场景的护士制服

门诊、病房、采血、影像检查、内镜准备等非无菌场景，护士统一采用日式 VN 风格的纯色短袖连衣护士裙与同色传统护士帽。当前基准色为浅粉色，衣领端正、腰线简洁、裙长及膝；不得替换为刷手服、V 领上衣、裤装、花纹布料或围裙。口罩、检查手套等防护用品按具体操作保留。

医生在这些场景可以穿白大褂；当同一画面同时出现医生与护士时，应通过白大褂和护士裙清楚区分身份。只有手术相关的无菌场景适用前述长袖手术袍规则。
