# 主角身份与称呼规范

主角的既定姓名为“本多繁邦”。VN 对话姓名栏使用全名；同事在正式院内语境中优先称“本多医生”，关系深入后可以依人物性格改用“本多”或其他经过剧情确认的称呼。

旁白采用第三人称，不再用连续的“你”代替主角姓名。为避免对白生硬，人物直接对本多说话时仍可自然使用第二人称；选择按钮继续写成玩家将要说或做的内容，不强行重复姓名。

姓名资料位于 `data/characters/protagonist.json`。`name_origin_hook` 与 `name_origin_revealed_flag` 为未来事件预留：某位女医或护士可以认出这个名字来自三岛由纪夫笔下的人物，事件完成后再写入识别旗标。当前版本只保存钩子，不提前指定触发人物、地点或关系等级。

新增内容应遵循：

- `speaker: "player"` 的姓名栏自动显示“本多繁邦”；
- 医院工作对白称“本多医生”；
- 旁白称“本多”或“本多繁邦”，并使用第三人称句式；
- 角色面对本多说话时可以使用“你”，无需机械地在每句话重复姓名；
- 文档中的“玩家”仍指操作者和系统概念，不替换成角色姓名。
