# 折川皐月 Lv1–Lv3 事件 CG 全节点清单

本文依据当前已实装的三段事件逐场整理。这里的“CG”包括鉴赏主图、同构图差分、短暂过场图、主观镜头和局部插图。清单有意从宽收录；标为可选的节点并不表示必须制作，只表示该节点若有图，会明显改善演出。

## 优先级与标记

- **S｜核心鉴赏 CG**：路线记忆点。建议进入 CG 鉴赏或至少全屏展示。
- **A｜强烈推荐**：显著加强情绪、空间或角色成长；预算允许时应做。
- **B｜可选演出**：普通立绘可以承担，但独立画面会更生动。
- **C｜气氛／局部插图**：短暂切入即可，可使用裁切、景物或手部特写。
- **V｜差分**：不另画完整构图，只替换表情、景深、手势或少量道具。

暴露标记：

- **普通**：日常服、护士服或刷手服。
- **医疗轻度**：病号服、裸肩、背部或覆盖单下的术前患者；无性化处理。
- **医疗敏感**：备皮、脱衣覆盖、区域麻醉体位等；画面应以流程和患者体验为中心。
- **术野**：消毒、铺巾、切口或开放术野；可按项目现有非教学、风格化医疗表现处理。

统一规格建议：横向 16:9、1920×1080 或更高；底部约 25% 避开关键脸部和手部。同一 CG 的差分必须保持人物身体、透视和背景完全一致。

主角镜头准则：尽量不在 CG 中直接画坂口，以免暗示玩家角色的身形、发型、肤色或外表；能由坂口观察的画面优先使用第一人称主观镜头。若剧情必须表现其空间位置，应通过其他角色视线、留白、对白或设备站位表达。
