# 医护人物事件包 v1

第一批可玩内容集中在神宮寺成美与七瀬恋。两人的事件使用同一套数据和运行器，但冲突来源、措辞与关系变化按职业和性格分别创作。

## 神宮寺成美 / 女医生

她温和、克制，带教时不直接给答案，对职业判断要求很高。四章依次为：

1. **冷掉的茶**：从休息室里一个很小的照顾或病例请教开始建立熟悉感。
2. **病历上的空白**：她指出病历记录了检查，却遗漏患者真正担心的事。
3. **没有立即给出的答案**：在天台讨论没有标准答案的医疗决定，她也第一次承认自己曾经出错。
4. **仍然亮着的灯**：第二天起解锁。玩家在工作、私人回忆与照顾她之间选择靠近的方式。

她更重视诚实、观察和独立判断。只用漂亮话回避问题，通常不如坦白不知道或主动补救。

## 七瀬恋 / 女护士

她细心温柔，习惯先照顾别人；一旦涉及患者安全，又会显出不轻易退让的一面。四章依次为：

1. **半份三明治**：她连休息时也留意呼叫铃，玩家可以替班、陪伴或倾听。
2. **交接单上的一行字**：一处模糊交接引发职业冲突，轻视问题会真实损失关系值。
3. **患者说“没关系”**：她从细小动作里察觉患者没有说出口的不安。
4. **摘下口罩以后**：第二天起解锁。坚持保护患者的人，也终于承认自己会疲惫。

她更重视协作、明确交接和对细节的尊重。温柔并不等于没有职业立场。

## 当前玩法与扩展

从医院地点进入人物档案，点击「人物事件」。每章开场有三个选择，随后得到该分支的专属回应并结束。事件消耗30或45分钟；前三章按前置事件顺序解锁，第四章还要求到达第二天。

每个 choice 可改变 trust、affection、respect、familiarity，并写入语义 flags。后续可直接引用这些旗标制作回忆、冲突延续、约会邀请或工作中的特殊回应，无需为每名角色另写运行代码。
