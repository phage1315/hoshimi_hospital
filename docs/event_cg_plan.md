# 首批人物事件 CG 计划

事件普通段落使用立绘差分；CG只放在值得停留的关系画面。建议输出 16:9、无文字、与现有日式VN背景和人物设定一致的插画。角色均为成年年轻女性，服装延续事件定义。

CG必须在镜头语言上明显区别于常规立绘。避免继续使用正面、居中、胸像式“角色看向镜头”的构图；优先采用三分之二侧面、过肩、俯拍、低机位或较宽的双人／环境构图，并让人物与茶杯、病历、门把、护栏、口罩等场景物件发生明确动作。奖励CG应呈现一个只能由该事件产生的瞬间，而不是“带背景的表情差分”。神宮寺成美的首张茶杯CG可暂时保留，后续重绘时应改为侧面窗边或玩家视角递茶后的动作镜头。
