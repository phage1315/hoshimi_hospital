# 医生属性

玩家以五项属性开始游戏：医术 50、伦理 0、魅力 50、威压 0、声望 0。医术、魅力与威压范围为 0–100；伦理与声望范围为 -100～100，0 表示中立或尚未建立评价。属性由关键选择累积，不依赖单独存档字段；读取存档时会从已经保存的事件重新计算，避免状态与选择记录不一致。达到上下限后，具体行为记录仍会继续累计，供事件和结局判定。

| 属性 | 主要来源 | 后续用途 |
|---|---|---|
| 医术 | 正确诊断、成功手术、危机处理 | 高难度术式、专业结局、同事尊敬 |
| 伦理 | 尊重患者、承认错误、拒绝滥用权力 | 患者信任、正派路线、医护支持 |
| 魅力 | 对话、约会、安抚和公开表达 | 说服、关系事件、恋爱路线 |
| 威压 | 恐吓、胁迫、无视反对 | 恐惧服从、黑暗路线、医护介入 |
| 声望 | 医疗结果、公开事件和院内评价 | 职位、资源与结局判定 |

现有错误术式分支包含两种处理：停下并重选不会改变属性；明知不符仍继续会造成伦理 -35、威压 +25、声望 -10，并留下 `wrong_procedure_deliberate`、`morality_cruel_choice` 和 `staff_intervention_pending` 标签。

装病罕见病例中的受压手术选择已经预设伦理 -25、威压 +20，同时改变患者恐惧、信任与尊严。该病例模板尚未接入随机患者运行流程；接入后应通过同一属性入口结算。

后续人物事件可以同时读取数值与行为标签。例如高威压本身不等于邪恶，但“高威压＋低伦理＋受压同意记录”可以触发护士制止、医生质疑、术后对质或暗之手结局。

## 医护介入与服从

未来的违规医疗选择会先触发“医护介入判定”。系统综合医术、声望、威压、与当事医护的关系，以及她本人的伦理、勇气和野心性格。玩家刚进入医院、声望与威压较低时，医生或护士更容易当场呵斥、拒绝执行、暂停手术或向上级报告。随着医术、声望和威压增加，同一句反对意见会逐渐变成谨慎质疑、低声提醒或沉默回避。

高权威不保证所有人服从。正直、勇敢或与患者关系亲近的角色仍可能制止玩家；野心强、依赖玩家、伦理较低或已经成为共犯的角色，可能保持沉默、替玩家寻找借口，甚至公开附和。角色应保存自己的“反对次数、沉默次数、协助越界次数与共犯程度”，使语气变化成为长期关系发展的结果。

建议使用一个不直接展示的权威判定值：`医术×0.30 + 声望×0.25 + 威压×0.30 + 关系影响×0.15`，再与角色的勇气、伦理和当时患者风险比较。低权威时倾向直接制止，中等权威时倾向质疑或要求复核，高权威时倾向沉默；只有角色自身条件允许时才进入附和或共犯路线。
