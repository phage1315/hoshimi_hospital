# 手术通用 CG 包 v1

当前接入用户提供的乳房、胸腔、心脏与腹部手术进行中 CG，原图均为 1672×936 PNG。图片作为不具名手术团队的通用画面，不尝试复现玩家实际选择的助手、器械护士与巡回护士；具体团队仍由术前职责确认立绘、对白和结算记录表达。

图片按部位存放在 `assets/surgeries/generic_v1/` 下。成功执行对应术式后，系统先播放随机 CG，再显示手术结果；若手术跨越工作日结束，则顺序为“手术 CG → 手术结算 → 一天结束”。心脏搭桥术使用独立心脏池，不会误用胸腔池。

## 随机与覆盖规则

同一 CG 池会排除刚播放过的图片，避免连续重复。`data/surgery_cg_pools.json` 中的 `priority` 和 `patient_ids` 已为后续覆盖保留：角色专属或术式专属素材可以使用更高优先级，并限定患者和术式；未命中专属素材时继续回退到当前通用池。

后续部位素材沿用 `assets/surgeries/generic_v1/<region>/<stage>_NN.png` 命名。支持的部位为乳房、心脏、腹腔、盆腔和胸腔；阶段支持开始、进行中、结束和并发状况。

## 腹部池范围

当前开腹术式统一归入腹部手术池，包括消化系统、腹壁、肾脏、腹膜后、膀胱和腹主动脉手术，不再拆分独立的“泌尿/腹膜后手术池”。子宫切除、卵巢囊肿切除、子宫肌瘤剔除和腹会阴联合直肠切除归入未来的盆腔手术池；后续若加入术式专属 CG，再通过更高优先级覆盖通用池。
