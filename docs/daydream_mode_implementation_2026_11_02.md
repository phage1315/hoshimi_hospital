## 数据契约

独立目录 `data/daydreams/index.json` 的 `events` 存放白日梦定义，不注册到正史事件集合。每项包含稳定 `id`、`level`（normal/intense/dark）、双语 `title`／`cast`／`tags`／`unlock_hint`、`gate`、`start` 和 `nodes`。

`gate` 支持 `met` 角色 ID 数组、`levels` 角色等级映射、`events` 已完成事件 ID 数组、`flags` 稳定 flag 数组。条件须对照实际工程，不可直接使用文档示例名。

节点的正文 `text`、`speaker_label`、选项 `label` 必须同时有 `zh_CN`／`en`。选择只允许在本篇节点间跳转或 `@end`；不允许 effects，不调用任何正史结算。图片和声音沿用已有固定 VN 字段；未有素材时不得声称已具备相应演出。
