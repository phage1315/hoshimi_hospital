# 不熟练手术护士通用对白

`data/dialogue/inexperienced_nurse_surgery.json` 为所有职业是护士、且 `surgery_proficiency` 为 `novice` 或 `limited` 的人物提供共用手术对白。它不覆盖医生；不熟练医生继续使用人物资料中的 `team_dialogue` 专属文本。

当前覆盖节点：

- 被指派为器械护士或巡回护士；
- 团队内再次确认器械护士或巡回护士职责；
- 主刀索取手术刀；
- 术中询问器械准备；
- 术中询问监护与记录。

每个节点至少有三个变体。游戏以护士、患者、术式、节点和当前事件进度生成稳定索引，同一场景重绘时不会跳句，不同手术中则可出现其他变体。熟练度为 `trained` 或 `expert` 的护士继续使用术式原有的专业对白。
