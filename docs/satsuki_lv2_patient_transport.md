# 折川皐月 Lv2《陪我去一次》实现记录

事件使用 `satsuki_lv2_patient_transport`，按护士站申请、看护部面谈、Holding 轮转、患者核对、走廊转运、门口急停、解释三十秒流程、进入手术室、正式交接、坂口确认和弘子收尾共十一组场景实现。完整路线包含 174 个短节点，中文与英文逐节点对应，所有节点均满足当前对话框无需滚动的规则。

触发条件为：完成皐月 Lv1、皐月关系恰为 Lv1、熟悉度至少 25、临床气场不高于 0，并且距 Lv1 完成至少三天。事件仍要求皐月、阿尔托莉雅、石神千鹤和杉村弘子已经相识。完成后关系升至 Lv2，增加统一的 Lv2 事件熟悉度，解锁围术期护理轮转，并写入成功转运与 Lv2 完成标记。

Lv2 后皐月进入星期日邀请候选。她当前的 Lv2 接受率为 35%，拒绝不会扣关系或消耗当天；接受率由 `date_profiles.json` 的 `acceptance_chance_by_level` 独立控制。因为尚无皐月常服素材，星期日资料暂以护士服作为视觉占位。
