# 中井美佳（nurse_rin）

中井美佳是 26 岁的资深病房护士，主要负责病房护理、患者交接与围术期支持。她公开给人的印象应始终是成熟、友善、可靠且合群：她会参加聚餐、节日和旅行，会帮助年轻护士，也会真心照顾患者。

她与普通优秀护士的区别在于，她对信息、记录、权限、药品旧制和医院动线具有偶尔过度精确的理解。相关细节必须保持自然并各自具有正常解释。剧情不使用恐怖音乐、邪恶笑容或明确犯罪证据提醒玩家；理想效果是谈话结束以后，玩家才意识到她似乎又多知道了一点。

她擅长识别患者隐藏的信息，因为她自己同样精于控制自己透露什么。她很少说可以核实的假话，而会只回答愿意回答的部分，再自然换题。她的当前善意和职业责任都是真实的，星见医院时间线中不从事违禁药品交易、伤害患者、破坏或勒索。

关系路线围绕“了解现在的她，同时接受无法占有她的过去”展开。Lv5 是最大信任，但过去仍不完整公开；恋爱、成人亲密、Staff-as-Patient 或公开教学手术都不能作为交换坦白的筹码。默认设定让玩家高度怀疑她曾卷入严重旧案，但不给出完整案卷、法律实锤、彻底洗白或最终抓捕。

她与杉村弘子的对照是开放照顾与克制控制；与朝倉美幸的对照是逐渐学会坦白与坚持不解释。两组关系应突出差异，同时保留真实的同事情谊。
