# 医院背景包 v1

第一批四张背景使用内置 ImageGen 生成，统一裁切为 1280×800 PNG，并已接入实际游戏流程。

| 场景 | 文件 | 使用位置 |
|---|---|---|
| 门诊诊室 | `assets/backgrounds/v1/clinic.png` | 门诊地点、接诊流程、门诊工作人员页面 |
| 住院病房 | `assets/backgrounds/v1/ward.png` | 病房地点、探视与术前准备 |
| 更衣／刷手区 | `assets/backgrounds/v1/changing_scrub.png` | 更衣、刷手、进入手术室前 |
| 手术室 | `assets/backgrounds/v1/operating_room.png` | 团队确认、麻醉选择及术中互动 |

视觉规范为低饱和蓝绿色、暖白、柔和春日光线和早期日式 PC VN 背景质感。所有背景无人、无可读文字、无标志和水印；下部降低视觉密度，为对话框预留空间。

医院大厅／导览、走廊、护士站、检查室、影像检验区和职员休息室已经在背景包 v2 中完成。几何占位背景现在只作为资源缺失时的回退方案。
