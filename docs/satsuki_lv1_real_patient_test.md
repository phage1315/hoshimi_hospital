# 折川皐月 Lv1《真人测试》实现记录

事件使用 `satsuki_lv1_real_patient_test`，按护士站、检查室进入、上椅测试、患者 POV、多人站位、“放松”反例、坂口采纳意见、阿库娅评价、二人收尾和走廊内心独白十组镜头实现。对白均拆成无需滚动的短节点，中英文逐节点对应。

触发条件为：`satsuki_lv0_complete`、折川皐月熟悉度至少 10、临床气场不高于 30，并要求皐月和阿库娅已经相识。事件完成后关系升至 Lv1，熟悉度使用 `progression_config.gd` 中统一的关系事件奖励，写入临床信任、患者视角特质和 Lv2 gate 标记。皐月目前没有约会档案，因此 Lv1 后不会进入周日约会候选。

## 分镜与素材

- 护士站开场使用 `nurses_station`。
- 主体流程使用 `gynecology_exam_room`，人物按说话者切换皐月护士服与阿库娅白大褂立绘。
- 患者 POV 节点隐藏人物立绘，只保留检查室背景和“只能看见灯、听见器械”的叙述，避免错误地继续展示站立人物角度。
- 坂口退后、阿库娅站足端、坂口站设备侧方均由独立节点明确交代，不让对白覆盖站位变化。
- 结尾切到 `hallway`，并用“皐月（心声）”区分旁白与内心独白。

剧本建议的 `CG_SATSUKI_LV1_TEST_01` 仍为可选素材缺口。正式图需要：皐月穿护士服、戴黑框眼镜、躺在妇科检查椅上，双腿置于腿托并由医疗覆盖巾妥善遮盖；阿库娅持控制器位于设备侧；坂口保持职业距离并观察设备和站位。现有通用妇科检查图角色、衣着和构图均不符合要求，因此没有作为替代品接入。补图后可在 `s03_frame` 节点增加 `cg_path`，无需改写事件流程。
