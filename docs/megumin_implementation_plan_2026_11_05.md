## 已核实的接口与风险

1. `godot/systems/fixed_calendar.gd` 已提供日期、星期、法定假日、休诊日及普通工作日；日历为 2025-04-01 起的固定一年。直接复用，不另造日历。学校假期和个人请假不能由公共假日表凭空推断。
2. `godot/systems/game_state.gd` 已有 `current_absolute_clock()`、`calendar_date()`、`is_routine_workday()`；`next_day_start_character_event()` 已处理多个固定剧情优先级。惠惠排程需接入该安全调度链，并明确记录冲突顺延，不能仅加一个点击入口。
3. 阿库娅真实 actor 为 `doc_aqua`，正式相识事件为 `aqua_intro_exam_chair`（`data/staff/doc_aqua/events.json`）。应验证完整事件完成事实，不能以人物已注册代替。
4. `begin_after_work_departure()`、`choose_after_work_walk()` 是现有同行链；后者会读取关系等级并增加熟悉度。因此只能复用表现层与资源，不能让惠惠直接进入原候选与结算链。
5. `godot/ui/character_stage.gd` 支持 `event_portraits`。计划复用舞台和 VN session；为非医护 NPC 添加最小身份/立绘查询适配，避免为获取头像而伪注册护士。`npc_megumin` 为拟用 ID，正式实施时再核查所有 actor/资源注册入口。
6. `data/staff/nurse_moe/profile.json` 实际姓名为“本庄 萌惠”、年龄18；包内写“本庄萌恵”。年龄相符，字形存在差异。保留原稿台词，建立技术 actor 映射；如要求玩家显示名称统一，需明确哪份字形为准。
7. M17 的女校保健室“两年”、M10 的旧手术袍收藏尚需逐条核实既有剧情依据；本轮不将其认定为已通过 canon 审计。

## 实施顺序

### 1. 非临床角色与基础展示

建立非临床 NPC 数据与资源映射，默认在职工作日出现在大厅前台，17:00离岗。身份查询与医护队伍、患者池、关系路线保持独立。接待服用于工作；校服必须等待 M07 展示；私服只作预备资源，不随机出现在前台。上班时间尚未锁定，09:00相识排程不等于擅自确定完整班表。

### 2. 自动相识与 M07

在阿库娅相识完成时记录稳定完成日期/时刻，计算之后首周一09:00；周一09:00前完成可排当天。冲突保留待办并顺延下一实际在岗日09:00，不当天补播。完整播放后提交已相识事实；当天不投放普通长事件或M07。次一合格离岗机会保证M07，完成前封锁其他校服内容。

阿库娅可出场与否按原稿双分支选取。任何伙伴都要求正式相识完成、真实可在场且空闲；遥凑若无工作日重叠，M12注册为休眠内容并报告原因。

### 3. 内容池

将原稿解析成可逐句追溯的节点数据，保留说话人、选项、标点与顺序；制作说明不展示给玩家。每日首次主动交谈优先临期节日，再季节，再普通主题组；完整结束才占用当天额度。重复点击选短对白；最近5条避重仅放运行内存，不保存最后对白或重放轨迹。

普通事件优先未见，冷却按实际在岗工作日计；五点事件在M07之后按包内30%及8工作日冷却。节日年度组只提交事件级完成事实。M06限周五临近下班，L08/L25限对应下午窗口。医院祭以真实活动状态驱动，无活动系统时相关条目休眠，不编造日期。

### 4. 存档与零奖励

沿用 `boundary_save.gd` / `save_store.gd` 的安全边界，仅保存必要事件完成、日期、已结算时间、年度组与排程业务事实。包内“VN中途恢复”不采用：项目明确禁止持久化节点、页码、分支路径、待确认演出状态或完整session。相识排程 pending 是未执行业务待办，不是演出续接状态。

各互动结算时间与所有数值增量均为零。离岗事件不能走现有熟悉度奖励函数。读档恢复已结算事实，不重放剧情或重发奖励。旧档若只有阿库娅完成事实而没有完成时刻，无法可靠算首周一时不得猜测；需另定旧档迁移策略。

### 5. 英文与表情

包内只有中文正文且明确禁止私自翻译，工程又要求英文完整覆盖。因此英文为正式交付前置：取得作者英文或明确翻译授权后，覆盖标题、公告、完成提示、章节、节点、选项、说话人标签。中文可按原文准备，不能将未获批准的英文静默补入。

包内建议完整表情共14种：接待服6（职业微笑、欢迎、得意、认真、慌张、狐疑）；校服5（问候、自信、挥别、紧张、沉思）；私服3（自然、开心、思考）。本轮三张是服装基础差分，尚不等于14张完成。后续以各服装基图局部编辑脸部，锁定画布、头部尺寸、眼线和身体位置，避免每次重画整个人导致切换跳动。姿势性动作如挥别另作明示的动作差分。

## 验收门槛

- 交付包静态校验与100条ID对应通过；另做逐句原文audit，不能把包内校验视作运行验证。
- 自动排程：周日前置、周一09:00前后、冲突逐日顺延、节假日、读档待办不丢失不双播。
- M07只出现一次；相识当天不播；手术跨过17:00不打断、不拖到夜间补播。
- 伙伴未见/忙碌/不在场全部正确过滤；年度互斥、季节窗口、日额度、冷却正确。
- 所有互动前后时间、属性、货币、关系值不变；医护、患者及约会候选不含惠惠。
- 只在导览/周日安全边界存档；文件不含演出内部状态；改节点结构仍可读；再次存读稳定。
- 运行 `python3 tools/narrative_localization_test.py` 与 `python3 tools/localization_audit.py`，之后完成中英文原生展示测试。
- 图片尺寸、透明边缘、四角、舞台比例和服装切换检查；接待中性→得意、怪谈→狐疑、M07换装、告别、私服展示。当前仅完成图片生成，未宣称通过这些原生测试。
