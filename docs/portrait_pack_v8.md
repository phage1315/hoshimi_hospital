# 患者病房透明立绘修正版 v8

`assets/characters/portrait_pack_v8/` 修正音羽響子与二ノ宮紗智子的病房表情差分。旧版表情图包含暗色渐变、床铺或完整不透明画布；v8 使用内置 ImageGen 的 `background-extraction` 编辑流程，仅保留患者本人，并输出真实 Alpha 透明背景。

每名患者包含 `neutral`、`smile`、`brave`、`worried`、`afraid`、`crying` 六种病房状态。`neutral` 沿用已验证透明的 v6 图，其余十张从 v7 对应表情逐张提取。编辑提示词要求保留人物身份、表情、发型、病号服、姿势、手部、比例、线稿、色彩和画幅，只移除渐变背景、床铺及家具，并禁止光晕、投影、边框、文字和水印。

术前界面也已同步调整：病房患者和医护立绘直接叠加在场景背景上；深色衬底仅保留给手术台俯视图。`tools/portrait_test.gd` 会检查所有病房立绘具有 Alpha，并要求画布四角透明，以防再次混入矩形底图。
