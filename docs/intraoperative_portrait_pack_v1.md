# 术中患者头肩立绘 v1

2026-09-24 使用内置 `image_gen` 为四名成年患者生成透明背景术中头肩立绘：

- `tense`：局部麻醉或硬膜外麻醉下清醒、紧张但仍配合。
- `pain`：无麻醉状态下流泪忍痛。
- `anesthetized`：全身麻醉下闭眼、表情放松。

统一构图为正面头、颈、锁骨与肩顶，人物轮廓在锁骨下方结束。按照用户反馈，最终资源不包含无菌单、衣物、胸部、手术器械或背景。

所有图片以各患者已有俯视手术台素材作为身份参考，使用内置图像生成工具分别生成。共同提示词要求保持人物面部、眼睛颜色、肤色与现有二次元画风，佩戴青绿色一次性手术帽，使用冷色手术室照明和真实透明背景。三组差分只改变表情与意识状态。

资源路径：`assets/characters/intraoperative_portraits_v1/<patient_id>/<expression>.png`。

显示规则：患者术中回应及全麻阶段记录显示患者头肩立绘；团队回应显示发言医护立绘；手术选项页隐藏人物，仅显示虚化后的团队手术背景。
