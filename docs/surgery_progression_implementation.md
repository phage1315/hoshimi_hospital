# 手术成长与术式解锁实现

本轮实现对应两份 V0.1 设计稿：

- `docs/design/HOSHIMI_SURGERY_PROGRESSION_AND_PROCEDURE_UNLOCK_SYSTEM_V0_1.md`
- `docs/design/HOSHIMI_SURGERY_UI_NAMES_AND_STARTING_UNLOCKS_V0_1.md`

## 已实现

- 手术技术仍显示为 0–100 等级，开局为 50；后台改用隐藏的 `surgery_xp` 累计。
- 经验升级曲线分段递增，90 以后明显变陡，99→100 需要 60000 XP。
- 成功手术以术式标准时长为基础结算经验；实际拖延时间不会增加经验。
- 学习效率采用倒 U 型：接近或略高于当前水平的手术收益最高，严重越级时效率下降。
- 每项术式具有 `base_difficulty`、`recommended_surgery` 与 `training_ceiling`；达到训练上限后不再获得全局手术经验。
- 明知适应证不符仍完成手术时，手术经验乘以 `0.20`。患者恐惧、临床气场、行为旗标和声望后果继续独立结算。

## 手术声望

- 2026-10-11 更新：普通病例池的单台基础声望按 `base_difficulty` 线性增长，公式为 `2 + round(clamp((difficulty - 32) / 63, 0, 1) × 13)`。阑尾（难度 32）为 `+2`，普通池最高难度 95 为 `+15`；完整清单见 `docs/surgery_catalog.md`。
- 病例池归属与技术难度分开判断。普通池含高难术式，不能因为难度达到 75 或 90 就发放高级转诊的 `+40 / +75` 奖励。`case_pool` 或 `catalog_visibility` 明确为 `advanced_referral` 才保留转诊奖励规则。
- 保留既有难度档累计软/硬上限：难度 <50 为 `80/100`，50–74 为 `240/300`，75–89 为 `480/600`，≥90 为 `800/999`。达到软上限时基础收益减半并向上取整，达到硬上限时不再增加声望。
- 扫荡使用基础收益；手动完成保留质量系数 S×1.20、A×1.10、B×1、C×0.75、F×0 并向下取整。普通池在质量加成后仍封顶 `15`，且不突破累计硬上限。既有处置惩罚继续独立扣除。
- 新公式仅作用于后续结算，旧存档已有声望与历史记录不追溯重算。千束三日教学的固定事件奖励 `+30` 保留。

## 其他既有实现记录

- 每台成功手术在术式实际耗时之外固定计入 `30` 分钟“术后交接与整理”，涵盖记录、医嘱、交接、家属沟通及更衣离开手术区。手动结算与扫荡结算均显示手术耗时、整理耗时和游戏内总耗时。
- 术中关键判断被纠正会降低本次经验质量，最低保留 50%。
- 25 个正式术式采用新的易读 UI 名称；经阴道子宫全切除作为第 26 项不可选择占位术式。
- 新游戏解锁设计稿指定的 9 项术式。其他术式在选择列表中可见、灰显，并提示必须通过真实临床参与学习。
- 初始患者池至少包含两项玩家能够执行的病例；其余病例按难度降低刷新权重。
- `unlock_procedure()` 作为真实临床参与、助手教学或特殊角色事件的统一解锁接口。阅读与办公室行动不会调用该接口。
- `surgery_xp`、经验历史和术式解锁集合进入 v28 存档。

## 当前平衡参数

基础经验为：

```text
标准时长 × 难度差学习效率 × 操作质量 × 适应证倍率
```

难度差效率：

| 有效难度 − 当前技术 | 效率 |
|---:|---:|
| `< -20` | 10% |
| `-20 ... -6` | 50% |
| `-5 ... +10` | 100% |
| `+11 ... +20` | 125% |
| `+21 ... +30` | 75% |
| `> +30` | 20% |

病例模板目前都有 `difficulty_modifier: 0`。未来加入粘连、解剖变异、组织脆弱等真实复杂病例时，可以在 `-30 ... +30` 范围内调整有效难度。
