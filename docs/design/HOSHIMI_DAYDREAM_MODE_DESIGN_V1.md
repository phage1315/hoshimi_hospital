# 星见医院｜办公室白日梦模式（Daydream Mode）设计 V1

**状态：** 设计基准／待未来实装。白日梦是**坂口隆司本人在办公室产生的非正史幻想**，不是实际发生的医院事件。

## 1. 入口与基本流程

- 在**坂口办公室**增加行动「白日梦」，由玩家主动打开剧本选择界面；绝不自动播放。
- 选择一篇已解锁的幻想，使用现有**固定 VN 演出系统**播放；可加入专属立绘、CG、音效及现实打断结尾。
- 玩家可随时退出并返回办公室；**游戏时间消耗 0**，不推进日历、不占用工作或约会行动。
- 白日梦**不产生** Surgery XP、Reputation、Familiarity、H 收益、真实手术记录或正史剧情 Flag；允许仅在独立的白日梦界面记录「已阅」。

## 2. 三级内容分类

| 等级 | 定位 | 内容示例 |
| --- | --- | --- |
| **普通（Normal）** | 轻松、荒诞、带成人趣味的幻想 | 医疗角色扮演、职业反差、轻喜剧 |
| **重度（Intense）** | 强烈的身体与心理冲击，但不必包含人格／权力越界 | 大型手术、深度恐惧、身体恐怖、极端医疗假想 |
| **暗黑（Dark）** | 明确突破正史行为边界、可能令人不安的幻想 | 非自愿情节、权力滥用、极端支配等黑暗主题 |

**重度不等于暗黑**：以内容性质和行为边界分类，而非仅按画面激烈程度排序。每篇有独立等级和具体内容标签。

## 3. 玩家自主控制

- **默认最高显示等级为「普通」**；玩家可以主动切换到「重度」或「暗黑」。等级作为**最高可见级别**：选择重度时同时显示普通与重度。
- 首次启用暗黑级别时显示明确提示；进入包含敏感主题的单篇剧本前，再显示具体内容标签，允许返回而不播放。
- 列表显示标题、主要角色、等级、内容提示与解锁状态；禁止将暗黑剧情混入普通 H Runner 的随机事件。

## 4. 剧本与正史隔离

- **所有白日梦均属于坂口的主观想象**：允许夸张、扭曲真实手术与人物行为，但不能反向修改人物 Character Bible，也不能将幻想中的行为写成正史事实。
- 剧本可以要求玩家**已经认识角色、完成相关个人事件或手术剧情**，以控制剧透；这些 Gate 只决定可见性，不改变原事件状态。
- 剧情通常从办公室进入幻想，再以走神结束、敲门或其他现实细节返回办公室；**不强制所有故事沿用同一种结尾**。
- 事件期间沿用固定 VN 的存档限制；退出应恢复进入前的办公室状态。

## 5. 交给 Codex 的最小实现边界

复用现有办公室行动菜单、固定 VN Runner、角色注册及资源映射；只新增**白日梦分类／选择界面、可见性 Gate、内容提示、返回办公室**和独立已阅记录。**V1 不开发第二套 Surgery Runner 或 H Runner。** 事件 ID、角色 ID、Flag、图片路径均由 Codex 对照真实工程绑定，不能把示例名字当作已注册接口。

**首批候选：** `FANTASY_MIZUHO_OR_SOLO_01`《敞开的腹腔与独享的手术台》，拟标记「暗黑」；须经单篇文学审定和素材确认后再开放。
