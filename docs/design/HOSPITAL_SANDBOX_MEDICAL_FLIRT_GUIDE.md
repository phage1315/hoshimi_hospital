# 医院沙箱 VN —— 医疗身份调情 / 擦边成人对白指南

## 1. 核心方向

医院背景本身可以成为调情语言。

成人医护之间可以通过以下话题制造暧昧：

- “如果换成我当患者”
- “你给别人检查那么认真，轮到我呢？”
- “是不是要脱光躺上你的检查床，你才肯一直看我？”
- “哪天我挂你的号，你最好亲自负责”
- “如果我是手术台上光光的那个，你会不会更紧张？”
- “我也想被你那么专注地照顾一整天”
- 制服 / 白大褂 / scrub / 手术帽 / 患者身份的反差
- 医生与患者角色扮演式玩笑
- 手术/被手术的幻想玩笑
- 关系越深，越可以主动提出“让我来当患者”的幻想

---

## 2. 低关系阶段：半开玩笑

特点：

- 说完还能退回“我只是开玩笑”
- 不直接要求发生什么
- 重点是测试主角反应

例：

> “你对患者都这么认真？哪天我也挂你的号试试。”

> “是不是非要坐到检查床上，你才会看我这么久？”

> “如果换我当患者，你可别突然变得不专业。”

> “刚才你盯手术台那么认真，我差点以为得躺上去才能抢到你注意。”

---

## 3. 中关系阶段：明显挑逗

例：

> “哪天换我脱光躺上去，你最好从头到尾都这么认真。”

> “我突然有点想知道，被你当患者照顾一整天是什么感觉。”

> “你刚才那副专注样子挺危险的。会让人想亲自躺上去给你开刀试试看。”

> “如果我真的把自己脱光光交给你检查，你敢不敢还这么镇定？”

---

## 4. 高关系阶段：主动角色扮演幻想

可以更直接，但仍以成人角色之间的自愿调情为核心。

例：

> “哪天我真想脱光戴个手术帽给你看，看你还能不能一直装得这么公事公办。”

> “我想当一次你的手术患者。不是开玩笑的那种。”

> “你对手术台上的那个女患者的身体那么专注，我有点嫉妒。哪天换成我躺在手术台上，你可得只看我。”

> “我有时候真想把工作身份全丢掉，乖乖爬上手术台躺下来，让你负责到底。”

---

## 5. Codex 写作规则

1. 医疗背景不是只能严肃，可以成为调情素材。
2. 低关系允许轻度“如果换成我”的暗示。
3. 高关系可以明确表达想扮演患者、接受检查、被主角专注照顾。
4. 调情要由角色性格决定，不要所有人都一样大胆。
5. 成熟女医更从容、掌控感强。
6. 温柔护士更像“照顾欲反转成想被你照顾”。
7. 年轻护士更容易说漏嘴、自己先害羞。
8. 保留成年人之间的自愿和玩笑感。
