## 0. 设计任务

- 角色用途：**常驻医生／外科副部长／外科主任候选／主线职业竞争人物／可攻略成年女性角色**
- 一句话卖点：**28 岁就成为外科副部长的“骑士型领导者”——她未必是医院里手术最锋利的那双手，却最擅长让医院里所有最锋利的手在正确的位置同时发挥。**
- 与现有医生的差异：
  - **神宮寺成美**：成美首先关注“患者本人有没有被医疗系统听见”，擅长患者照护、临床伦理和带教；阿尔托莉雅首先关注“整个团队是否被正确组织”，擅长资源配置、术前计划与多专业协同。两人都重视人，但观察层级不同。
  - **深山佳織**：佳織偏急诊型，节奏快、直接、擅长在信息不完整时抓住事实并立刻处理当前危机；阿尔托莉雅更擅长把复杂病例拆成完整战役，为每一个阶段配置最适合的人和备用方案。
  - **御堂江美子**：御堂相信“我的技术能治好她”；阿尔托莉雅相信“我能让这家医院最强的医生都发挥自己的长处，把患者成功获救的概率推到最高”。御堂是个人技术峰值型，阿尔托莉雅是团队领导峰值型。两人互相尊重且竞争外科主任。
  - **城宮明日香**：明日香是年轻院长兼成长中的外科医生，强项是理论、医院整体管理与制度层决策；阿尔托莉雅是成熟得更早的临床前线领导者，权威主要来自手术团队、病例组织和承担结果的能力。
- 希望玩家产生的第一印象：**年轻得不可思议、端正得近乎古板、讲话像已经当了十年主任；对任何人一视同仁，冷静到很难判断她有没有私人情绪。**
- 关系深入后被推翻或补充的第一印象：**她不是没有欲望和感情，而是习惯把“领导者的责任”放在所有私人需要之前；她真正的成长不是学会领导，而是学会相信别人、分担责任，以及允许自己在下班后只是一个28岁的女人。**

## 3. 人格结构

- 公开形象：**年轻、严谨、公平、极强责任感、说话正式、几乎从不在公开场合失态的外科副部长。**
- 核心性格：**自律、责任感、正直、公平、坚定、克制、竞争心**
- 优点：
  1. **真正能听意见**：不会把“我是领导”误解成“别人不必说话”。
  2. **极强团队识别力**：非常清楚每个医生、护士、麻醉人员真正擅长什么。
  3. **承担最终责任**：需要决定时绝不把最终判断推给委员会。
  4. **公平**：即使讨厌某个人，只要对方技术最合适，她仍然会安排那个人上台。
  5. **危机中稳定**：压力越高，语言越简短，指令越清晰。
- 缺点：
  1. **过度承担**：习惯把团队失败首先解释为“领导者没有做够”。
  2. **不擅长示弱**：疲劳、委屈、欲望和私人需要都倾向压到工作之后。
  3. **责任感偶尔会滑向控制欲**：她会提前替所有人把问题想完，反而让同僚感到“不被真正托付”。
  4. **对自己要求不现实**：允许别人犯错并成长，却很难允许自己“只是普通地累了”。
- 私下的一面：
  - 食量意外大；
  - 对好吃的东西比自己愿意承认得更认真；
  - 对现代轻松约会、随便逛街等“没有目的的活动”有些笨拙；
  - 被夸外貌时反而比被夸手术能力更难接话；
  - 下班后依然穿得过分端正。
- 最在意的事：**自己是否真正让患者获得了“这个医院能够提供的最佳结果”。**
- 最害怕失去的事：**团队对她最终判断的信任；以及因为自己的领导失误让本来可以被救的人错失机会。**
- 容易被误解之处：**她听取很多意见并不意味着优柔寡断；她愿意把最难的步骤交给别人，也不意味着自己技术不足。**
- 喜剧点／反差点：
  - 明明 154 cm，却能让一整间会议室安静；
  - 食量明显超过外表给人的预期；
  - 很认真地分析一个本来只是玩笑的问题；
  - 私服看上去像“永远准备参加正式仪式”；
  - 对医院节庆的小游戏也会认真到像在参加竞技比赛。
- 压力反应：
  - 语速不会显著加快；
  - 句子反而变短；
  - 开始频繁确认人员、资源与 Plan B；
  - 如果危机继续恶化，会收回部分讨论权，直接进入命令模式；
  - 真正极限状态下，她的危险不是慌乱，而是试图把太多责任重新抓到自己手里。
- 专业状态：
  - 表情收紧；
  - 所有非必要闲聊停止；
  - 会迅速确认“谁最适合处理当前问题”；
  - 最终命令清楚、具体、有对象，不会喊空泛的“大家注意”。
- 伦理底线：
  - **绝不为了主任竞争、个人荣誉、证明技术或维持面子而牺牲患者安全。**
  - 如果御堂比她更适合某一步，她会让御堂做。
  - 如果主角真的成为更合适的主刀，她也会让出主刀位。
  - 对她而言，拒绝承认更强的人才是真正的失职。

## 4. 专业能力与玩法定位

数值使用 0—100。50 为合格年轻医生，65 为可独立承担常规任务，75 为成熟骨干，85 为专科强手，90 以上为医院顶尖。

| 能力 | 数值 | 设定理由 |
|---|---:|---|
| 手术技术 `surgery` | **91** | 明确属于医院顶级外科医生，但纯粹比较极限操作技术时仍低于御堂的个人峰值；这也是她愿意在特定步骤使用御堂的原因。 |
| 诊断能力 `diagnostics` | **88** | 高水平复杂病例整合能力，尤其擅长从多专业资料中寻找影响手术计划的关键变量。 |
| 团队协作 `teamwork` | **98** | 核心强项。能理解每名队员的能力、压力与角色，并在复杂手术中实现真正多核心协作。 |
| 患者照护 `patient_care` | **84** | 礼貌、可靠、愿意解释，但安慰风格偏正式；在情绪细腻度上不取代神宮寺成美或杉村弘子。 |
| 器械操作 `instrument_handling` | **90** | 作为顶级外科医生必须具备，但这不是她最特殊的标签。 |
| 临场镇定 `calmness` | **96** | 几乎不会在团队面前慌乱；越危险越清晰。真正风险是过度承担，而非失去冷静。 |

### 扩展玩法属性

```yaml
leadership: 97
```

> `leadership` 是阿尔托莉雅主任竞争线的核心隐藏／扩展属性。  
> 若当前角色系统尚未正式拥有该字段，可以先保留为剧情 Gate 或派生值，后续再由 Codex 接入。

- 手术熟练度：`expert`
- 可担任岗位：`primary_surgeon, assistant_surgeon`
- 最擅长的术式／场景：
  - 高复杂度腹部大手术；
  - 多阶段、长时间手术；
  - 需要多名高级术者协作的病例；
  - 术前资料繁杂、需要 Plan A / B / C 的病例；
  - 多专业会诊与术中资源重新配置。
- 明显短板：
  - 极限精细操作的纯技术峰值不如御堂；
  - 有时过度依赖自己维持全局；
  - 不容易主动承认疲劳；
  - 如果所有人都等她决定，她会本能地承担，而不是逼团队成员成长。
- 独特团队效果构想：
  - **`Right Person, Right Position`**：手术队中每名成员若承担与其强项匹配的岗位，可获得额外稳定性／效率收益。
  - **`Contingency Ready`**：降低突发并发症首次出现时的团队混乱惩罚。
  - **`No Wasted Talent`**：高级助手在她领导下更容易触发角色专属协助技能。
  - **`Command Burden`**：若团队过度依赖她、连续多个阶段由她承担最终处理，她自身疲劳累积更快，表现其“把所有责任抓回来”的缺点。
- 首次担任助手时的特殊表现：
  - 她不会把“助手”理解为低一级的岗位；
  - 会在术前主动询问主刀的计划、备用方案和希望她承担的职责；
  - 确认后严格执行；
  - 若主刀临时改变方案，只要理由成立，她不会因为“不是我的方案”而抵触。
- 与坂口隆司在手术台上的互补或冲突：
  - 初期她会观察坂口是不是只会靠个人技术强推；
  - 她尤其关注他是否懂得使用护士、助手、麻醉团队；
  - 中期两人容易在“该不该继续自己承担”上发生冲突；
  - 高关系后，她可以把整台手术的团队协调权交给自己，同时接受坂口作为最终主刀／最终权威；
  - 佐伯大手术中，她成为第二助手兼全局协调，是两人关系的最高职业证明。

## 5. 医院活动范围

- 固定工作地点：
  - `or`
  - `surgery_director_office`
- 随机休息地点：
  - `lounge`
  - `rooftop`
- 常见上班时段：
  - 工作日 07:30—19:30 为主；
  - 大型手术日可明显延长；
  - 偶尔在晚上仍出现在外科办公室做次日排班和病例计划。
- 初次见面地点与时间：
  - `surgery_director_office`
  - 主角加入医院后的早期工作日上午。
- 初次见面是否有前置条件：
  - 完成基础医院探索；
  - 已开放外科科室；
  - 不要求关系数值或高 Surgery。
- 加入手术团队的解锁条件：
  - 完成初次登场事件；
  - 她确认主角至少具有独立外科医生的基础能力；
  - 初期优先作为主刀或高级助手；
  - Lv1 后可常规邀请；
  - Lv3 后解锁高难病例的“全局协调”高级行为。

## 6. 说话方式（Voice Profile）

| 维度 | 设定 |
|---|---|
| 正式程度 `formality` | **高**。即使熟悉以后，在工作场合仍保持完整而准确的表达。 |
| 直接程度 `directness` | **高**。不会用模糊语言逃避决定，但也不故意羞辱人。 |

## 8. 个人剧情与关系弧线

- 核心矛盾：
  > **她已经会领导别人，却仍然不真正相信“领导者可以把责任交出去”。**
- 她最初如何评价坂口隆司：
  > “技术评价很高。但一个人会开刀，和一个人值得别人把手术交给他，是两回事。”
- 坂口最初如何评价她：
  > “二十八岁就当副部长，讲话却像已经替整个外科收拾了十年烂摊子。”
- 两人建立尊重的关键：
  > 坂口第一次在手术中主动把一个自己“也能做”的步骤交给更合适的人，同时明确承担最终决定；阿尔托莉雅意识到他不是只会证明自己。
- 她不愿公开的脆弱或秘密：
  > 她长期把“值得被依靠”与“不能给别人添麻烦”混为一谈。真正疲惫时反而更难求助。她害怕一旦承认自己也需要照顾，团队对她的信任就会下降。
- 关系弧线一句话：
  > **从“我要成为所有人的可靠领导者”，发展到“我可以相信一个人，在我不当领导的时候也接得住我”。**
- 路线基调：
  > **竞争者／职业搭档／主任哲学对照／成熟恋爱／医生→患者角色反转**

> “你做得到不说话？”

阿尔托莉雅：

> “……这是另一项挑战。”

# 角色生态位结论

阿尔托莉雅会与御堂存在明显功能重叠：

```text
两人都是顶级外科医生
两人都是主任候选
两人都具有很强权威
```

但必须坚持以下差异：

```text
御堂江美子
= “最强的刀”
= 个人极限技术
= 技术自信
= 手术本身带来的强烈欲望与兴奋
= 我的技术能治好患者

阿尔托莉雅
= “最好的指挥者”
= 团队极限
= 责任与组织
= 把正确的人放到正确位置
= 让整个医院共同治好患者
```

两人互相承认：

> **御堂知道，如果要组织一场超大型复杂手术，阿尔托莉雅比自己更适合统筹。**

> **阿尔托莉雅知道，如果术野进入最糟糕的纯技术死局，御堂是自己最希望站在身边的人。**

当坂口隆司最终同时满足：

```text
Surgery > 御堂
Leadership > 阿尔托莉雅
Relationship(御堂) >= Lv3
Relationship(阿尔托莉雅) >= Lv3
```

并成功主刀佐伯ほづみ的地狱级手术时：

> **御堂承认：他的技术已经足以让自己作为第一助手。**

> **阿尔托莉雅承认：他的领导力已经足以让自己接受最终指挥。**

这不是“主角击败两个女人”。

而是：

> **两个本来都有资格成为外科主任的人，在亲眼看见他的能力以后，共同得出结论——坂口隆司比她们更适合坐那个位置。**

这是阿尔托莉雅在 Hoshimi 主线中的最高职业意义。
