# 术前流程小屏动画

## 当前接入

“更换手术服”“刷手准备”和“进入手术室”动作成功结算后，界面以 752×416 居中小屏静音播放对应动画。画面不使用标题、倍速提示、按钮或装饰边框，只显示视频本身。三段运行素材均以 2 倍速播放，实际转场约 1–1.19 秒；结束后自动返回术前流程。

- `change_scrubs`：`assets/animations/preop/change_scrubs_take_gown_v1.ogv`；用户提供的2.25秒裁剪版，2倍速实际约1.125秒。
- `scrub_hands`：`assets/animations/preop/scrub_hands_v1.ogv`；从6.04秒原片截取第2.000–4.000秒，2倍速实际约1秒。
- `enter_room`：`assets/animations/preop/enter_operating_room_v1.ogv`；用户提供的2.38秒裁剪版，2倍速实际约1.19秒。

动作状态与耗时在播放前已经结算，视频只承担视觉转场。视频结束后才重新渲染术前界面，因此刷手完成后可能触发的人物事件可以继续放在动画之后，不会被转场覆盖。

更衣与刷手虽然共用 `changing` 流程阶段，但场景会随状态改变：更衣完成前使用 `changing`，完成更衣后即切换到 `scrub_area`，刷手动画及后续刷手池事件因此都建立在刷手区场景上。

`PREOP_TRANSITION_VIDEOS` 按动作 ID 配置，后续还可以直接加入：

- `enter_room`：进入手术室。

## 素材约定

- 用户可以提供 MP4，原始文件保存在 `research/videos/preop/`；
- Godot 运行文件使用 Theora OGV、`yuv420p`、24 fps；
- 推荐画面比例接近 16:9；当前素材为 752×416；
- 推荐截取后时长 1.5–3 秒，再按动作节奏设置 1–2 倍播放；
- 默认移除音轨，避免极短转场的声音突兀或倍速变调；
- 小于约 1.5 秒的实际演出不显示跳过按钮。
