# 手术流程小屏动画

## 当前接入点

已配置动画池的术式在确认下刀后按以下顺序显示：

1. 显示患者术中立绘；
2. 玩家选择下刀后，不再显示二次确认，立即从对应术式的动画池随机挑选一段；
3. 在 752 × 416 的小屏窗口以 1.25 倍速播放切口动画；
4. 动画结束后显示患者的疼痛反应，并继续术式步骤。

腹部普外、泌尿及腹主动脉术式共用腹部切口池；妇科盆腔、乳房以及开胸／心脏术式各用独立池。所有切入动画统一以 1.25 倍速播放，6.04 秒的素材实际约占用 4.83 秒。无麻醉时保留动画原声；局麻、硬膜外和全身麻醉时仍播放画面，但统一静音。全麻播放结束后直接进入下一项手术步骤，不产生清醒患者的疼痛反应。播放器提供“跳过动画”，播放完成也会自动继续。

同一动画池会记住上次播放结果；存在多个可用素材时，不会连续两次播放同一段。其他术式以后可以建立独立的动画池。

当前动画池：

- `abdominal`：腹部普外、泌尿、腹主动脉；
- `pelvic`：妇科盆腔手术；
- `breast`：乳腺肿瘤切除术、全乳房切除术。
- `thoracic`：开胸肺部、食管手术及心脏手术。

## 素材约定

- Godot 运行素材：`assets/animations/surgery/*.ogv`；
- 推荐视频编码：Theora，像素格式 `yuv420p`；
- 推荐音频编码：Vorbis，48 kHz；
- 推荐画面比例：接近 16:9；
- 推荐时长：3–8 秒；当前素材为 6.04 秒、752 × 416、24 fps；
- 不循环播放，动画只负责视觉演出，不推进手术状态。

原始 MP4 留在 `research/videos/`，游戏只加载 OGV。
