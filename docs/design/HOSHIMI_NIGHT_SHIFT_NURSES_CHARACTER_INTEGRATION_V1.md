## 神宮寺成美 / 七瀬恋
### Codex Character Integration Guide — V1

> **项目实施注记（2026-09-29）**：用户在导入本文时明确要求删除神宮寺成美与七瀬恋原有的四章 Lv1 事件链，并在之后重新构思。该当次指令优先于本文中“不要删除已有事件链／现有事件方向必须保留”的旧建议。人物背景与性格定位继续作为 canonical；旧事件标题和结构只作为历史材料，不再是当前事件设计。

> 用途：把此前关于《夜勤病棟》角色如何进入 Hoshimi Hospital 的讨论固化为 Codex 可执行的人物档案与兼容规则。

> 本文件优先描述 **Hoshimi AU 的既定人物定位**。它不是《夜勤病棟》原作剧情复述，也不要用本文件反向推断原作全部设定。

>
> **Night Shift past = character history, not current main plot.**
>
> Hoshimi 要保留她们过去留下的性格、职业习惯、警觉、创伤与彼此关系，但不要把旧作黑暗剧情重新变成星见医院现在正在发生的主线。

# 2. 两人的共同 Hoshimi 背景

Hoshimi 采用的是“旧作之后／旧作分歧后的第二人生”式兼容，而不是把《夜勤病棟》原剧情原封不动搬进来。

当前既定理解：

```text
神宮寺成美
+
七瀬恋
↓
曾共同经历过极不健康、危险的旧医院环境
↓
两人最终一起摆脱比良坂竜二一类旧环境影响
↓
离开旧生活
↓
被城宮明日香接纳 / 招入 Hoshimi Hospital
↓
在星见医院重新建立职业与私人生活
```

最重要的是：

> **过去已经结束。**

它可以留下：

- 对某类患者状态的敏锐；
- 对权威滥用的警惕；
- 对“患者说没事”这句话的怀疑；
- 对夜班、封闭空间、异常医患关系的复杂反应；
- 两人之间无需解释的默契；
- 偶尔的旧事 callback。

但不要变成：

```text
比良坂突然来到星见医院
旧医院犯罪集团继续追杀
旧作主线重新启动
每个 Lv Event 都围绕 PTSD
角色永远活在受害者身份里
```

# 3. Hoshimi 的“第二人生”原则

星见医院不是她们原作悲剧的续集舞台。

应该表现为：

> **她们已经能够正常工作、开玩笑、恋爱、参加团建、做手术、照顾患者。**

过去并未消失，但：

> **过去不能吞掉现在。**

写作比例建议：

```yaml
current_hospital_life: 70
professional_identity: 20
legacy_past: 10
```

这不是严格数值，只用于提醒 Codex：不要每三句话就暗示旧作。

# 4. 神宮寺成美 — Character Bible

## 4.1 核心定位

> **真正会先听患者说话，再看数字的医生。**

她特别重视：

- 患者主观感受；
- 病历没有写出来的部分；
- 家属与患者意见冲突；
- “医学上能做”与“患者还想不想继续”之间的距离；
- 团队成员是否真的听见患者。

关键词：

```yaml
tags:
  - physician
  - clinically_observant
  - patient_voice
  - thoughtful
  - experienced
  - restrained
  - dry_humor
  - mentor_energy
```

## 4.2 当前职业角色

Hoshimi 中她属于：

```text
医生
可作为手术助手
可参与病房判断
可承担患者沟通
可参与临床带教
```

她不是只负责“心理安慰”的医生。

在手术室中，她必须表现出真实医学能力和可靠的协助手术判断。

## 4.3 性格

表面：

- 成熟；
- 稳定；
- 不轻易惊慌；
- 会说略带刺但不恶意的话；
- 不喜欢空泛安慰；
- 对医疗中的自欺欺人比较敏感。

她不是圣母、软弱、永远温柔、没有主见。

## 4.4 关系主题

不要写成：

> “坂口把她从过去救出来。”

更适合：

> **两个已经能正常工作的成年人，在职业判断、疲劳、患者选择和彼此信任上逐渐靠近。**

她过去的价值在于解释为什么她如今如此重视患者自己的声音，而不是制造连续黑暗剧情。

## 4.5 现有事件方向必须保留

- 《冷掉的茶》：忙碌、职业克制、休息室里的私人一面。
- 《病历上的空白》：病历没有写出来的东西同样重要。
- 《没有立即给出的答案》：医疗伦理没有永远标准化的唯一答案，她允许“不确定”。
- 《仍然亮着的灯》：工作后的私人时间、带教、前辈影响、两个成年人一起留到很晚。

# 5. 七瀬恋 — Character Bible

## 5.1 核心定位

> **她真正想要的是一个普通人的生活。**

她最重要的愿望就是：

> “普通地工作、普通地下班、普通地吃东西、普通地喜欢一个人。”

关键词：

```yaml
tags:
  - nurse
  - sensitive
  - observant
  - practical
  - emotionally_guarded
  - wants_normal_life
  - patient_advocate
```

## 5.2 当前职业角色

适合：

```text
病房护理
交班
患者情绪观察
巡回护士
围手术期患者照护
```

她尤其适合观察：

> 患者嘴上说“没关系”，身体和行为却明显不是。

## 5.3 性格

她不是永远害怕、永远沉默、纯受害者。

她可以：

- 正常吐槽；
- 和同事吃饭；
- 参加团建；
- 对坂口表现出不耐烦；
- 工作时非常硬；
- 在患者安全问题上突然变得很坚决。

## 5.4 核心人生目标

恋来到 Hoshimi 后最重要的东西：

> **普通。**

因此很多很小的事件都可以有意义：

- 午休把三明治吃完；
- 下班以后不再需要担心谁会突然找她；
- 周日真正休息；
- 和别人约会；
- 去买东西；
- 抱怨值班；
- 第二天照常来上班。

## 5.5 现有事件方向必须保留

- 《半份三明治》：日常压力与“正常吃饭”都不一定容易的起点。
- 《交接单上的一行字》：她认真注意到别人容易忽略的信息。
- 《患者说“没关系”》：她非常关键的职业主题。
- 《摘下口罩以后》：工作时坚硬的一面结束后，她允许自己承认疲劳与情绪。

# 6. 成美与恋的共同关系

她们应该是：

> **共享过一段无需对别人详细解释的旧历史。**

但不要让两人的关系变成每天互相安慰过去。

更自然的是：

- 工作中直接说话；
- 不需要解释某些反应；
- 会互相拆台；
- 对方情绪异常时能第一时间发现；
- 共同生活经验形成老搭档感。

她们已经从：

> “共同逃离过去的人”

变成：

> “真正的同事。”

---

# 7. 建议共享事件：《夜班结束以后》

当前讨论中已经确定的适合两人的共同主题事件。

核心对白：

恋：

> “这里的夜班还真安静。”

成美：

> “不好吗？”

恋：

> “很好啊。特别好。”

不需要解释“为什么”。

了解旧作的人自然明白；不了解的人也能理解她珍惜这里平静的夜班。

# 8. 城宮明日香的作用

当前兼容设定中：

> **城宮明日香是把她们接入 Hoshimi 的关键人物。**

不要写成救世主神话。

更适合：

```text
Asuka recognized competence
+
accepted that both had complicated prior employment
+
gave them a legitimate new workplace
+
did not force them to endlessly explain the past
```

因此两人对明日香的尊重可以比普通员工稍深。

但她们现在留下来，是因为真的喜欢并认可现在的医院，而不是因为欠明日香一辈子的人情。

# 9. 坂口与她们的关系

坂口不需要调查旧医院。

禁用：

```text
“告诉我过去到底发生了什么”
“我要替你报仇”
“我来治愈你的创伤”
```

更好的关系：

- 对成美：职业判断上的互相尊重逐渐进入私人关系。
- 对恋：让她发现与一个男人建立亲密关系，也可以不意味着再次失去生活控制。

如果进入成人路线，必须是现在的、双方自愿的成年关系。

不要让 H 场景承担“治疗旧创伤”的功能。

# 10. Surgery / OR 中的两人

## 成美

手术时应：

- 专业；
- 直接；
- 能质疑坂口；
- 能判断什么时候应该继续；
- 能关注患者整体状态；
- 不因为私人关系而降低标准。

## 恋

手术室中应：

- 非常注意患者情绪；
- 认真确认交接；
- 能在必要时提醒医生“患者真正说了什么”；
- 不只是负责慌张或害羞的背景护士。

# 11. Staff-as-Patient

未来两人都可以进入 Staff-as-Patient 系统。

前提：

```text
成人
高关系
自愿
医学安全条件成立
```

### 成美

作为患者后仍然很容易本能地分析医疗过程。

她需要学习：

> 今天不是由她来做判断。

### 恋

对“成为患者”可能拥有更复杂的控制感反应。

但她最终愿意躺上手术台应该表达：

> **现在的她已经能够主动选择把控制交给自己信任的人。**

不要写成旧作情节复刻。

# 13. 旧作 callback 的允许范围

允许：

- 一两句旧医院；
- 对夜班的特殊感受；
- 两人之间不解释的眼神；
- 看到某类不专业权威时明显反感；
- 某些旧照片；
- 某些职业习惯。

不允许：

- 详细重演虐待；
- 大量 flashback；
- 把比良坂重新变成现役主线 villain；
- 当前 Hoshimi 大规模复制旧医院伦理崩坏。
