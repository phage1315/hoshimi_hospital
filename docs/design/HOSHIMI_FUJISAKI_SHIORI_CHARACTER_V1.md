# 藤崎詩織角色设计 V1

## 基本资料

- 姓名：藤崎 詩織（ふじさき しおり）
- 年龄：25
- 性别：女性
- 职业：医生
- 专科：综合内科
- 职称：内科医师／专攻医（完成初期研修，正在内科专科训练）
- 定位：从“校园里的全能女神”成长为几乎没有明显短板的年轻内科医生；她最擅长的不是某一项绝技，而是把患者作为一个完整的人看懂。

## 性格与说话方式

温柔、端庄、自律、聪明、理性、有教养，待人自然亲切；隐藏着很强的好胜心和自尊，对自己的要求远高于表面表现。说话礼貌清楚、语速平稳，很少抢话；面对患者会主动把医学术语换成容易理解的表达。即使反对别人也先说明理由，不咄咄逼人。关系熟悉以后会流露含蓄的玩笑和竞争心。

## 与现有及未来角色的关系

- 坂口隆司：内科与外科之间的天然会诊搭档。坂口擅长解决病灶，詩織提醒他是否还有没被看见的全身问题。
- 神宮寺成美：非常合拍的临床同事。成美关注患者有没有被听见，詩織关注是否真正理解了完整病情。
- 城宮明日香：很快注意到她几乎没有明显临床短板，并把她视为未来内科骨干。
- 御堂江美子：彼此尊重；围术期风险判断发生分歧时，詩織不会因御堂的外科权威而退让。
- 佐仓双叶：未来角色。双叶关注标准数据，詩織会提醒她漂亮的数据不等于完整的临床事实。
- 伊吹摩耶：未来角色。两人都礼貌克制；摩耶可能较早看出詩織总表现得“自己没问题”的习惯。

未定义的佐仓双叶与伊吹摩耶目前只作为未来写作关系保留，不建立运行时引用。

## 游戏定位

- 开局未认识。玩家完成至少 3 例手术后，可在门诊或病房遇见并触发相识；事件此后持续保留，避免永久错过角色。
- 相识时坂口会认出她曾因游戏角色设计选秀而被媒体称为“国民女神”。她对此非常不好意思，并解释那次活动原本只是纪念，却意外引来广告、采访与事务所邀请；娱乐圈不断要求她成为别人期待的“藤崎詩織”，与她的志向不合，因此最终选择了更自在也更真实的医生道路。
- 正式相识后可邀请加入手术团队。
- 手术岗位仅限助手，熟练度 `limited`；不作为常规主刀。
- 主要工作：内科会诊、术前风险评估、围术期内科管理、复杂患者综合评估。
- 擅长综合诊断、原因不明症状鉴别、多系统疾病整合、慢性病管理、围术期心肺与代谢风险判断、复杂病史整理、患者沟通和长期随访。
- 短板：实际手术经验有限，不擅长用纯技术操作解决问题；不习惯公开承认不会或判断失误，也不擅长在被依赖时及时说自己累了。

## 手术团队对白

- 被选入团队：「我可以做助手，不过先说好，我不是外科医生。需要我看全身状态的话，我会比看术野更有用。（有点紧张……不过我应该可以做好的。）」
- 术中回应：「循环目前稳定。继续可以，但别只看眼前这一块。」
- 被纠正：「明白，是我判断得太快了。继续，我会重新确认。」
- 稳定突发状况：「先别慌。手术本身的问题交给主刀，其他生命体征我来重新整理。」
- 岗位确认：「助手位确认。不过围术期状态如果出现异常，我会直接说，不会等你问。」

## 写作约束

公开形象是年轻、漂亮、成绩优秀、待人得体、患者缘很好的模范女医生。她知识面广、沟通能力强、情绪稳定，能把碎片信息整理为患者的完整医学图景。压力越大，她表面越平静礼貌，会反复检查资料并减少不必要的话；即使疲劳也常回答“我没事”。

关系发展的核心是：一直被认为什么都能做到的人，也希望偶尔有人允许她做不到。事件可围绕优秀身份的压力、第一次公开承认判断错误、允许别人替她处理事情，以及医生以外的普通成年女性生活展开。

不能把她写成高傲大小姐、没有缺点的万能机器、轻浮的红发女医，或让她抢占御堂、阿尔托莉雅等人的外科生态位。她不会为了完美形象隐瞒会危害患者的重大错误。
