# Hoshimi Hospital 世界观基调与内容设计原则
## Codex / 内容生成统一规范

> 项目：Hoshimi Hospital  
> 文档用途：统一世界观、剧情语气、角色事件、手术室事件、医院活动、成人内容与群像设计方向。  
> 适用范围：角色事件、手术室事件、患者事件、办公室事件、医院祭、医院吉祥物、H事件、随机日常事件。  
> 本文优先定义“这个世界应该给玩家什么感觉”，不是现实医疗规范。

---

# 1. 一句话世界观

> **看起来像一群年轻美少女/美女组成的青春社团在经营医院，工作起来却是真正专业、可靠、经得起考验的医护团队。**

进一步概括：

> **轻松、可爱、荒诞、带一点色情和越界；但总体安全、温暖、低致死性。**

---

# 2. 游戏的情绪目标

玩家应该长期感受到：

```text
这里很好玩
这里很有人情味
这里有很多漂亮、可爱、专业的年轻医护
这里经常发生一点不太正常、甚至有些黄油味的事情
但这里不是邪恶医院，也不是黑深残世界
```

玩家的核心感受不是：

> “我什么时候会被剧情狠狠惩罚？”

而应该是：

> “今天这家医院又会发生什么奇怪但可爱的事？”

---

# 3. 医疗世界的“物理法则”

本作不是现实主义医疗剧。

采用：

> **高戏剧性、低致死性**

原则。

## 3.1 几乎不会死人

普通手术、普通事故、普通失误：

```text
不要轻易导致死亡
不要频繁导致永久残疾
不要用严重后遗症制造剧情重量
```

真正死亡只适合极少数特殊剧情，而且不是日常玩法基调。

---

## 3.2 手术意外主要用于制造互动

例如：

```text
出血
低血压
低氧
患者恐慌
患者逃跑
器械问题
助手判断失误
术式比预期困难
```

这些事件的主要作用是：

```text
制造策略
制造角色互动
制造角色成长
制造CG
制造吐槽
制造回调
```

而不是制造黑暗后果。

---

## 3.3 痛苦可以夸张，后果不必阴惨

例如无麻醉路线：

```text
患者可以惨叫
可以哭
可以挣扎
可以骂主角
可以心率飙高
可以说“我不要开刀”
```

但世界观默认：

> 她大概率仍然会平安结束手术。

术后可以：

```text
红着脸抱怨
吐槽医生
说再也不要来了
过一阵又出现
```

荒诞感优先于创伤感。

---

# 4. 专业性必须始终成立

轻松、可爱、黄油化，不代表“大家都是笨蛋”。

所有主要医护角色都必须：

```text
有明确专业能力
有职业判断
有自己的强项
遇到真正问题时能立刻进入专业状态
```

例如：

- 御堂江美子：外科技术极强，判断果断。
- 杉村弘子：资深护士，患者照护和新人带教可靠。
- 飯村真奈美：药剂师，外科现场会吐槽，但药物相关问题非常专业。
- 城宮明日香：年轻院长/年轻医生，理论强、观察与辅助经验丰富，主刀经验仍在成长。
- 本庄萌恵：年轻、可爱、偶尔缺根筋，但会学习、会成长。

核心原则：

> **角色可以闹，但不能长期无能。**

---

# 5. “青春社团感”是什么

医院里的年轻医护应该有：

```text
同事间玩笑
互相吐槽
恶作剧
害羞
八卦
比赛
节庆
一起加班
一起吃东西
一起做奇怪企划
```

但工作时：

```text
该刷手就刷手
该清点就清点
该处理风险就处理
该认真时瞬间认真
```

可概括为：

> **“看起来像青春社团，工作起来像真正医院。”**

---

# 6. 成人/H感的核心原则

成人内容不要求每次都是直接H。

更重要的是：

```text
身份反差
医疗羞耻
熟人之间的边界轻微越过
职业角色变成患者
清醒患者的脆弱
秘密OR文化
高关系角色之间的默契和暧昧
```

推荐的成人味：

> **医疗仪式中的受控越界感。**

不是：

> 越露骨越好。

而是：

```text
先把医疗场景建立得很专业
→ 再让角色关系稍微跨过正常边界
→ 产生荒诞、暧昧、可爱、性感的效果
```

---

# 7. 成人事件的边界

所有成人/H相关角色必须明确为成年人。

高关系成人事件默认要求：

```text
adult_character = true
relationship_threshold met
consent / willingness clearly established
```

本作可以：

```text
大胆
浪
暧昧
恶作剧
越界
成人化
```

但整体目的应是：

```text
角色互动
喜剧
亲密感
收藏内容
特殊CG
```

不要把医院写成恶意场所。

---

# 8. 非恶意越界可以存在

本作允许熟悉医护之间出现：

```text
恶作剧式体位固定
患者体验模拟
奇怪的手术室秘密
成人向“秘密抽屉”
教学录像
深夜OR玩笑
角色互换
医护自己成为患者
```

核心要求：

```text
不是为了伤害
角色之间有足够熟悉度
事后能自然回到轻松关系
不会造成黑暗后果
```

---

# 9. “失败”应该产生内容，而不是只产生Game Over

推荐：

```text
做错
→ 被助手发现
→ 修正
→ 花时间 / 增加风险 / 被吐槽
→ 继续
```

玩家应该记住：

> “那次御堂救了我。”

而不是：

> “那次系统弹出了失败界面。”

---

# 10. 角色互动本身就是玩法

提高游戏性不只靠：

```text
更多数值
更多难度
更多失败概率
```

还靠：

```text
更多角色专属反应
更多团队组合
更多关系回调
更多CG
更多特殊事件
```

玩家应该会产生：

> **“我想再和这个角色上一台手术，看看她还会说什么。”**

这是与策略玩法同等级的重要目标。

---

# 11. 手术室是重要社交舞台

手术室不只是“战斗地图”。

它也是：

```text
职业关系
角色默契
成人反差
荒诞事件
患者互动
角色成长
CG解锁
```

的重要舞台。

同一台普通手术，因为：

```text
助手是谁
器械护士是谁
巡回护士是谁
患者是谁
关系等级是多少
```

应该拥有明显不同的气氛。

---

# 12. 手术室互动岗位基调

## Assistant

> 最深的技术互动

负责：

```text
判断
提醒
建议
质疑
介入
救场
```

## Scrub Nurse

> 最频繁的微互动

负责：

```text
器械
传递
节奏
清点
主刀习惯
默契
```

## Circulating Nurse

> 最丰富的情境互动

负责：

```text
患者情绪
监护
补给
设备
联络
外围问题
```

---

# 13. 医护成为患者的特殊事件

这是本作非常重要的高关系内容。

核心：

> **平时最熟悉流程的人，真正躺到患者位以后，第一次从身体上理解自己每天做的事情。**

职业差异：

## 护士作为患者

更敏感于：

```text
器械
术前准备
清点
体位
监护
流程
```

## 女医作为患者

更敏感于：

```text
解剖
术式进度
牵拉
身体感觉与手术步骤对应
```

这类内容可用于：

```text
Lv5
特殊CG
角色成长
术后职业行为改变
```

---

# 14. 荒诞事件的推荐风格

推荐：

```text
妇科主任测试新妇科椅把自己卡住
女外科医生偷偷体验患者位后被熟人恶作剧
药剂师被拉去做临时手术助手
患者看到器械台吓到失控
高Fear患者逃离OR
清醒患者懂医学，边痛边实时分析自己被做到哪一步
```

这些事件的共同原则：

> **有点越界，有点黄，有点可爱，但最后不会变成惨剧。**

---

# 15. 医院吉祥物系统

医院吉祥物用于强化：

```text
青春社团感
医院归属感
医院祭
办公室视觉成长
患者互动
周边与CG
```

---

# 16. 吉祥物设计大赛

建议作为院内活动。

各科室可以提交自己的版本。

例如：

```text
外科：手术帽动物
妇科：可爱子宫/花朵主题
药房：胶囊/药瓶主题
护士站：爱心/绷带主题
```

角色会根据性格产生不同提案。

---

# 17. 吉祥物投票

玩家可参与最终选择。

效果可影响：

```text
Hospital Morale
Relationship
Hospital Reputation
office decoration
festival content
```

不需要复杂数值。

---

# 18. 吉祥物后续用途

获胜吉祥物可以出现在：

```text
医院入口海报
护士站马克杯
患者区玩偶
医院祭大型人偶
办公室摆件
贴纸
手术帽图案
```

角色也可以产生个人反应。

例如御堂嘴上说幼稚，办公桌却出现一只。

---

# 19. 医院祭（Hospital Festival）

医院祭是本作重要的大型群像活动。

灵感：

> **学园祭式医院活动**

世界观理由：

> 医院年轻医护很多，院长希望医院不只是“治病的地方”，也成为员工和患者愿意亲近的场所。

---

# 20. 医院祭可包含的活动

## 科室摊位

例如：

```text
外科：模拟缝合体验
药房：猜药名 / 药物知识小游戏
护士站：血压测量
妇科：健康咨询
康复科：体力小游戏
```

不追求现实严肃科普。

---

## OR开放体验

不观看真实手术。

可以：

```text
展示器械
穿手术服体验
看模拟OR
模拟手术竞赛
```

本庄可以负责讲解器械。

若已发生“别让她看见”事件：

> 她会明显更注意参观者是否被吓到。

---

## 模拟手术比赛

医生和护士组队。

适合：

```text
御堂过度认真
明日香开心参与
饭村被拉来吐槽
弘子负责维持秩序
```

---

## 医院制服 / 主题服装

医院祭可以解锁：

```text
围裙
法被
主题T恤
吉祥物服装
角色专属节庆CG
```

---

## 医院小姐 / 人气投票

作为轻黄油活动可以存在。

前提：

```text
大家自愿参加
整体气氛轻松
不影响职业尊严
```

---

## 后夜祭

活动结束后：

```text
屋顶
休息室
手术室
办公室
```

可以出现：

```text
收拾
吃剩下的食物
群像对话
关系事件
```

非常适合中后期角色内容。

---

# 21. 医院活动的用途

大型活动不是纯装饰。

它们可以：

```text
增加 Staff Morale
增加关系
增加 Hospital Reputation
解锁CG
改变办公室装饰
创造角色组合事件
```

---

# 22. 一年的节奏

建议形成：

```text
工作日
→ 门诊 / 手术 / 办公室

关系日
→ 角色事件 / H事件 / 私人互动

节庆日
→ 医院祭 / 吉祥物 / 群像活动
```

避免：

```text
看病 → 开刀 → 约会 → 看病 → 开刀
```

无限重复。

---

# 23. 主线氛围

主角：

```text
海外研修归来
一年期合同
最初把医院当暂时落脚点
```

一年中通过：

```text
共同手术
患者故事
办公室物品
医院祭
角色关系
荒诞日常
```

逐渐产生归属感。

主线不是：

```text
揭露巨大阴谋
拯救医院
黑暗医疗政治
```

而是：

> **“什么时候，这里从工作地点变成了我的医院？”**

---

# 24. 角色事件设计检查表

新增事件时，应至少满足以下一项：

```text
A. 让玩家更理解医疗工作
B. 让玩家更理解某个角色
C. 让玩家更喜欢待在这家医院
D. 提供有趣的角色互动
E. 提供可爱的荒诞感
F. 提供成人/暧昧内容
G. 提供CG/收藏价值
```

如果一项都没有：

> 不建议加入。

---

# 25. 不推荐的剧情方向

默认避免：

```text
连续死人
医疗事故造成长期阴影
恶意虐待患者
角色长期互害
大型犯罪阴谋
黑帮
血腥复仇
悲剧性永久残疾
为了“深刻”而强行黑暗
```

除非未来明确决定制作特殊支线。

---

# 26. 推荐的剧情方向

优先：

```text
职业成长
人物默契
患者康复
医院生活
同事打闹
轻度嫉妒
荒诞OR事件
角色身份反差
高关系越界
成人喜剧
群像活动
特殊CG
一年后的归属感
```

---

# 27. 对“色”和“浪”的要求

允许：

```text
角色评论漂亮身材
医疗场景中的羞耻感
泳装晒痕
成人玩笑
高关系的边界越过
特殊OR秘密
H事件
角色之间大胆调情
```

但不要让所有对话都色情化。

成人味应该是：

> **偶尔突然冒出来，反差才有味道。**

---

# 28. 对“可爱”的要求

可爱不等于幼态。

主要角色是成年女性。

“可爱”来自：

```text
反应
嘴硬
害羞
犯小错误
认真过头
职业反差
互相吐槽
熟人恶作剧
```

而不是儿童化。

---

# 29. 对现实医学的态度

目标：

> **方向正确即可。**

不追求：

```text
真实麻醉科模拟
真实外科教程
完整医院排班模拟
严格现实死亡率
```

现实知识主要服务：

```text
临场感
角色对白
手术氛围
策略直觉
```

如果现实准确度与“本作轻松荒诞基调”冲突：

> 优先保证游戏基调。

# 31. 最终世界观总结

这不是：

> 一家危险、阴暗、吃人的医院。

而是：

> **一家年轻、漂亮、专业、偶尔离谱、经常很好笑、偶尔很色、又真正会认真救人的医院。**

患者可以：

> 被吓到怀疑人生。

但原则上：

> **尽量不要真的失去人生。**

医护可以：

> 玩得很浪、越一点界、做一些不太正常的事。

但真正需要她们的时候：

> **她们一定靠得住。**

最终玩家应该觉得：

> **“这家医院很奇怪。”**

然后一年以后变成：

> **“但我真的舍不得离开。”**
