## 《本人就在这里》
### 锦木千束 / Advanced Referral Tutorial / 完整 Script + Codex 实装规格

> **文件性质：Canonical Event Design**
>
> **稳定文件名：** 后续直接更新本文件，不创建 V2 / V3。
>
> **事件目的：**
>
> 这是玩家第一次进入 Advanced Referral 的固定三日教学病例。
>
> Day 1 与 Day 3 以 scripted VN 为主，只保留少量不影响结果的选择；

# 1. 为什么锁定为心脏手术

千束的角色核心本来就和人工心脏高度相关。

因此第一次 Advanced Referral 如果使用：

> **开胸人工心脏系统置换**

会比肝脏手术更有角色意义。

这次 Hoshimi AU 的病情设定：

```text
千束现有人工心脏系统出现无法通过外部维护解决的驱动 / 供能异常
↓
目前仍然稳定，不是急诊濒危状态
↓
需要在有充分准备的情况下进行计划性开胸置换
↓
由于装置特殊、既往接受过心脏手术、胸内存在术后粘连
↓
外院转诊至 Hoshimi
```

不要写成：

```text
她突然因为冠心病需要 CABG
```

这和 19 岁千束的角色背景不自然。
