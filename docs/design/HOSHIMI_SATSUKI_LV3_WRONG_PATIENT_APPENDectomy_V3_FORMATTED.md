# 2. 百合香在星见医院的状态

御统百合香为成年女性。

她因为反复发作的胃十二指肠疾病长期在内科治疗，已经不是第一次住院。

她对星见医院非常熟：

- 知道护士什么时候换班；
- 知道哪顿医院饭最难吃；
- 做过胃镜、抽过很多次血；
- 已经不再把普通检查当回事；
- 和病房护士会互相开玩笑；
- 最大的问题不是害怕医院，而是住得太久以后无聊。

因此当天皐月推着术前准备车出现时，她不会第一时间意识到出了大问题。

她首先会觉得：

> “医院今天又给我安排了什么奇怪项目？”

# 4. WRONG-PATIENT ERROR CHAIN

这次事故不能写成“皐月突然变笨”。

Lv2之后的皐月已经能完成独立转运和交接。

当天真正发生的是一条连续失效链：

1. 原定接受阑尾切除的外科患者临时换床；
2. 内科为了调整床位，把百合香移进原床位；
3. 病区白板已经更新；
4. 纸质转运单仍旧写着旧床号；
5. 原患者的术前资料夹没有及时跟着移动；
6. 两名患者都叫“百合香／ユリカ”；
7. 皐月到床边时依赖床号、资料夹和名字进行确认；
8. 她只问了“百合香小姐？”；
9. 御统百合香当然回答“是”；
10. 皐月没有要求她重新说出完整姓名；
11. 手术部接收时沿用了同一套错误资料；
12. 镇静以后，百合香已经无法再提供足够清晰的信息来打断流程。

事故是系统性的。

但皐月非常清楚：

> 如果自己最后一次完整核对姓名和出生日期，事情仍然可以停下来。

因此她不会把责任完全推给流程。
