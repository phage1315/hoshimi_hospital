# CORE —— 医学伦理悬疑 VN
## 作者内部 Story Bible / 正式设计规格

> **最高注意事项**
>
> 本文件使用“作者上帝视角”编写。
>
> Codex 不得因为读取了本文件，就默认让主角或其他角色知道本文中的真相。
>
> 后续剧情必须严格区分：
>
> 1. 客观真相
> 2. 每个角色知道什么
> 3. 主角知道什么
> 4. 玩家实际看到什么

---

# 1. 项目定位

**类型：** 强剧情日式 Visual Novel × 医学悬疑 × 医疗伦理悲剧  
**基调：** 优美、克制、冷静、令人不安、具有亲密的人物情感  
**核心体验：**

> 玩家逐渐发现，这家医院里最令人不安的事情，恰恰是由真正想救人的人做出来的。

本作不是沙箱。

本作应大幅弱化：

- 自由日程
- 大量随机患者
- 大量手术刷取
- 复杂职业养成
- 多角色自由攻略
- 成人向荒诞系统
- 大量数值优化

重点放在：

- 强节奏叙事
- 信息控制
- 医疗伦理困境
- 少量关键患者
- 少量重要手术
- 人物立场
- 历史真相
- 永久谜团

---

# 2. 核心主题

最核心的问题不是：

> “人体实验是不是邪恶？”

而是：

> **如果一种令人不安、甚至残酷的医疗方式真的能够拯救本来必死的患者，而参与者又是成年人、知情并且自愿，那么“自愿”是否足以洗掉这种手段本身的不正义？**

进一步的问题：

- 临终患者有没有权要求极端实验性治疗？
- 医生有没有权满足这种要求？
- 治疗什么时候变成研究？
- 恐惧、绝望、药物、手术中的压力会不会使“同意”失去自由性？
- 如果违规真的救了人，规则还拥有怎样的道德权威？
- 如果严格遵守规则意味着患者死亡，那么“守规矩”是否真的干净？
- 一个机构能不能依赖医生个人良知运行？
- 如果一个医生的研究依赖有伦理问题的样本，她还能宣称自己站在道德高地吗？
- 一个本来想改革系统的人，从哪一步开始已经成为系统的一部分？

---

# 3. 叙事原则

禁止简单写成：

```text
善良伦理医生
vs
邪恶疯狂科学家
```

真正的结构应是：

> **几乎所有核心人物都希望患者少死。**

她们争论的是：

- 今天允许多少伤害？
- 谁能承担风险？
- 什么叫真正的知情同意？
- 为未来的患者，今天可以牺牲多少？
- 医疗机构可不可以执行一个成年人自愿要求的极端治疗？

任何核心阵营都不能永远正确。

任何核心角色都不能只是哲学观点的传声筒。

---

# 4. 疾病设定

暂定名：

**Core-Dependent Malignancy，核心依赖型恶性肿瘤**

名称以后可以更换。

---

# 5. 非核心病灶

患者体内会出现多个看似普通恶性肿瘤的病灶。

它们：

- 会长大
- 会侵袭
- 病理表现恶性
- 能在影像中出现
- 可以切除

但：

> 切掉 non-core lesion 并不能真正阻止疾病。

其他地方仍会出现新病灶。

早期医学界因此长期误以为：

> 这是一种极端容易转移的恶性肿瘤。

---

# 6. Core

少数患者体内存在一个：

> **Core**

它可能：

- 很小
- 极难辨认
- 外观接近普通组织或普通肿瘤
- 位置不可预测

观察结果：

```text
切除 non-core
→ 疾病继续

正确切除 Core
→ 某些患者出现全身病灶停止增长甚至明显退缩
```

但：

> 切除 Core 不保证百分之百治愈。

必须保留失败可能。

否则实验派在伦理争论中会天然“必然正确”。

---

# 7. Core 的生物通讯

Core 参与一种异常的全身实时通讯网络。

可能涉及：

- nervous signaling
- immune signaling
- endocrine signaling
- tumor-host signaling

具体机制尚未完全理解。

医生真正识别 Core 的依据，不只是“看见一个特殊肿瘤”。

而是在活体条件下：

> 观察某块组织受到刺激、药物、局部血流变化之后，身体其他区域是否产生联动反应。

---

# 8. 为什么尸检无法解决问题

循环停止以后，Core 的特殊活体状态迅速崩溃。

死亡后病理可能只看到：

- 坏死组织
- 普通恶性组织
- 模糊残迹

因此：

> 死后不能可靠判断某块组织究竟是不是 Core。

这也是为什么医学界长期无法通过尸检真正理解疾病。

---

# 9. 全麻为什么成为伦理灾难

深度全身麻醉会抑制：

- 自主神经活动
- 某些应激反应
- 特定神经递质
- Core 与其他病灶之间的动态信号

结果：

> **全麻以后，Core 几乎无法与普通病灶区分。**

因此当前 Core Search 只能在：

- 区域阻滞
- 强镇痛
- 有限镇静
- 保持一定意识与生理反应

的状态下进行。

这不是现实医疗教程，而是本作虚构疾病规则。

---

# 10. 镇静与 Core 信号的核心矛盾

```text
镇静 ↑
患者舒适度 ↑
Core Signal ↓

镇静 ↓
Core Signal ↑
Patient Stress ↑
```

这会成为关键手术的重要 gameplay。

---

# 11. 患者本人的感受会成为数据

由于 Core 通讯与神经系统有关，某些操作过程中患者可能报告：

- 特殊牵涉感
- 温度异常
- 压迫感
- 电击感
- 难以描述的身体联动感

这些主观反应可能帮助定位 Core。

于是患者不只是“接受手术的人”。

她还成为：

> **检测系统的一部分。**

研究派女医可以因此批判：

> “我们已经不是在问她痛不痛。我们是在把她的感受当成仪器读数。”

---

# 12. 为什么 Core Search 可能极其广泛

Core 位置不可预测。

一次手术可能：

```text
先探索腹腔
↓
没有找到
↓
实时信号提示胸腔区域
↓
考虑扩大探查
```

重点不是现实术式细节。

重点是：

> **患者术前同意到底覆盖到哪里？**

如果患者已经：

- 疲劳
- 恐惧
- 用药
- 身处手术过程中

她此时说：

> “继续。”

还算不算真正自由的同意？

---

# 13. 三种 Core 理论

不要彻底解决。

### Theory A
Core 是真正原发肿瘤。

### Theory B
Core 是肿瘤与免疫 / 神经系统共同形成的控制节点。

### Theory C
Core 根本不是传统肿瘤，而是整个疾病网络中的功能节点。

游戏可以证明：

> 切掉某些活体组织确实可能改变整个疾病。

但不一定证明：

> 为什么。

---

# 14. 永久科学谜团

**Core 到底是什么？**

可以永远不完全揭晓。

这是本作三个永久谜团中的第一个。

---

# 15. 研究派的目标

研究派反对 Core Search 成为长期常规治疗。

她们的目标：

## Detection
开发 tracer / imaging 方法，在术前发现 Core。

## Treatment
开发能够直接攻击 Core 的药物。

## Culture
在体外维持 Core 活性并研究其机制。

最终目标：

> **终止 Core Search。**

---

# 16. 最残酷的悖论

研究派要终止 Core Search。

但她们需要：

> **新鲜、活的 Core 样本。**

而这些样本只能来自：

> Core Search。

因此形成：

```text
Core Search
    ↓
Live Core Sample
    ↓
Research
    ↓
未来可能出现非手术检测 / 药物治疗
    ↓
目标：永远终止 Core Search
```

但在突破之前：

```text
更多研究
=
需要更多 Core Search
```

---

# 17. 医院的公开身份

表面上：

> 私立综合医院 + 肿瘤研究中心

公开形象：

- 医术很好
- 医护优秀
- 愿意接收疑难病例
- 某些领域声誉很高

医学界内部却有人称它：

> “那家医院。”

---

# 18. 医院不是器官交易组织

早期剧情可以强烈让主角怀疑：

> 非法器官交易。

但客观真相：

> 完全没有器官买卖。

这些可疑的人体组织运输是：

> Core 样本。

---

# 19. 为什么一切必须秘密进行

Core Search 曾经半公开存在。

重大丑闻之后：

- 伦理审批停止
- 大学撤出
- 基金停止
- 学术合作终止
- 大型医院拒绝参与

但是：

> 病没有消失。

患者仍然存在。

这家医院最终成为：

> 唯一仍偷偷收治这类患者的地方。

---

# 20. 上帝视角历史线

以下年份暂用相对时间。

---

## ~24年前：异常病例出现

院长祖父已经是一名著名外科医生。

数名患者表现出：

```text
切掉一个肿瘤
↓
又长出多个
↓
行为不像普通转移
```

此时没人知道 Core。

---

## ~21年前：Patient Zero Miracle

一名晚期患者接受姑息性大手术。

医生为了处理其他问题，偶然切掉一小块不起眼组织。

术后：

> 其他多个病灶停止增长，部分逐渐退缩。

这是第一次“奇迹”。

---

## ~19年前：第一次主动 Core Search

团队提出：

> 可能存在隐藏的控制病灶。

一名晚期、无其他治疗方案的成年患者自愿接受极端实验手术。

他们第一次有意识寻找 Core。

找到。

切除。

患者长期缓解。

Core Program 正式诞生。

---

# 21. 治疗逐渐变成研究

最早祖父可以诚实地说：

> “我们只是在救没有其他办法的人。”

但为了提高成功率，团队必须研究：

- Core 在哪里
- 怎样辨认
- 怎样判断
- 搜索多久
- 什么时候停

于是每台手术逐渐同时拥有两个目的：

1. 救当前患者
2. 为下一个患者取得知识

两者开始混在一起。

---

# 22. ~14年前：研究最辉煌时期

Core Program 获得有限外部合作。

这一阶段：

- 有成功
- 有失败
- 有死亡
- 有珍贵数据
- 有初步体外培养
- 有越来越多医学争议

一些现今资深角色可能来自这个时期。

---

# 23. ~12年前：Case 17

这是整个历史最重要的事件。

患者：

- 年轻成年女性
- 尚能工作与生活
- 不是马上要死
- 症状不重
- 理论上还有时间

研究数据显示：

> 越早 Core Search，可能越容易找到 Core，治愈机会越高。

她同意手术。

---

# 24. Case 17 手术

手术时间非常长。

Core 没有找到。

患者为了维持 Core Signal，必须保持相当程度的意识和生理反应。

过程中：

- 疲劳
- 恐惧
- 镇痛
- 生理状态恶化

团队仍继续搜索。

患者死亡。

真正的问题：

> **什么时候应该停止？**

---

# 25. Case 17 的锁定黑暗真相

Case 17：

- 没有被绑架
- 没有被强迫
- 确实签署同意
- 确实知道手术高度实验性

但是：

> 她没有得到全部风险信息。

此前至少有两例死亡可能与 prolonged Core Search 有关。

祖父认为：

> 因果尚不明确，不能当成“已确认手术死亡”写进风险说明。

因此：

> 她是自愿的。

但：

> 她是不是“充分知情”，存在严重问题。

---

# 26. 永久历史谜团：到底是谁决定继续？

当 Case 17 状态恶化以后，到底是谁决定继续？

至少存在三种版本。

### Version 1
祖父坚持继续。

### Version 2
患者本人仍明确要求继续。

### Version 3
当时已经没有多少治疗价值，团队为了研究继续探索。

记录互相矛盾。

可以包含：

- 不完整手术记录
- 时间戳冲突
- 护士私人日记
- 片段录音
- 当事人不同回忆

不一定最终给答案。

---

# 27. 为什么主流医学界封杀 Core Search

调查发现：

| 问题 | 真相 |
|---|---|
| 极高风险探索手术 | 是 |
| 既治疗又研究 | 是 |
| 部分死亡资料未完整上报 | 是 |
| 部分 informed consent 有问题 | 是 |
| 同一医生既治疗又研究 | 是 |
| 强迫患者 | 没有证据 |
| 杀人取样 | 否 |
| 器官买卖 | 完全没有 |
| Core 理论纯属骗局 | 也不是 |

因此：

> **停止 Core Search 是可以理解、甚至合理的决定。**

主流医学界不能被写成“愚蠢保守派”。

---

# 28. 第二个伦理灾难

封杀以后：

> 疾病继续存在。

普通医院只能：

```text
切除明显肿瘤
↓
化疗
↓
复发
↓
姑息
```

但过去确实有 Core Search survivor。

因此越来越多患者开始寻找祖父的医院。

---

# 29. 地下化

祖父决定：

> 不停止。

Core Program 转入地下。

可能出现：

- 编码病例
- 私人转诊
- 不进入普通系统的手术安排
- 样本代号
- 私人资金
- 限制区域
- 夜间手术

这些在主角眼里非常像犯罪组织。

---

# 30. 器官交易 Red Herring

早期主角可能看到：

- 身份不明患者
- 深夜入院
- 奇怪手术
- 人体组织运输箱
- “保持活性”
- 特殊资金
- 地下实验室
- 加密病历

合理推测：

> 器官交易。

第一次大反转：

> 不是器官交易，而是活体 Core 样本。

但谜团没有结束。

新的问题：

> 这些样本到底是怎么得到的？

---

# 31. 祖父晚年

不能写成单纯疯掉。

他的笔记应该互相矛盾。

例如：

> “成年人如果理解风险，我们没有资格替他拒绝。”

另一方面：

> “我们可能忘了医生首先面对的是眼前这个人。”

又可能：

> “如果另一种方法出现，Core Search 必须结束。”

因此不同阵营都能引用他的文字支持自己。

---

# 32. 永久人性谜团

**祖父最后到底后不后悔？**

不完全回答。

这是第三个永久谜团。

---

# 33. ~3年前：年轻女院长继承医院

祖父去世。

年轻孙女继承：

- 医院
- 员工
- 债务
- 名誉
- Core Program
- 秘密患者网络
- 数十年数据

她最初的第一反应：

> **停止 Core Program。**

这一点必须保留。

---

# 34. 院长第一次妥协

暂停项目后，一名晚期患者来到医院。

其他机构全部拒绝。

患者了解 Core Search，并明确请求。

院长拒绝。

患者快速恶化。

某个紧急情况下，Core 团队最终进行了手术。

找到 Core。

患者活下来。

这成为年轻院长的：

> **原罪。**

从那以后，她批准项目恢复。

---

# 35. 年轻院长的规则

她为了证明自己不同于祖父时代，制定：

- 只接受成年人
- 必须具备判断能力
- 必须明确告知非标准治疗
- 可撤回
- 手术必须有潜在治疗价值
- 团队核心成员可以要求停止
- 成功失败都必须记录
- 扩大术式前必须重新确认患者意愿

她相信：

> “我们和过去不同。”

剧情最终要问：

> **真的不同吗？**

---

# 36. 核心人物：实验派外科女医

她代表：

> **今天正在死的患者。**

她相信：

> Core Search 很残酷。

但：

> 这是目前唯一真实出现过长期治愈 / 缓解的办法。

她的核心论点：

> “你的药五年以后也许能救人，但我的患者可能活不到五个月。”

她必须：

- 技术极强
- 冷静
- 尊重患者
- 不享受痛苦
- 会拒绝不适合手术的人
- 真心把自己当临床医生

她不是疯科学家。

她的危险就在于：

> 她非常有道理。

---

# 37. 核心人物：研究派女医

她反对 Core Search 成为常规治疗。

她希望：

- 术前发现 Core
- 用 tracer 标记 Core
- 用药物杀死 Core
- 体外培养 Core

最终目标：

> 让未来患者永远不需要接受这种手术。

但她的实验室依赖：

> 外科团队送来的活体 Core。

所以她也不是干净的。

重要角色节点可以是：

> 她第一次主动要求手术团队“多取一点组织”。

说完以后，她意识到：

> 自己跨过了过去谴责别人跨过的线。

---

# 38. 两名女医的关系

她们的终点其实一致：

> **终止这种残酷治疗。**

区别：

### 外科女医
今天先救人。

### 研究女医
必须尽快创造不需要这种手术的未来。

她们互相需要。

可以有：

> “在你的药出来之前，这些患者还是需要我。”

以及：

> “我的研究存在的唯一目的，就是有一天不再需要你这样做。”

---

# 39. 核心人物：年轻女院长

她代表：

> **机构责任。**

个人医生可以说：

> “我承担。”

但院长必须问：

> “医院能不能靠个人良知来运行？”

她既不是实验派，也不是纯反对派。

她是：

> 继承者、管理者、共犯、改革者。

---

# 40. 核心人物：资深护士

几乎必须存在。

她代表：

- 患者真正经历了什么
- 手术室里的现实感
- 医生记录之外的记忆
- Case 17 的另一种历史

医生讨论：

> 数据。

护士看到：

> 人。

她可能掌握医生没有的细节。

---

# 41. 核心人物：麻醉 / 患者舒适与安全医生

由于全麻会破坏 Core Signal，这个角色的重要性大幅上升。

她长期面对：

```text
让患者舒服一点
vs
保留 Core Signal
```

她也最容易质疑：

> 手术中的患者说“继续”，到底有没有足够自由意志？

她可以提出：

> “能回答问题，不等于真正能自由做决定。”

---

# 42. 必要患者：Miracle Survivor

一名长期 Core Search 幸存者。

功能：

> 证明这套体系真的救过人。

她不能简单成为实验派宣传角色。

她可以同时说：

> “他们救了我。”

又说：

> “救了我，不代表后来的一切都正确。”

---

# 43. 必要患者：Terminal Volunteer

一名当前晚期患者。

必须明确：

- 成年
- 判断能力完整
- 风险已知
- 没有经济胁迫
- 没有精神问题
- 没有隐藏骗局

她就是：

> **真正自愿。**

用来堵住玩家最容易的逃路：

> “那些患者其实都是被逼的。”

不是。

她真的自愿。

---

# 44. 必要患者：Early-Stage Patient

她可能是全游戏最重要患者之一。

她：

- 看起来健康
- 还能正常生活
- 并不马上死亡

但医学模型提示：

> 越早 Core Search，治愈机会可能越高。

于是医院第一次必须讨论：

> 要不要给一个“现在看起来没那么严重”的人做极大手术？

这就是：

> **“不必要的手术”**

最强体现。

---

# 45. 必要人物矩阵

| 人物功能 | 必要性 |
|---|---|
| 主角 | 绝对必须 |
| 年轻女院长 | 绝对必须 |
| 实验派外科女医 | 绝对必须 |
| 研究派女医 | 绝对必须 |
| 资深护士 | 几乎必须 |
| 麻醉 / 安全医生 | 强烈建议 |
| Miracle Survivor | 必须 |
| Terminal Volunteer | 必须 |
| Early-Stage Patient | 必须 |
| Case 17 | 必须，但可仅存在于历史 |
| 外部调查者 | 后期大概率需要 |
| 病理 / 实验室负责人 | 有用，可与研究女医合并 |

| 记者 | 可删 |
| 医院律师 | 可删 |
| 董事代表 | 可删 |

---

# 46. 信息必须分层

每个重要秘密都建议使用：

```yaml
truth:
hidden:
disputed:
false_belief:
```

例如：

```yaml
case17:
  signed_consent:
    truth: true

  fully_informed:
    truth: false

  requested_continuation:
    truth: unknown

  grandfather_forced_continuation:
    truth: disputed
```

---

# 47. 四层知识结构

任何重要事实都必须区分：

## Layer 1 — Objective Truth
作者知道的客观真相。

## Layer 2 — Character Knowledge
每个角色知道、误解、怀疑、隐瞒的内容。

## Layer 3 — Protagonist Knowledge
主角当前真正知道什么。

## Layer 4 — Player Knowledge
玩家在当前周目实际看到什么。

严禁混淆。

---

# 48. 人物认知地图

每名核心角色以后都应有：

```yaml
character:
  knows:
  suspects:
  misunderstands:
  deliberately_hides:
  does_not_know:
```

误导应优先来自：

> **不完整的真话。**

而不是：

> 每个人都为了剧情方便故意撒谎。

---

# 49. Reveal Ledger

每个秘密要记录：

| 信息 | 首次暗示 | 开始怀疑 | 部分揭晓 | 完全揭晓 |
|---|---|---|---|---|
| 地下研究存在 | Act I | Act I | Act II | Act II |
| 器官买卖为误判 | Act I | Act I | Act II | Act II |
| Core 存在 | Act I | Act II | Act II | Act II |
| 全麻/Core Signal 问题 | Act I病历 | Act II | Act II/III | Act III |
| Case 17 | Act II | Act III | Act III | 路线相关 |
| 祖父责任 | Act II | Act III | Act IV | 永久不完全明确 |
| Core 真机制 | Act I | Act II | Act IV | 永远不完全解答 |

具体章节号以后确定。

---

# 50. 永久谜团

至少保留：

## 科学谜团
Core 到底是什么？

## 历史谜团
Case 17 最后到底是谁真正决定继续？

## 人性谜团
祖父最后是否后悔？

三者分别对应：

```text
Science
History
Human Nature
```

---

# 51. 主角不是完全自由 Avatar

固定必须发生：

- 进入医院
- 发现异常
- 接触 Core 患者
- 知道 Core 真相
- 参与 Core 相关治疗
- 得知旧丑闻
- 发现研究派也依赖伦理有问题的样本
- 发现自己已经无法保持旁观者身份
- 最终必须面对医院未来

玩家塑造的是：

> 主角如何理解、评价、承担这些事情。

---

# 52. 玩家选择比例

建议：

```text
70–85% 固定强剧情
10–20% 态度 / 信息 / 信任变化
5–10% 真正改变命运的关键选择
```

不要每五分钟弹出一次：

```text
善良
中立
邪恶
```

少量重要选择才有重量。

---

# 53. 不建议使用 Good / Evil

若需要属性，更适合：

- `PatientAutonomy`
- `ClinicalCaution`
- `ScientificAmbition`
- `InstitutionalLoyalty`
- `Transparency`
- `PersonalAttachment`

这些主要影响：

- 主角台词
- 他人对主角的评价
- 可获得信息
- 少量特殊选项
- 最终路线倾向

不应让整章内容因为数值不同而消失。

---

# 54. Act I —— 美丽的医院

目的：

- 建立普通医院日常
- 让玩家喜欢这里
- 认识重要角色
- 感受这里的人真的在救人

轻微异常：

- 奇怪病历
- 限制区域
- 深夜入院
- 特殊组织运输
- 异常麻醉记录
- 不存在的病房或手术编号

主角可能怀疑：

> 器官交易。

---

# 55. Act II —— 秘密真的能救人

主角逐渐知道：

- Core 存在
- 特殊患者存在
- 样本研究存在
- Core Search 有时真的有效

第一场真正让玩家理解 Core Search 的病例，最好：

> 成功，或至少产生明确治疗价值。

目的：

> 不能让玩家太轻松地得出“这都是邪恶疯子”。

玩家第一次意识到：

> 医院可能正在用违规手段做善良的事。

---

# 56. Act III —— “自愿”开始裂开

主角发现：

- 历史患者并非都得到完整信息
- 治疗与研究长期混合
- Case 17 存在
- 研究派依赖 Core Search 样本
- 全麻/Core Signal 的真正含义
- 手术中的“继续”并不一定等于真正自由

主角也开始：

> 亲自参与无法完全洗白的决定。

---

# 57. Act IV —— 医院无法继续隐藏

外部压力出现：

- 调查
- 泄漏
- 死亡
- 内部举报
- 科研重大突破
- 机构危机

与此同时：

> 研究可能真的接近结束 Core Search。

最终问题：

> **这套体系还有没有继续存在的资格？**

---

# 58. 结局方向

不叫 Good / Bad。

---

## Truth / Exposure

秘密曝光，地下项目停止。

代价：

- 研究暂停
- 患者失去治疗机会
- 医院崩溃

价值：

- 透明
- 责任

---

## Continuation

Core Search 继续。

价值：

- 当前患者继续有机会

代价：

- 秘密仍存在
- 伦理问题继续
- 主角彻底成为体系一部分

---

## Destruction

主角主动摧毁项目与资料。

价值：

- 彻底终止不正义体系

代价：

- 可能摧毁真正接近成功的医学成果

---

## Reform / Possible True Route

不是完美折中。

可能需要：

- 公开历史死亡
- 院长辞职
- 外部审查
- 暂停项目
- 数据上交
- 医师处罚
- 独立伦理监督
- 研究以后在合法结构下恢复

这条路线必须付出真实代价。

不能是：

> “大家坐下来沟通以后全部圆满解决。”

---

# 59. “最后一次 Core Search”

可以作为全作最重要的象征目标：

> **让最后一台 Core Search 真正成为最后一台。**

实验派：

> 先救今天的人。

研究派：

> 让未来的人不再受这种手术。

院长：

> 找到一个机构能够承担的合法未来。

最终可能面对：

> “我们是不是还要再做最后一次？”

---

# 60. 最终私人化的伦理冲突

可考虑：

某个与主角关系非常深的人：

- 成年
- 完全知情
- 主动要求
- 具备明确医学适应症

她请求接受 Core Search。

于是抽象问题变成：

> “你过去认为别人有权承担这种风险。”

现在：

> “如果是你爱的人呢？”

使用时要克制，避免单纯煽情。

---

# 61. CORE 的手术玩法

CORE 不需要庞大的可重复手术系统。

大部分普通医疗可以叙事化。

只有少量关键手术进入互动状态。

可使用：

```text
PatientStability
CoreSignal
Sedation
PatientStress
SearchProgress
TeamConfidence
ElapsedTime
```

关键选择：

- 增加镇静
- 保持信号
- 继续搜索
- 停止
- 询问患者是否继续
- 相信某位医生
- 扩大原计划范围

因为少见，所以每次互动都应该有重量。

---

# 62. CORE 的人物关系

不做沙箱式攻略。

不做自由刷 Rank。

关系主要通过主线自然发展。

可以保留非常轻量：

> `Trust / Information Access`

影响：

- 是否告诉主角某段过去
- 是否给旧病历
- 是否相信主角
- 是否提供 Case 17 的另一个版本

单周目不必获得所有真相。

---

# 63. 患者数量

核心患者不应很多。

建议：

> 8–12 名重要患者。

每个人必须承担：

- 主题功能
- 信息功能
- 人物功能
- 医疗功能

普通患者可以少量出现，用来维持正常医院感。

---

# 64. 时间结构

CORE 的时间不是资源。

时间是：

> **叙事工具。**

不必每天都显示。

可以：

```text
April 7
↓
April 12
↓
April 26
↓
May 3
```

中间普通工作一句带过。

只保留：

> 有故事价值的日子。

---

# 65. 基调

CORE 应该：

- 克制
- 冷
- 安静
- 美
- 越来越不安
- 重视人物心理
- 避免廉价血腥冲击
- 避免不停反转
- 避免阴谋无限升级

真正的恐怖来自：

> **有同情心、有能力、真心想救人的人，做出了自己能够认真辩护的可怕选择。**

---

# 66. 美术方向

建议：

- 较冷色调
- 医院空间更空
- 夜间氛围重要
- CG数量少，但每张有叙事价值
- 医疗服装更统一真实
- 手术场景重视构图、声音、对白、患者反应
- 地下区域不画成俗套邪恶实验室

同一医院：

```text
白天：
干净、专业、温暖

夜晚：
安静、限制、模糊、不安
```

---

# 67. Codex 编写剧情时的硬约束

1. 不得因为读取本 Story Bible 而让主角提前知道真相。
2. 写任何秘密相关场景前先检查 Reveal Ledger。
3. 每个核心人物必须有独立 Knowledge Map。
4. 永久谜团不得被随意对话解决。
5. 争议历史不得被 Casual Dialogue 直接定论。
6. 不把任何核心人物写成单纯立场工具。
7. 医学机制服务叙事，不写成现实医疗教学。
8. 不因为底层引擎支持沙箱系统，就把沙箱机制带入 CORE。
9. 普通患者和普通手术应简化。
10. 强剧情节奏优先于自由度。

---

# 68. 一句话设计法则

> **CORE 讲的是一群真正想救人的人，为了拯救患者而逐渐做出连自己都无法完全证明正当的事情；而主角最终发现，知道全部真相并不会让选择变容易。**
