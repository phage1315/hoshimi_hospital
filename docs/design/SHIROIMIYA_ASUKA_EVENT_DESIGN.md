# Hoshimi Hospital — 城宮明日香事件设计规格
## Codex 实现用 MD

> 角色：城宮明日香（Shiromiya Asuka / 城宮明日香）  
> 项目：Hoshimi Hospital  
> 定位：年轻院长 / 年轻外科医生 / 医院继承人  
> 本文用于事件、解锁逻辑、关系成长和手术互动的实现。  
> 本文中的角色设定为本项目的平行世界重构，不要求与原作剧情逐项一致。

---

# 1. 角色核心

城宮明日香是医院现任院长。

她非常年轻，医大毕业、取得医师执照不到一年，但因为家族与医院继承关系，在父亲退出管理后提前接任院长。

她不是“没有经验的吉祥物院长”。

她从医学生时期开始就长期在医院活动：

```text
长期观摩手术
参与允许医学生承担的辅助工作
毕业前已经非常熟悉OR流程
取得执照后才开始真正作为医生承担主刀病例
```

所以她的能力结构应表现为：

```text
Medical Knowledge      很高
OR Familiarity         很高
Assistant Surgery      很高
Teamwork               很高
Independent Surgery    中等 / 经验偏少
Administration         很高
Leadership             高，但仍在成长
```

她非常清楚：

> “看过很多台、做过很多次助手”与“自己作为主刀承担责任”不是一回事。

这应成为她职业成长线的重要主题。

---

# 2. 性格

核心关键词：

```text
年轻
娇小
礼貌
聪明
有少女感
好学
亲切
坚定
不容易被操纵
```

她不是冰山型院长，也不靠大声训人建立权威。

她通常：

```text
说话柔和
态度友好
容易微笑
不会摆大小姐架子
对年轻医护很有耐心
```

但一旦涉及正式决策，她的边界非常清楚。

典型权威表达：

```text
“我明白你的意见了。不过这件事已经决定了。”

“我说，已经决定了。”
```

重点：

> 她可以很好说话，但绝不是好欺负。

---

# 3. 医院理念

明日香希望把医院建设成一个更愿意培养女性医护、尤其是年轻女性医生与护士的环境。

她的理念不是“只招女性”，而是：

```text
让过去容易被低估的年轻女性医护，获得真实的训练机会、手术机会、带队机会和晋升机会。
```

推荐对白：

```text
“医学院里女生一点也不少。”

“可越往外科、管理层、主任的位置走，人就越来越少。”

“有能力的人不应该因为二十五岁、三十岁以后可能结婚、生孩子，就在二十三岁的时候先被判断‘不值得培养’。”

“如果别人不愿意给她们第一台手术、第一次带队、第一次独立处理患者的机会——那我们给。”
```

这个理念同时解释：

```text
为什么医院里年轻女医生较多
为什么年轻女护士较多
为什么医院愿意让年轻医生实际参与高强度医疗工作
```

---

# 4. 玩家首次状态

游戏开始时：

```text
院长办公室不可正常拜访
```

显示方式可以是：

```text
院长办公室
[现在似乎没人]
```

或直接暂时锁定。

在认识明日香之前，玩家不应该在普通地图事件中直接见到她。

---

# 5. 相识事件触发方式

相识事件不在院长办公室发生，而是在：

```text
手术前 → 更衣 / 刷手流程 → 选择“刷手准备”
```

触发。

推荐最低条件：

```text
未认识明日香
Completed Surgeries >= 2
OR Professional Reputation >= 5
```

第一版可以用简单伪随机：

```text
第一次满足条件后的刷手：30%
第二次：60%
第三次：100%
```

Charm 可作为未来附加修正，不建议作为唯一门槛。

原因：

> 明日香首先注意的是一个在医院里真正做事的医生，而不是单纯“魅力高的人”。

# 6. 相识事件 01：《刷手池边的女孩》

## 6.1 场景

```text
location: scrub_area
background: scrub_sink
outfit: scrubs + cap + mask_preparation_state
```

玩家进入刷手池时，看见一名漂亮、娇小、看起来非常年轻的女性正在刷手。

因为：

```text
年轻
娇小
没有白大褂
处于手术区
```

玩家在心里自然先猜她可能是护士。

重要：

> 玩家不要直接称呼她“护士小姐”。

这样避免把主角写得没礼貌。

---

## 6.2 第一印象

叙述建议：

```text
她刷手动作非常熟练。
没有多余停顿，对无菌边界的习惯不像第一次进OR的人。
```

主角内心：

```text
“这么年轻……但动作不像新人。”
```

---

## 6.3 推荐对白节奏

### Opening

玩家：

```text
“辛苦了。你也准备上台？”
```

明日香：

```text
“嗯。隔壁那台。”
```

玩家：

```text
“今天手术室挺忙。”
```

明日香：

```text
“忙一点总比病床一直空着好吧。”
```

语气轻松、有少女感。

---

## 6.4 医学知识伏笔

如果玩家提到自己今天的术式，明日香可以非常自然地接话。

例如：

```text
“那个术式后半段如果暴露不好，会比前面更费时间吧。”
```

玩家：

```text
“你常跟这种台？”
```

明日香：

```text
“以前看过很多次，也帮过不少次。”
```

她没有撒谎，但也没有主动解释自己的身份。

---

## 6.5 一个小伏笔

刷手结束前：

```text
“那，坂口医生，手术顺利。”
```

玩家此时可能没有注意：

> 自己没有正式向她做过自我介绍。

这意味着她其实已经知道主角是谁。

不要额外强调，让玩家自己发现。

---

## 6.6 事件结束

设置：

```text
flag: met_asuka_scrub_sink
flag: asuka_identity_unknown
```

事件结束后：

```text
自动完成本次 scrub_hands
hands_ready = true
```

不要要求玩家再点一次刷手。

# 7. 相识事件 02：《隔壁那台》

## 7.1 触发

当前手术完成后自动触发。

地点：

```text
OR corridor / postoperative transition
```

人物：

```text
player
OR head nurse / senior OR nurse
```

---

## 7.2 对话目标

玩家询问：

```text
“刚才刷手池那个年轻护士，是新来的？”
```

护士长：

```text
“年轻护士？”
```

玩家简单描述。

护士长：

```text
“我们今天那边没有新人啊。”
```

玩家：

```text
“她说自己是隔壁那台的。”
```

护士长停顿。

```text
“隔壁？”
```

然后：

```text
“那台今天是院长亲自上的。”
```

玩家：

```text
“……院长？”
```

护士长此时才意识到：

```text
“等等，你还没见过院长？”
```

最后：

```text
“明天去院长办公室正式拜访一下吧。”
```

## 7.3 事件结果

设置：

```text

```

```text

```

# 8. 相识事件 03：《院长室里的她》

## 8.1 场景

第二天首次进入院长办公室触发。

画面：

```text
昨天刷手池里的年轻女性
坐在明显偏大的院长办公桌后
```

视觉反差必须强。

---

## 8.2 开场

明日香先自然地说：

```text
“啊，坂口医生。昨天的手术顺利吗？”
```

玩家：

```text
“……院长？”
```

明日香：

```text
“嗯？”
```

玩家：

```text
“你是院长？”
```

明日香笑：

```text
“护士长没告诉你吗？”
```

玩家承认自己昨天一直以为她是手术室护士。

明日香不是生气，而是真的觉得有趣：

```text
“这样啊。”

“难怪昨天你一直用那种语气跟我说话。”
```

玩家：

```text
“什么语气？”
```

明日香：

```text
“就是很普通的同事语气。”

“我挺喜欢的。”
```

---

# 9. 必须立刻展示院长权威

这个事件不能只停留在“可爱的年轻院长”。

明日香随后拿出玩家最近的病例 / 手术记录。

推荐：

```text
“不过昨天那台，我看过记录了。”
```

然后根据实际游戏数据动态插入一句。

例如：

```text
手术成功但术前超时
→ “手术本身没有问题。不过术前准备比预定多花了十二分钟。”

患者体验很低
→ “技术结果不错，但患者体验评分很低。”

选择过于激进
→ “你推进得很快。不过有两次其实已经接近不必要的风险。”
```

最后：

```text
“这些我不会因为手术做得漂亮就不管。”
```

她仍然保持温和语气。

目的：

> 玩家马上理解：她真的在管理医院。

# 11. 初始关系印象

建议：

```text
Trust       低-中
Affection   低
Respect     中
Familiarity 低
```

她不会因为玩家“不认识院长”而扣好感。

相反，如果玩家第一次见面时：

```text
礼貌
自然
没有因她看起来年轻而轻视她
```

应得到小幅正向印象。

---

# 12. 明日香的关系线主题

她的关系路线不应只是一条恋爱线。

核心主题：

> **两个人一起成长为可以真正承担医院未来的人。**

玩家成长：

```text
医生
→ 熟练主刀
→ 团队核心
→ 医院管理候选
```

明日香成长：

```text
年轻院长
+ 高理论 / 高助手能力
→ 累积主刀经验
→ 真正独当一面的外科医生
```

两条线应互相见证。

---

# 13. 关系阶段建议

## Lv0 — 相识

三段事件：

```text
刷手池偶遇
→ 护士长揭底
→ 院长办公室正式认识
```

解锁：

```text
院长办公室
明日香普通地图事件
明日香可逐步加入手术团队
```

---

## Lv1 — 《院长的第一助手》

推荐主题：

> 明日香作为玩家的第一助手。

玩家第一次真正发现：

```text
她的助手能力远高于她看起来的资历
对OR流程极熟
预判能力好
理论很扎实
```

但她不抢主刀。

推荐代表台词：

```text
“我来保持术野，你按自己的节奏做。”
```

完成后，玩家会开始重新评价她的职业能力。

---

## Lv2 — 《这次换我主刀》

明日香第一次作为主要剧情事件里的主刀。

玩家做第一助手。

她的表现应是：

```text
技术上大体正确
动作不慌乱
但明显更谨慎
关键步骤确认较多
复杂局面处理速度不如御堂
```

代表对白：

玩家：

```text
“院长也会紧张？”
```

明日香：

```text
“院长不会。”
```

停顿。

```text
“主刀会。”
```

这是角色代表句之一。

---

## Lv3 — 《为什么是年轻女人》

用于解释她的医院理念。

场景可在：

```text
院长办公室
屋顶
手术后休息室
```

她解释：

```text
自己为什么愿意大量培养年轻女医生与护士
为什么愿意让年轻人真正上台
为什么她不接受“因为年轻所以先别给机会”的逻辑
```

同时第一次谈到自己接任院长时受到的质疑。

她可以说：

```text
“他们说我太年轻。”

“这句话有一半是对的。”

“所以不知道的事情，我会承认不知道。”

“但不知道，不等于别人可以替我做决定。”
```

---

## Lv4 — 《真正困难的一台》

两人共同完成一次高难度手术。

可以设计：

```text
复杂病例 Modifier
至少一个非预期情况
明日香主刀或共同主导
玩家作为关键助手
```

重点：

> 她不再需要玩家频繁兜底。

玩家真正见证：

```text
她已经从“年轻、聪明、经验少”成长为能够独立承担高风险手术的人。
```

关系层面开始进入明显私人亲密阶段。

---

## Lv5 — 《医院的未来》

终局级角色事件。

主题不是简单“恋爱告白”，而是：

> 两个人开始讨论医院未来。

根据玩家职业路线，可产生不同方向：

```text
玩家继续做纯临床核心
玩家成为外科主任候选
玩家进入医院管理层
玩家成为院长最信任的临床搭档
```

如果进入恋爱结局，仍然应保留：

> 明日香不是把医院交给玩家，而是邀请玩家一起承担它。

# 14. 手术团队中的 Gameplay 定位

建议后台倾向：

```text
Medical Knowledge       92
Assistant Skill         85
Observation             85
Technical Judgment      82
Procedure Familiarity   75–90（按领域）
Intervention Skill      75
Independent Surgery     58–70（随成长提升）
Teamwork                88
Leadership              80
Administration          95
```

数字仅作为方向，不要求硬编码。

核心区别：

> 她“知道”通常比她“独立做过”更多。

---

# 15. 明日香作为助手时的互动风格

## 低关系

```text
礼貌
专业
略保守
很少主动调侃
```

## 中关系

```text
更敢主动提醒
会提出不同意见
开始有轻松吐槽
```

## 高关系

```text
非常了解主角节奏
主角未开口时就能预判需求
愿意公开指出主角的错误
私下语气更少女、更亲近
```

重要：

> 高关系提升的是沟通主动性与默契，不是让她技能凭空暴涨。

---

# 16. 明日香作为主刀时的互动风格

早期：

```text
确认较多
节奏偏稳
理论判断可靠
遇到非预期时会明显思考
```

中期：

```text
确认减少
节奏更自然
能独立处理常见变化
```

后期：

```text
可以承担大型手术
仍然不会假装自己什么都懂
必要时会主动让御堂等更资深医生主刀
```

这一点非常重要：

> 知道什么时候应该让更合适的人主刀，也是她领导能力的一部分。

---

# 17. 与御堂江美子的对照

## 御堂

```text
顶级外科技术权威
主刀经验极强
判断快速
对技术要求高
```

## 明日香

```text
理论强
助手经验丰富
行政能力强
独立主刀经验仍在成长
```

御堂可以对明日香评价：

```text
“知识够了，手也不差。”

“但是主刀经验不是站在旁边看一千台就能得到的。”
```

明日香：

```text
“我知道。”
```

两人不是简单竞争关系。

---

# 18. 与杉村弘子的互动潜力

弘子可以天然成为：

```text
年轻院长与护理团队之间的桥梁
```

明日香尊重弘子的临床经验。

弘子也不会因为她是院长就盲目顺从。

适合出现：

```text
明日香提出新制度
弘子指出实际病房负担
两人讨论后修改
```

这样可以表现：

> 明日香虽然年轻，但愿意听真正懂一线的人。

---

# 19. 与飯村真奈美的互动潜力

飯村可以对明日香的年轻院长身份保持：

```text
尊重
但经常吐槽医院越来越离谱
```

例如：

```text
“院长，你知道我只是药剂师吧？”

“知道呀。”

“那为什么手术助手名单里还有我的名字？”
```

适合喜剧互动。

# 24. 角色设计底线

必须避免：

