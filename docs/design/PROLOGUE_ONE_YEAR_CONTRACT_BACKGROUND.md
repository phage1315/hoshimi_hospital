# Hoshimi Hospital 序章背景补充
## Codex 实现规格

> 目标：在当前“初到星见”序章中，简洁补充主角的职业背景。  
> 不要把开场写成长篇履历说明。  
> 详细背景留到主角办公室里的可回顾内容中。

---

# 1. 序章新增背景

当前开场保留原有春日医院走廊画面。

在“今天，是坂口隆司作为外科医生在这里工作的第一天”这一段前后，加入以下 3–4 个旁白框。

## Prologue Text

### P01

海外研修结束后，坂口隆司原本并没有打算立刻决定自己的下一站。

以他的履历，他还有不少更显眼的选择。

### P02

最后让他来到星见医院的，是医学院时代导师的一句推荐。

「如果还没决定去哪，就到这里试试看吧。」

### P03

坂口最终只签了一份为期一年的合同。

对他而言，星见暂时只是回国后的落脚点。

### P04

今天，是他在这里工作的第一天。

---

# 2. 叙事要求

开场只需要让玩家知道四件事：

```text
1. 主角刚结束海外研修
2. 主角履历不错，本来还有其他选择
3. 星见医院是医学院原导师特别推荐的
4. 主角只签了一年合同，目前把这里视为暂时落脚点
```

不要在序章继续展开：

```text
导师为什么推荐这里
主角具体海外经历
主角拒绝了哪些医院
导师与星见医院的关系
主角年末是否会留下
```

这些全部留给后续办公室回顾内容。

---

# 3. 办公室回顾内容预留

在未来的 `player_office` 系统中预留一个可查看项目：

```text
mentor_recommendation_letter
```

显示名建议：

```text
导师的推荐信
```

玩家查看后，可以触发更详细的回忆事件。

该回忆事件以后再实现，本轮只需要预留 ID / flag。

---

# 4. 推荐信的长期叙事作用

未来可根据游戏阶段改变说明文字。

## 开局

```text
一封导师写给星见医院的推荐信。
当时你并不明白，他为什么偏偏推荐这里。
```

## 中期

```text
你已经很久没有重新看过这封信。
```

## 年末

```text
「如果还没决定去哪，就到这里试试看吧。」

当时你以为，他说的是“试一年”。
```

此处用于呼应游戏总主题：

> **本来只准备待一年，最后发现这里已经成为自己可以贡献力量的地方。**

---

# 5. 实现要求

1. 不改变现有序章场景背景。
2. 不新增复杂 UI。
3. 只需要把 P01–P04 插入当前序章对白流。
4. 每段控制在一个 VN 对话框能舒适阅读的长度。
5. 保持当前“春日、清爽、第一天上班”的氛围。
6. 不提前煽情。
7. 不提前暗示主角一定会留下。
8. 为未来办公室系统预留：
   - `mentor_recommendation_letter`
   - `office_has_mentor_letter = true`
9. 若项目已有文档/收藏系统，优先接入现有结构，不新造重复系统。

---

# 6. 主题

序章时玩家应该感受到：

> **“这里目前只是主角的一年期落脚点。”**

年末时再通过人物关系、病例、办公室物品和医院生活，让这句话自然发生变化。
