# 6.1 真正胃部患者 — 事件用变体资源

本事件新增一名**无长期路线的成年女性患者**：

```yaml
actor_id: guest_true_gastric_patient
adult: true
role_type: event_only_patient
persistent: false
```

她就是原本应该接受深山这台胃部教学手术的人。

最低美术需求：

```text
患者袍
弹性手术帽，所有头发收入
光脚
惊恐 / 快哭出来 / 慌张
从 OR 门口往外跑的动态立绘或事件差分
```

制作要求：

> **可以直接以彩子的“患者袍 + 手术帽”服装构图为基础做变体，但人物必须明显不同。**

也就是说：

- 患者袍式样可以一样；
- 手术帽可以一样；
- 身高、体型可以接近；
- 年龄也可以接近；

但：

- 脸不同；
- 发色 / 五官不同；
- 神态完全不同；
- 彩子是“兴奋取材 / 好奇”，真患者是“临上台崩溃 / 惊恐逃跑”。

她的作用是：

> **让工作人员在强烈的“刚刚跑掉一个患者”心理预设下，把彩子错认成同一个人。**

不需要为她制作：

- 常服；
- Lv 系统；
- relationship；
- 后续角色线。

## CG 03 — 《采访怎么躺上手术台了》

彩子已经躺在 OR table，在无影灯下，手术帽戴好，神情从好奇逐渐变成困惑。

### CG 03A／03B — 《真的下刀了》

使用同一构图的两帧医学近景差分：

1. 无菌洞巾中央露出已经消毒的白皙腹部，深山一手稳定皮肤，另一手持手术刀，刀尖刚接触完整皮肤；
2. 第一刀完成，原构图只增加一道短而浅的线状切口和少量血珠。

采用极近术野构图：洞巾开口逆时针旋转约 45°，身体纵轴在屏幕上由左上通向右下，手术刀与切口沿肚脐至下腹的纵向中线排列。洞巾、动画化的白皙腹部、两只手套与刀尖填满画面，不显示铺巾下的胸廓、骨盆、整张手术台或其他身材比例线索。镜头也不出现人物面部、胸部、下体，不展示深层组织或器官。第一帧绑定 Scene 11 器械递入，第二帧绑定 Scene 12 第一刀落下。

---

## CG 04 — 《病灶呢？》

采用坂口站在第一助手位的低机位主观视角。

- 深山位于手术台对侧，俯身观察无影灯下的术野；
- 七瀬恋站在深山侧后方，同样焦急地向下确认；
- 两人均穿完整无菌手术服，使用后脑系带式手术口罩；
- 画面下沿只出现抬高的蓝绿色无菌单和模糊的手术台边缘；
- 患者身体、切口、器官、血液与器械接触处全部不入镜。

视觉重点是两人突然意识到病例与眼前情况对不上。开放腹腔的事实继续由前后对白建立，CG 本身保持完全 SFW。

彩子坐起一点，一只手护着腹部，另一只手疯狂在速写本上记录。

## Scene 18 设计重点

本版的决定性证据不是：

> “排班时间看错了。”

而是：

> **真正应该躺在手术台上的患者本人，被医院另一处找到了。**

这使错误变得非常具象。

旧版的“时间异常”可以保留到事后复盘里作为辅助线索，例如：

> 某些时间戳与患者真实转运记录并不吻合。

但不再承担主要剧情功能。

# 44.1 责任归属说明

本事件后续复盘时，必须避免把七瀬恋和朝倉美幸写成“粗心导致开错人”的责任核心。

## 七瀬恋

她的现场判断依据：

```text
刚刚确有一名同龄女患者从 OR 区域逃跑
+
数分钟后彩子穿着相同患者袍 / 手术帽 / 光脚出现在附近
+
彩子身上有完全匹配原患者身份的有效腕带
+
彩子在镇静前没有明确否认身份
```

因此：

> **恋的最初误认在现场语境中有充分理由。**

她事后可以自责：

> 「我应该对那句‘我是来参观的’多问一句。」

但那句话出现时：

> 彩子已经明显处于镇静影响中。

所以制度整改重点应是：

> **异常身份陈述必须使用独立来源重新核验。**

而不是：

> **处分恋。**

## 朝倉美幸

朝倉作为 scrub / instrument nurse 接手时：

- 患者已由上游建立身份；
- 腕带、病例、术式和 OR 信息一致；
- 她负责的是无菌侧与器械工作。

因此：

> **朝倉基本没有个人责任。**

她可以参与事故复盘，但不应被写成责任人。

## 深山与坂口

两人承担：

> **作为术者没有发现身份链源头已经被污染的系统性责任与职业反思。**

但不能写成：

> “他们连患者是谁都懒得看。”

整个事件的核心应该始终是：

> **所有人认真核对了很多次，但实际上一直在核对同一个已经被污染的身份来源。**
