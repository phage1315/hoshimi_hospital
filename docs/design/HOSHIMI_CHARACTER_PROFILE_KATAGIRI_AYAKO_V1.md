# HOSHIMI_CHARACTER_PROFILE_KATAGIRI_AYAKO_V1

## 角色名

- 中文名：片桐彩子
- 日文名：片桐 彩子（かたぎり あやこ / Katagiri Ayako）
- 稳定 ID：`guest_ayako`

## 1. 基本定位

- 年龄：25 岁
- 性别：女性
- 职业：漫画家／插画家
- 身份：医院外部来访角色、剧情型配角、可反复登场 NPC
- 不可攻略，不建立正式好感路线，不可加入手术团队。
- 一句话定位：开朗、元气、爱画画、行动力很强的年轻漫画家，因为一场离谱的“误入手术室事件”而和星见医院结下奇妙缘分。

主要用途：

1. 深山佳織 Lv2《取材过头了》的核心人物。
2. 提供轻松、荒诞、带一点恶趣味的医院外部视角。
3. 后期以“星见医院题材漫画”创作者身份回归。
4. 在医院结局、医院祭或庆祝场合暖心返场。

## 2. 外观设定

- 身高约 158cm，纤细轻盈，娇小到中等身材，明确为成年女性。
- 银紫色／淡紫银色长发，保留高束、上扬发束与富有动感的轮廓。
- 蓝紫色大眼，明亮且表情丰富。
- 气质明快、亲切、容易兴奋，带有创作者的感性、观察欲和生活气。
- 成年后仍保留元气与可爱，不走职业 OL、成熟冷艳或妖艳路线。

常服采用宽松淡紫衬衫、白色简单内搭和高腰深蓝长裤。随身携带帆布包、速写本／绘图板和画笔，突出“很好接近的年轻女性创作者”。

运行时优先表情：

- `casual/neutral`：明亮、亲切、随时准备记录。
- `casual/shocked`：真实受惊，眼睛睁大、语速失控。
- `patient_gown/neutral`：作为手术患者穿患者袍、戴手术帽，平静等待。
- `patient_gown/puzzled`：尚未意识到乌龙，对流程产生疑问。
- `patient_gown/happy`：把“体验式采风”当真时的兴奋表情。
- `operating_table/nervous`：已经仰卧在手术台上；肩部裸露，胸部以下由手术单完整遮盖。
- `operating_table/drowsy`：镇静生效后眼神失焦、昏沉欲睡。
- `operating_table/composed`：镇静结束、发现已经开腹后恢复镇定，决定不浪费这次第一手体验。
- `operating_table/happy`：认为结果没有那么糟，还顺便切除了阑尾时的明亮笑容。
- `operating_table/annoyed`：轻微嫌弃与无奈，表达“我说了开刀的不是我，可是没人听见”。
- `ward/postop`：术后换回普通病房患者服，疲惫但迅速恢复元气。
- `hospital_nurse/visit`：第二次及之后来院时使用的护士服纪念版，保留速写本与画笔。

## 3. 世界观内背景

彩子已经是小有成绩的漫画家／插画家，工作覆盖少女漫画插画、轻小说插图、青年向短篇和杂志随笔漫画。她对专业世界的真实细节有强烈兴趣，准备创作医院题材作品，因此独自来到星见医院观察采访。

她想了解真实病房、诊疗区、护士站和手术区如何运作，也关注医生、护士与住院患者各自看见的医院。她不是病人，没有严重疾病背景；她原本只是采风，却阴差阳错卷入手术事故式喜剧事件。

## 4. 性格

关键词：开朗、元气、感性、直率、好奇、表情丰富、天然、冒失、恢复力强。

她遇到离谱事件会先慌、先叫、先短暂放空，不会异常镇定。事情过去后，创作者本能会迅速回归，把灾难整理成构图、对白和素材。她不是黑深残角色，不黑化，也不发展为职业受害者；她的价值是给医院剧情带来轻快空气，并把荒诞经历收束成有温度的长期联系。

## 5. 人际关系

### 藤崎詩織

- 两人同为 25 岁，过去认识，但现在并非密切往来。
- 旧识可来自学生时代、公开活动、校友圈或文化活动。
- 彩子第一次来院不是经诗織介绍；旧识在后续剧情自然揭露。
- 彩子可能后知后觉地发现当年的“国民女神”就在星见工作。

### 深山佳織

- 深山 Lv2 的核心关联角色，也是深山职业生涯中最离谱事故的直接当事人。
- 事件后深山对她既愧疚又感激；彩子认为深山“虽然遇上的事离谱，但人很好，也真的很认真”。
- 彩子的恢复力与表达会推动深山的人物塑造和她与坂口的 Lv2 关系进展。

### 坂口隆司

- 坂口是事故善后协助者与见证者。
- 初印象是“在一群离谱的人里好像还算靠谱”。
- 后续回院时互动自然，但不进入恋爱或成人路线。

### 城宮明日香

- 明日香负责医院秩序、调查与善后。
- 后期可正式允许彩子有限度采风。
- 她最终可能送彩子一套护士服作纪念。

## 7. 核心事件：《取材过头了》

- 运行时 ID：`miyama_02_manga_artist_wrong_patient`
- 归属：深山佳織 Lv2
- 前置：完成深山 Lv1；深山开始愿意邀请坂口共同参与或旁观部分手术工作。
- 结果：坂口协助深山完成事故善后，深山关系推进到 Lv2。

事件必须保留以下事实：

1. 一名与彩子脸型、发色相近、真正排定手术的女患者因术前情绪激昂逃出手术室，并从彩子身边跑过。她与彩子近看可由鼻梁、眼形和瞳色区分，但不熟悉双方的医护在匆忙中难以辨认。
2. 彩子因采风需要被误导穿上患者袍、戴上手术帽，并在手术区附近活动；追出来的团队把她误认成刚刚逃跑的正式患者。
3. 在镇静、紧张与混乱中，彩子被推进手术流程。
4. 切开后发现器官完全健康，与预定病灶不符，进而暴露身份与患者错误。
5. 彩子受惊，但恢复很快，把经历转化为创作素材。
6. 她会提出想看术野照片，并说“既然都开了，不如把阑尾顺手切掉”。
7. 事件基调以“太离谱了”“我居然真的进手术室了”“这素材也太第一手了”为核心，不转为黑化或长期创伤路线。

建议六幕：

1. **采风入院**：彩子带速写本采访流程，因为兴奋而频繁离开指定路线。
2. **真正患者逃跑**：预定女患者情绪激昂冲出手术室，从彩子身边跑过；追出的医护只捕捉到近似脸型、银紫发和患者装束。
3. **更衣与身份错位**：彩子把患者袍和手术帽当作“体验式采风”的许可内容，随即被误认成逃跑后追回来的预定患者。
4. **术中发现**：切开后解剖与病灶完全不符，深山首先意识到问题并叫停。
5. **事故善后**：坂口协助解释、陪同恢复；明日香接管医院层面的处置。
6. **创作者反弹**：彩子从惊恐、发愣迅速切换到素材模式，提出术野照片与阑尾问题，留下后续回归接口。

建议旗标：

- `ayako_research_visit_started`
- `ayako_mistaken_for_patient`
- `ayako_wrong_surgery_incised`
- `ayako_requested_field_photo`
- `ayako_requested_appendectomy`
- `miyama_02_manga_artist_wrong_patient_completed`
- `ayako_hospital_manga_planned`

## 8. 后续回归

### 医院题材漫画计划

彩子中后期再次来院，表示那次经历让她真正对“医院里的人”产生兴趣。她要画的不只是猎奇手术，而是医生、护士和患者共同组成的医院故事。

### 护士制服纪念

明日香半开玩笑、半认真地送她一套护士制服。彩子把它当作宝物收藏，对应 `hospital_nurse/smile` 立绘。

### 大结局／庆功派对

彩子穿护士制服回来凑热闹，让玩家意识到她没有被遗忘，也让那次离谱事故沉淀为星见医院独有的共同记忆。

## 9. 对话风格

活泼、直白、表情感强，容易惊呼、吐槽和自问自答。害怕时会真实大叫，平静后又迅速进入创作者模式。

代表语气：

- 「欸欸欸欸？！」
- 「等等等等，这也太奇怪了吧！」
- 「这也能当素材吗……不对，这根本就是超强素材吧！？」
- 「我是不是该先害怕，再兴奋？」
- 「虽然肚子有点痛，但我好像赚到了第一手体验……」
- 「术野照片可以给我看吗？我保证不画得太写实——大概。」
- 「既然都开了，不如把阑尾顺手切掉？……为什么你们突然一起摇头？」

## 10. 写作边界

- 保持轻快、荒诞、可爱、略带色情喜剧边缘感。
- 不写成病娇、黑化、职业受害者或沉重创伤路线。
- 不进入攻略、H 或复杂感情线。
- 她会害怕和疼痛，但恢复叙事以旺盛生命力与创作者视角为中心。
- 她不是一次性笑料，至少保留医院漫画、护士服纪念与庆祝返场三个长期接口。
