## 鉴赏页尺寸修正

用户指出 native4 的服装预览仍超大，复查截图确认属实。原因是 TextureRect 在关闭原图最小尺寸限制前赋值 size，导致显示框被钳制为 1024×1536。已将 EXPAND_IGNORE_SIZE 设置移至 size 之前。native5 对全部 15 张预览增加实际显示尺寸与画布边界断言，911 检查、0 失败、退出 0；另打开接待服、校服、私服三张实际截图确认比例。此前 native4 仅验证资源尺寸与透明通道，不能证明预览显示尺寸正确。
