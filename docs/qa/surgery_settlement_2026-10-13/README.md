# 手术结算UI验证

`tools/surgery_result_growth_test.gd` 使用测试状态渲染中文/英文结果页与成长窗。截图数值为测试数据，不来自玩家存档。普通三人团队全部可见；更长列表可滚动。运行时测试核对奖励实际增加、升级、重复调用不重复发奖、保存恢复、角色标记替换与显示区域边界。

- `surgery_result_zh_CN.png` / `surgery_result_en.png`：无患者头像的结果卡片及完整记录区。
- `surgery_growth_zh_CN.png` / `surgery_growth_en.png`：实际XP、等级变化和岗位训练进度。
