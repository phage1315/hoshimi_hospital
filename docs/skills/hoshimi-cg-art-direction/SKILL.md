# 星见医院 CG 审美基准

## 已确认的视觉锚点

用户对江美子 Lv3 手札样图明确确认：“画风，人物和五官都很好！就按照这个标准”。

- [已确认样图](../../../research/generated_candidates/emiko_cg_style_pilot_v1/lv3_private_notes.png)
- [该图完整生成提示词](../../../research/generated_candidates/emiko_cg_style_pilot_v1/prompt.txt)
- [原作参考图及角色说明](references/originals.md)

生成前查看样图，并查看目标角色自己的已确认种子图／立绘。样图负责统一画风，目标角色资料负责身份；不要把所有角色画成江美子的眼型、发型或体型。原图临时剪贴板路径不可作为长期依赖。

## 画风与人物

- 以早期日式 PC 视觉小说的清晰线稿、赛璐璐人物上色为基调。轮廓与发梢、下颌、衣褶转折利落；深色描线有轻重，不使用厚涂笔刷、软糊轮廓或 3D 皮肤质感。
- 固有色清楚，人物以两三层硬边阴影为主，局部渐变克制。白衣阴影以蓝灰／紫灰为参考，按场景调整。
- 保留角色特有的眉眼、面部比例、发色与发束结构；发丝高光成组呈带状，不逐根堆细丝。避免把不同人物统一成圆脸、大眼的现代萌系。
- 江美子基准：银紫色披散长发、不对称厚刘海遮住一眼、狭长锐利眉眼、冷静自信的神态；红上衣、白大褂等随实际剧情穿戴。无菌场景需收发入帽，不能为了辨识度露出长发。

- 手术室 CG 按用户确认的服装细节：外科口罩使用脑后／颈后上下两组系带，不画挂耳环；刷手服口袋不插笔。

## 色调与背景

- 角色色鲜明，肤色自然克制；不要用整张橙黄滤镜取代场景光色。
- 医院以中性／偏冷光为基础；寿司店、午后办公室可用局部暖光。特殊舞台／夜景允许参考原作彩光，不把所有场景统一打光。
- 背景有明确透视、具体生活物件与早期数码背景画质感，细节服务叙事，不抢人物。避免默认强景深虚化、光晕、镜头光斑、油亮皮肤与过度电影轮廓光。
- 输出高清干净边缘，不复制原作截图的压缩、锯齿、UI、标志与水印。

## 制作与接入

1. 读取当前事件和角色资源映射，核对时刻、地点、服装、在场人物和关键道具。剧本文字与既定形象冲突时报告具体冲突，不擅自改原文。
2. 通过内置 image_gen 生成或编辑；参考图明确区分“角色身份”“全局画风”“场景／服装”。使用已确认样图作画风参考时，明确不要继承其办公室、衣服或姿势到无关场景。
3. 默认横向 1536×1024 完整场景 CG；构图随任务适配。主角默认第一人称不露脸，必要时仅手部入镜；用户指定第三人称时以用户为准。
4. 预留实际对白框空间，使面部、互动手势和核心道具尽可能可读。样图的审美获批不等于道具布局、医学图示或 UI 遮挡已验收；接入仍需检查实际显示。需要时复用先展示完整 CG 再显示对白的既有机制。
5. 同构图差分锁定身份、镜头、服装、光线与环境，仅改变要求的表情／动作。用户已授权制作时直接执行，不以本 skill 增加逐张审批门槛。
6. 原始输出、最终提示词、参考来源与 SHA 归档到 `research/generated_candidates/<batch>/`；正式接入素材放 `assets/events/<batch>/`。纯审美确认不自动授权替换旧 CG 或接入节点，按当次任务范围执行。

## 交付前观察

对照已确认样图检查人物辨识度、五官、线条、阴影边界、发束高光与色调；检查手部和道具结构、剧情状态以及关键区域是否被对白框遮挡。区分“图片完成”“用户认可审美”“运行接入”“原生显示已验证”。不要用文字声称一致来替代看图。
