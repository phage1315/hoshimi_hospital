# 接入与验收

## 工作顺序

1. 查Git状态、现行Registry、角色原稿及资产清单，保留已有修改。列作者缺口，已授权的独立技术工作继续进行。
2. 原件归档、逐字节摘要；有作者修订则明确版本来源。不要运行会覆盖无关事件的旧导入器。
3. 导入指定图片并记录槽位、原路径、目标路径、尺寸、Alpha、SHA256。新图不能因文件名相似误认成旧角色资源。检查已提供附件有没有遗漏，例如芹香annoyed曾留在Downloads而未进入正式目录。
4. 生成／适配Profile、Flow、Context，补齐英文；依据最终图标定热区。能用共用adapter就不复制一套Runner。必需信息缺少时保留明确缺口，不发明台词、图像或解锁事实。
5. 先验证未就绪条目拒绝启动，再在资产与内容具备后登记ready、运行正式路径；若失败且未修复，恢复不开放状态，不能用ready掩盖问题。
6. 测试数据只存在内存；如需测试持久预约，使用独立临时路径，且只在安全边界保存稳定业务事实。不覆盖玩家槽位，不写中途会话快照。

## 最少验证内容

- normalize成功，actor_id一致；所有正式图片ResourceLoader可加载，背景ID有文件，layout_id及图片真实尺寸匹配。
- 4×9偏好优先级、非空反应回退、实际表达图片路径；MAX只出现一次，不自动进入阶段二。所有六种表情至少加载并显示一次。
- 每个多边形代表点、非交互背景、图片外、letterbox、重叠优先级；通过真实TextureRect GUI输入回调测试缩放坐标。
- 入场策略与本次会话稳定性、两种style、六句播放次序、池内无放回、手动完成只生效一次、确认回应才切场、事后两句结束才返回。
- 中文与英文姓名、正文、选项、地点、预约回应，所有保留池也要检查译文。原文逐句／说话人／顺序核对，不仅检查“有英文key”。
- 正式人物菜单→预约→下班转场→入场→互动→阶段二→确认→事后→次日导览。等级数字不代替完成事实；无真实前置时仍不可约。普通重复内容不携带一次性剧情event上下文。
- 过程中不能保存；结算只推进一次，不重复奖励，预约清理，回到安全边界才能保存。重跑保持稳定。若改了存档代码，还须按项目要求做迁移和结构变化测试。

## 复用测试而不是照抄结论

参考：

- `tools/serika_free_h_test.gd`：中英内容和阶段UI。
- `tools/serika_free_h_bodymap_test.gd`：真实图片热区输入。
- `tools/serika_free_h_e2e_test.gd`：生产路径、六表情、原生截图；当前夹具在内存设置Lv4完成与当日在场事实，不等于自然Lv0→Lv4剧情链实测。
- `tools/serika_free_h_source_audit.py`：源文／英文／摘要校对。86条、芹香家、特定文件名是该人物断言，新人物须按真实输入重新计算。
- `tools/free_h_scheduling_test.gd`：共用预约、日期、边界和小夜香回归。

若改adapter或共用UI，还跑小夜香系统／UI及预约回归。纯补一张图不需要无理由重跑整个仓库；按实际改动选择验证。

新增或修改剧情内容必须运行：

```sh
python3 tools/narrative_localization_test.py
python3 tools/localization_audit.py
```

独立Profile池还需专属英文审计，通用工具不一定覆盖全部内容。不要照抄之前400／179等数字，交付当前日志中的真实结果。

## 原生窗口验证

- 先查本机Godot可执行文件，命令用显式`--path`与临时`--log-file`；不要依赖用户默认日志目录可写。
- `--headless`只能报告逻辑／UI树测试，不能叫实机显示验证。去掉该参数才是原生窗口；固定测试脚本可驱动真实按钮signal和GUI输入，并等待渲染帧后保存截图。
- 原生截图复核透明边缘、缩放、头像位置、对白换行、姓名和按钮可读性。已确认对白框覆盖CG是预期，不因为遮到下沿就擅自裁图或改构图。
- 需要继续使用真实鼠标或窗口操作时用可用的本机UI工具。区分脚本驱动和人工点击，不把二者混写。
- 沙箱内无法开原生窗口时，使用合法权限流程；失败后准确报告限制，继续headless和静态审计，不声称视觉通过。没有授权不改全局系统设置。

## 交付状态

分别列出素材接收／导入／验证、正文／英文、正式Registry、实际解锁前置和测试方式。可用附件来源和缺图清单应重新枚举，而非机械继承旧文档。

验收记录包含：代码版本与工作区状态摘要、原稿版本、图片摘要、运行命令、结果计数、必要截图、未测项。仅存QA证据，不能把会话内部状态包装成可恢复测试存档。
