# 剧情、双语与素材技术接入

适用于新增／修订固定剧情或接入用户明确指定的资源。先读根 AGENTS.md；本工作流不授权补写、润色或生成素材。

1. **定位。** 查看工作区变更、角色稳定 ID、relationship 槽、事件索引与 bundle、生产入口和测试入口；确认是 Character Event、Special Event、重复 Runner 还是纯演出。
2. **原稿锁定。** 从用户指定文件及 `research/source_scripts/` 确定本次最终版；记录版本、路径和摘要。原稿、译稿、导入脚本与运行 JSON 分开保留。版本不明、说话人不明、缺句或分支缺去向时暂停该依赖工作并询问，继续无依赖的检查。
3. **映射。** 建立原稿段落→事件 ID／节点→说话人→场景／资源→结算的对照。稳定完成 flag 表达业务含义，不暴露选项路径。查现有导入器后再决定是否运行，避免覆盖其他未提交内容。
4. **已有资源。** 按用户文件→槽位映射原样复制、登记路径、尺寸、Alpha、SHA-256 与来源。技术检查不需主动打开图片；不裁切、遮挡、改画、借其他角色图片或自动生成替代品。纯本地授权不包含发送第三方服务。
5. **数据与逻辑。** 内容留在 JSON；优先共用会话、角色上下文及 registry。只有确实缺少接口时修改状态层，UI 读取表现数据。不把剧情专用内容自动塞进重复流程，不绕过正式门槛。
6. **双语。** 同步核对标题、公告、完成提示、画廊、正文、说话人标签、选项；复用已批准译文。缺英文不得称完成。技术 ID 不翻译；翻译授权不足时明确列缺口。
7. **逐句审计。** 对照原稿检查全文、标点、顺序、选项、说话人，回滚未经授权增删改。必要的结构适配单独说明，不用“更顺”理由改变正文。专项 `*_source_audit.py` 辅助检查不能替代未覆盖字段的核对。
8. **验证。** 必跑 `python3 tools/narrative_localization_test.py` 和 `python3 tools/localization_audit.py`；按影响范围加数据校验、角色 headless、演出／存档回归。随后按原生测试技能跑实际入口、分支、语言与返回路径；不借用旧报告声称新版本通过。
9. **交付。** 分别报告原文一致性、英文、素材、运行加载、正式解锁、headless、原生 GUI、未测路径。缺素材时保留真实 pending 状态；文档与测试入口存在不能替代完成。

建议接入记录逐项包括：原稿版本及摘要、目标角色与事件 ID、文件→资源映射、改动范围、结算事实、双语缺口、实际测试命令／日志／截图和剩余项。记录不应复制用户敏感全文到无关日志或第三方服务。
