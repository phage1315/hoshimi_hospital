# 术中危机系统实现

实现依据为 `docs/design/HOSHIMI_SURGERY_FAILURE_AND_CRISIS_SYSTEM_V0_1_2026-10-04.md`。普通手术的唯一通用生理失败入口是 `physiologic_crisis`；尊严、配合度和术野不进入这套随机失败公式。

## 运行流程

正确完成一个手术节点后，系统按麻醉路线、节点生理压力、恐惧、痛苦、稳定度和失血计算 2%–30% 的危机概率。全身麻醉不计清醒患者的恐惧与痛苦。节点可显式提供 `physio_stress: low|medium|high`；缺省时根据节点位置和现有提示推断。

危机发生后暂停节点推进，提供三种处理：暂停操作并稳定患者、保持术野让团队处理、先完成关键动作。三次机会采用常规危机 90/50/25、严重危机 80/30/10 的基础成功率，再叠加团队与选项修正。每次选择和随机点数都写入事件日志，因此读档重放得到相同结果。

三次补救均失败时，追加支援稳定患者并中止手术。患者不会死亡；该台手术不计完成次数，不获得手术经验或解锁进度。消耗的手术时间与危机处理时间保留。

## 玩家开关与持久化

主角办公室提供“术中危机事件：开启／关闭”。关闭后只跳过通用随机生理危机和由此导致的中止；患者互动、CG、Fear、Pain、Dignity、Cooperation、Visibility、Blood Loss、Stability、Progress 和 Time 均继续运行。

开关默认开启，并同时保存在 `user://settings.cfg` 与游戏存档快照中。旧存档缺少该字段时按开启处理。

## 当前校准与待讨论项

专项测试覆盖普通麻醉与无麻醉的目标完成率、强／普通／成长中团队、危机成功恢复、连续失败后安全中止、事件重放、旧事件兼容和开关存档恢复。

目前团队能力取助手、器械护士和巡回护士的 `surgery`、`teamwork`、`calmness` 平均值：82 以上为 Strong，55 以下为 Developing。现有手术节点尚未全部显式标注 `physio_stress`，运行时先使用推断值。后续可讨论是否改用别的技能权重，以及是否逐术式补齐显式压力档。
