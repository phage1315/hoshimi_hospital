# 医院背景包 v5

本批增加三个可直接访问的数据驱动场景。三张背景均由内置 imagegen 生成，原始输出为 1672×941 PNG，游戏以 16:9 裁切方式显示。

| 场景 | 文件 | 当前用途 |
|---|---|---|
| 医院药房 | `assets/backgrounds/v5/pharmacy.png` | 飯村真奈美常驻地点；未来承载处方、用药核对与药剂部事件 |
| 妇科检查室 | `assets/backgrounds/v5/gynecology_exam_room.png` | 空场景；包含妇科检查台、超声和隐私帘，预留专科检查事件 |
| 院长室 | `assets/backgrounds/v5/director_office.png` | 空场景；预留年轻女性院长及医院主线互动 |

画面统一要求为空房间、无可读文字、无标志，保留足够区域给立绘和界面。妇科检查室保持临床、中性和无人状态。
