# 角色立绘导入规范

本规范适用于今后导入或生成的所有普通角色立绘，包括常服、工作服、刷手服、无菌手术服及其表情差分。全屏事件 CG、卧姿患者图和术中特写另按各自素材规范制作。

## 画布与构图

- 固定输出为 1024×1536 PNG，并保留真实透明 Alpha 背景。
- 人物统一采用头部至腰部或髋部的半身／四分之三身构图；不得提交完整站立全身图作为普通立绘。
- 人物主体应在画布内占据足够面积，头顶只保留少量透明空间，左右居中，腰部或髋部在画布下缘附近自然截断。
- 同一人物的不同服装和表情应保持近似的头部尺寸、眼睛高度、肩宽和截断位置，避免切换时明显跳动。
- 不添加场景、光晕、投影、边框、文字或不透明底色。

## 医疗服装

- 戴手术帽时，长发必须完整收进帽内；不得露出长鬓发、马尾或后发束。
- 为保留人物辨识度，可在额前保留极少量整齐短碎发，但不得形成大面积外露头发。
- 无菌手术服必须同时包含正确佩戴的口罩、手术帽和无菌手套；普通刷手服按场景决定口罩位置。

## 导入检查

- 检查尺寸为 1024×1536、存在 Alpha 通道且画布四角透明。
- 在游戏固定立绘框内检查人物大小，确保视觉比例与现有半身立绘一致。
- `focused` 等状态若暂时复用 `neutral`，只需替换其共同指向的源文件。
