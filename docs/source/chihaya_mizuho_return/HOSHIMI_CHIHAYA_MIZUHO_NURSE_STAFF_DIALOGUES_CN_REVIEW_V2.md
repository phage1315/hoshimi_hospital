### 0.2 工作声音的区别

- **千早：** 比以前敢回嘴，仍然小心、认真，对陌生患者的恐惧有敏锐反应。偶尔想起自己躺在台上时的丢脸经历，但已经能用那段经历帮助别人。她不是专业的护士前辈。
- **瑞穗：** 外向，爽快，先答应再发现事情比想象复杂；能承认没弄懂并向正式护士求助。她不是只会闯祸的笨蛋，也不能一直用家里有多少钱开玩笑。已吸取明日香关于尊重普通同事的提醒。
- 两人共通：对坂口亲近、信任，叫“坂口医生”；对女性护士前辈保有尊重。日常对白不提前宣告 Lv4 已发生，更不能在 Lv5 之前提到“刚刚又开过一次刀”。
- **临床信息优先级：** 真正的危机报告只讲监护现象，不提供玩家决策提示。黑色幽默主要放在平稳工作、病房交班与闲谈场景。

## 4. 巡回护士术中危机播报（八类完整覆盖）

**调用合同：** 仅当角色实际被分配为当前手术的有效巡回护士时调用。参照薗田愛実已写出的医护数据格式，每类提供 **normal／severe 两档，各第1、2、3次处理回合**，其中首回合报告新发现，第二、三回合报告异常仍在持续。**这是文本编排方案，Codex 必须核实实际解析器的严重度和 attempt 键名、可用回合数及回退规则，不得未经验证宣称完全符合 schema。** 严重强度不是任意疾病诊断；不能额外修改危机概率、处置选项、成功率、手术评分或解锁。当前方案不添加出血类型，因为失血属于其他 Gameplay 层。

**强制性语气约束：** 报告用短句，信息清楚。她们可以紧张，但不能插入嘲笑患者、介绍自己以前做过手术、建议玩家点哪个处理按钮等戏剧内容。

### 4.3 危机播报 QA

1. 每名护士为八类 ×（normal 三回合＋severe 三回合）＝**48 条**，两人合计 **96 条**。这是已写出的文本量，不等于已完成 runtime schema 验证。
2. 实际呈现时只能由**正在担任巡回护士的那名角色**播报，姓名框、演员立绘和岗位着装必须是同一个人。不能从一句对白中的“坂口医生”误判发言人。
3. 必须核对真实解析器是否支持严重度 × 第几次处理（attempt）索引；若只有严重度随机池，Codex 不可直接把“还在持续”的第2、3回合混作首次报告。若实际键数量不同，应报告映射／回退方案，不擅自删掉已审定的文本。中文和英文必须在同一 flavor／severity／attempt 对齐，英文在正式 Bundle 阶段编译和复核，不在本稿填入占位。
4. 其他护士担任巡回时继续使用其专属播报或系统既有 fallback；千早与瑞穗未入职、未编队、处于 Staff-as-Patient 患者状态时不得成为巡回播报者。
