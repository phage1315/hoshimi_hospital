## 7. Scene 06 — 第一次接吻，和第一次叫他男朋友

**地点：**沿用 Scene 05 的夜间街景；最后自然过渡到分别处（车站附近／回家路线）。  
**时间：**Scene 05 关系确认后，仍是同一晚。  
**在场：**坂口隆司、南条小夜香；两人均穿常服。  
**演出要求：**首吻必须以清楚的动作写出；不使用模糊的「很短的一次接触」替代。不得提前播放 H 或进入 Lv4 Hotel。

【玩家可见正文】

旁白：路灯下，两人安静地站了一会儿。坂口并没有马上迈步，小夜香也没有催他。她抬眼看着坂口，眼角还带着笑。

南条小夜香：「干嘛，正式叫了女朋友，就突然只会站着看我了？」

坂口隆司：「我在想是不是还少做了一件事。」

南条小夜香：「现在才想起来？你平时工作的时候可没这么慢呀。」

旁白：坂口向她靠近。小夜香没有躲开，反而微微抬起脸。坂口低头吻住了她；小夜香也自然地回应了这个吻。两人分开以后，她没有像平时那样立刻接上一句玩笑。

旁白：小夜香轻轻呼了口气，目光短暂地移开，又忍不住笑起来。

南条小夜香：「……你动作倒是挺快的。我刚才还在想说点什么，结果一下子忘词了。」

坂口隆司：「难得你也有接不上话的时候。」

南条小夜香：「少得意。我是觉得不错，才没急着逗你。」

旁白：她说完，往坂口身边靠近了半步。比起刚才，这个距离已经不需要再解释什么。

南条小夜香：「……那男朋友。今天送我回去。」

坂口隆司：「这就开始使唤我了？」

南条小夜香：「不行啊？我又没叫你替我上班。就是想让你陪我多走一段。」

坂口隆司：「行。」

南条小夜香：「那走吧。」

旁白：小夜香走在坂口身侧。过马路时，两人的手背轻轻碰到一起，她没有避开。一路上没有谁特意再提刚才那句「女朋友」，却已经很自然地照着那个答案相处。

### Scene 06B — 临别：一次轻松回调（同一主事件的最后一拍）

旁白：到了两人准备分别的路口，小夜香停下脚步，回过头。

坂口隆司：「明天医院见。」

南条小夜香：「嗯。不过明天工作的时候，别老盯着我看哦。」

坂口隆司：「不是你先一直看我？」

南条小夜香：「我可以看你，你不可以看我哦。」

旁白：她故意板着脸，没坚持两秒自己先笑了。

坂口隆司：「这是什么规矩？」

南条小夜香：「我定的。开玩笑的，想看就看。手上的病历可别漏了就行。」

旁白：小夜香向坂口挥挥手，转身离开。坂口看着她走远，这一天到这里才真正结束。
