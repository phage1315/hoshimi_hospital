# 星见医院｜深山佳織 Lv0 相识事件《先把事实说全》

**版本性质：完整中文 VN 修订审稿稿 / 可供 Codex 逐句接入的演出文本。** 本次按用户反馈修订为普通检查室白大褂立绘，并将首次相识的对白调整为礼貌、有距离、富于职业锋芒；不改变事件入口、事件走向、节点 ID、结算或后续 Lv1–Lv3。用户批准前不视为已在 Godot 中生效。

## 0. 事件定义与演出约定（非玩家可见）

- **事件功能：** 坂口隆司正式认识深山佳織；展示佳織容貌端丽、才华出众、气场自信、带一点高飞车的年轻女医形象；建立对坂口海外临床背景的好奇与挑战；用一次手术室来报形成星见式黑色幽默与 Lv1《叮。》伏笔。此处**只正式相识，Relationship 仍为 Lv0**。
- **触发：** Day 1 或早期，玩家首次进入既有`exam`检查室触发；使用项目已经存在的相识事件入口与地图位置，不另造急诊室、患者病例或专用小游戏。
- **人物：** 深山佳織、坂口隆司；结尾由一名普通手术室护士短暂入场。没有正在检查室接受治疗的患者，也不在本事件中展示护士口中的手术患者。
- **职业与衣着：** 深山以外科为主、兼顾急诊。**相识事件的普通检查室 `exam` 一律使用现有白大褂工作立绘**，不是全程刷手服立绘；坂口为日常医生工作装。白大褂下是否穿医院日常工作服不需镜头指定；**离开检查室后**才在手术区域按正常流程完成手术帽、口罩、刷手和着袍准备。本场不展示这些准备，也不得在检查室门旁放手术帽。职业身份不意味着检查室是急诊室。
- **镜头：** 既有检查室背景，开头以安静、端正的工作近景展示深山，随后以表情／视线和手中报告完成演出；护士匆匆闯入时加快节奏。无必须新画的 CG，也不以纸面资源名冒充已导入的纹理。
- **表情语义（待 Codex 根据实际资源映射，不是资源路径）：** `composed`＝礼貌而审慎的职业常态，不主动亲近；`light_smile`＝极短、客气的表情变化，不是熟人式亲切；`competitive_smile`＝有实力支撑的高傲与一点挑战意味，不是打情骂俏；`guarded`＝提及父亲时一瞬间收敛，而非恐惧；`clinical`＝接到手术通知后立即切入工作状态。**以上全部应映射为白大褂版本的实际立绘／表情**，不应自动切到刷手服。**必须实际切换，不可整场冻结一种表情**。若特定表情没有对应素材，应反馈资源缺口，而不是假装已经实现。
- **称呼锁：** 在坂口尚未正式认识院长时，深山当着坂口只说「院长」，不说「明日香」，不提前暴露两人的大学旧友关系。
- **父女伏笔锁：** 父亲是院外知名外科教授深山総一郎；她只说明父女关系，绝不谈母亲、过去的中止手术或教学练习。
- **对白与舞台：** 下列「旁白：」及各角色对白均为玩家可见；`【立绘】`、`【镜头】`、`【事件节点】`等为非玩家可见的执行提示。编号仅用来核对演出顺序，不是引擎 API。
- **选择分支：** 唯一选择仅塑造坂口的回应语气；两路无数值奖励、无额外前置，均回到同一个结尾。**坂口初见保持有礼、有分寸，不冒失地开玩笑或追问私人往事**。运行时不添加“继续交谈”伪选项。
- **职业距离／演出尺度：** 深山的优越感来自实际训练和工作标准，不靠不断刻薄羞辱对方；她会短暂认可有理有据的回答，但整场没有建立私人亲密关系。声线克制、锋利、讲理。患者、麻醉、后续手术均不在此次相识事件里实际显示。

【立绘：深山佳織，**白大褂工作装**，`composed`】

旁白：检查室里暂时没有患者。桌上的报告按日期排成整齐的一叠，屏幕上还停留着刚核对过的影像资料。

【事件节点 M0-0002｜旁白】
旁白：工作台前站着一名年轻女医生。白大褂穿得整齐利落，姿态端正，容貌出众。她正低头核对报告，眉目间透着一股不好敷衍的认真。

【事件节点 M0-0003｜旁白】
旁白：坂口在门边敲了两下。她将眼前一行记录写完，才抬起头，看了看他的胸牌。

【立绘：深山 → `light_smile`】

【事件节点 M0-0004｜深山佳織】

【立绘：深山 → `competitive_smile`】

【事件节点 M0-0010｜深山佳織】
