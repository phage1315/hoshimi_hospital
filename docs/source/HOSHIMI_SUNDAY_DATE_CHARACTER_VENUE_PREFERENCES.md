> **Status:** Proposal / 本轮待用户审校的作者侧剧本与实装指南。**不是 canonical Gate 更新，也不代表已在 Godot 实装。**  
> **Stable filename:** `HOSHIMI_SUNDAY_DATE_CHARACTER_VENUE_PREFERENCES.md`（直接维护本文件，不创建 V2 / FINAL 副本）。  
> **Scope:** 本轮提供的 21 名角色、16 个候选地点、每人 2 个特别偏好、4 类约会响应。  
> **写作来源：** 用户 2026-10-12 本轮提供的角色－地点配对及理由；现有 Gate Matrix、Character Bible、Familiarity / Sunday Date 和 Codex-Ready 写作标准。  
> **优先级：** 已确认的 `HOSHIMI_CHARACTER_RELATIONSHIP_GATE_MATRIX.md`、独立 Character Bible / Event、`HOSHIMI_FAMILIARITY_AND_RELATIONSHIP_PROGRESSION_RULES.md` 高于本文的新增建议。  
> **实施要求：** This is an implementation task, not a rewriting task **（仅在用户确认本文逐句对白之后）**。未审校的对白仍是 Proposed Copy，Codex 不得将其当作已确认 canonical 自行上线。

## 1. 本轮决策与内容约束

1. **约会名单可见，不等于可约会。** 已正式相识、加入角色名册的医护即使当前 `invite_allowed=false`，也可以显示在周日名单上；选择她仅播放本人 **拒绝约会** 一句。不进行随机接受率判定、不消耗 Sunday 行动、不增加 Familiarity / Charm、不写 `date_completed` / 约会冷却或关系升级；也不制造新的失败恋情 flag。
2. **未正式相识的隐藏角色依照原有 UI / 角色解锁规则，不因本系统泄露姓名或未来登场。** 如现有 UI 明确提供未认识角色剪影，该剪影不能朗读本人拒绝台词。
3. 已满足个人硬门槛时才进入**随机接受判定**。硬门槛不满足必拒绝，随机运气好也不能绕过 Gate。非恋爱／暂缓路线继续保持 `invite_allowed=false`；地点喜好本身绝不赋予约会资格。
4. 本轮只使用 **四种事件类别**：接受约会、拒绝约会、满意、特别满意。**没有不满意或糟糕约会结局**。每人原则上 1+1+1+2=5 句中文文本，其中两句特别满意各自专属一处地点。不可约会者只有拒绝句可进入 runtime，其余四句为**禁用的候选素材**，不得因为文本存在而解锁。
5. 约会地点首先决定 `满意 / 特别满意` 播放分流，不改变接受率或角色 Gate；本文件**不新增或改写**约会基础 Familiarity/Charm 与其它五维的现有结算。**“特别满意”是否还应获得额外数值奖励尚未讨论，本轮暂不锁定**；若工程已有对应规则，Codex 必须报告并沿用已确认部分。“地点特别喜欢”不代表恋爱确认，不触发 H。
6. **选择两处喜欢的地点只在可用季节产生特别满意。** 其余合法地点统一播放该角色的 `满意` 台词；没有额外随机“表现不好”。每人至少有一处非季节限定喜好，保证全年都有机会特别满意。
7. **周日专属 milestone 先于普通邀请结果 / 普通 Date 池处理。** 例如小夜香已满足 Lv4 《那就别回去了》时，沿用既有 pre-commit 确认和事件接管，不因本文引入普通 100% 接受或 +10 Familiarity 双结算。普通约会已经完成一次可用于现有成美 Lv4、真奈美 Lv3 的专属前置，但下班同行或多人聚餐不能替代。
8. 本文不修改每个角色原有 Lv1–Lv5 Gate；不额外添加月度锁、连续约会次数或新的 `romance_points`。不能将下班同行的概率表视为周日约会概率表。
9. *台词核对*：下文全部为本轮新写的中文候选文本，未引用成品 canonical 剧本原文。人物说话人就是对应标题中的姓名；如项目本地化系统自动加 `「」`，Codex 应保留玩家可见效果为一对引号，不可重复打印。英文译文及真实数据路径由工程接入时依据已确认中文制作。

## 3. Gate 与接受率（原有规则优先；数值为提案）

### 3.1 通用规则提案

- 默认正式相识后，Familiarity ≥10 可以尝试周日约会；部分角色可具有明确的特殊阶段门槛。**小夜香第一次正式约会特殊：不额外要求 Fam10；按已有 Lv1 入口处理**。
- 已满足硬门槛的概率以人物基础表为准。可选的轻微 Familiarity 修正：Fam≥25 额外 +5 个百分点，Fam≥55 再 +5 个百分点，取 100% 上限；**若某阶段已有硬性 `<50%` 上限，则必须截断保持低于50%**。这是简化提案，若当前系统已有相等语义的接受率实现，优先复用。
- 角色专属 milestone 已经 ready 时由既有剧情条件与入口优先接管；绝不可让普通随机拒绝阻塞已经被正式触发的专属剧情。
- **本轮不消耗整个周日作为被拒绝惩罚**。若游戏已有邀请次数或可重试限制，由 Codex 核实并在实施前反馈；不要臆造当日多次邀请机制。随机拒绝结果应按角色、周日、存档稳定，不允许无限读档重抽。
- 关系等级与 Fam 各自独立；Fam 达 100 不会提前绕过 Lv2/Lv3 Gate。高等级少数拒绝表现为当日已有安排，不应假装角色对坂口的既定亲密感突然消失。

## 5. 玩家可见台词候选稿

**每名角色五句、四类：** `接受 ×1`、`拒绝 ×1`、`满意 ×1`、`特别满意·地点一 ×1`、`特别满意·地点二 ×1`。**本节文本均为初稿待审，审定之后才允许逐字锁定并导入。**

台词语义：接受／拒绝用于周日邀请回应；满意用于不在两处特别偏好地点的成功约会；特别满意的两句只在标明的地点和有效季节触发。即使人物的场所特别喜欢，也不保证有更深关系事件或成人内容。

对 **当前关闭** 的五位角色，**仅“拒绝”一行可接入运行时**；其它四行是日后有明确授权改变路线时才可能使用的预备候选文本，不可配置为可触发资源。此策略兼容“每人四类草稿”和“当前点击始终拒绝”的双重要求。

```text
      -> 如果禁止：直接播放该角色的拒绝文本；NO roll / NO commit / NO reward
      -> 如果已达既有专属 milestone gate：按已锁事件优先处理 pre-commit；禁止普通奖励双结算
      -> 否则用该角色有效接受率单次判定
          -> 拒绝：播放拒绝；默认不消耗整个 Sunday action
          -> 接受：进入已有 Sunday Date 选择地点／事件流程
              -> 检查 venue availability (including season)
              -> 若 venue ∈ 该角色两处最爱：播放该地点专属特别满意文本
              -> 否则：播放普通满意文本
              -> 仅在成功提交完成后，按**现有** Sunday Date 奖励和完成记录结算一次
```

地点选择处于接受前还是接受后、UI 是否允许预选地点，沿用已有流程；无论哪种顺序，地点偏好在本版都**不改变邀请成功概率**。

### 6.3 不能做的事情

- 禁止把石神、安琪、樱花、双叶、摩耶的“备用接受”台词引入可执行剧情。
- 禁止把尚未满足 Lv 的皐月／御堂／芹香／Saber 偷偷用高 Fam 或高概率绕开硬门槛。
- 禁止用普通下班同行收益代替周日约会收益；下班同行与 Sunday Date 各用原系统。
- 禁止把季节限定地点当常年地点；非当季不显示、不选取、不触发超级满意。
- 禁止把所有喜欢地点的普通满意替换成同一句通用“太开心了”，失去个人辨识度。
- 禁止新加“不满意”“糟糕”“约会失败导致降好感”档位。
- 禁止运行时即兴用 LLM 生成缺失台词；缺失角色资源应在 QA 阶段拦截，而不是让引擎猜。
- 禁止把普通约会的两处 favorite 解释为开放性爱或医疗 Staff-as-Patient 的资格。

### 6.4 QA：建议至少验证的用例

1. 普通已相识但 Fam 不足的角色：仍在可见清单、点击本人拒绝、无 random roll／无结算。
2. 石神、安琪、樱花、双叶、摩耶：已正式相识才可见；不管 Fam / Lv，始终只触发拒绝，没有接受或满意等声音、奖励或 flags。
3. 折川皐月 Lv1/Fam100：仍绝不接受；Lv2：接受率含修正仍严格 `<50%`；Lv3 之后恢复正常。
4. 御園芹香 Lv2/Fam100：仍拒绝；完成 Lv3 才可随机接受。
5. 御堂江美子 Lv1 或 Artoria Lv0：必拒；通过指定等级才抽接受率。
6. 小夜香首轮真正约会：走既有 Lv1 关系剧情，不强制要求 Fam10；成功后一次性完成状态。
7. 小夜香 Lv4 Gate ready：按既有 pre-commit 选择 `[继续约会]/[改天再约]`；不进入随机 Date 池、不重复 +10 或 Charm，取消不占 Sunday 行动。
8. 成美至少完成一次周日约会、真奈美至少完成一次单独约会：可以满足各自已锁高关系 Gate；普通多人聚会、下班同行不计。
9. 普通有效约会：非喜欢地点永远走 `满意`，两处喜欢地点分别走各自 `特别满意`；不能只有一条万能特别满意文案。
10. 春／夏／秋／冬：赏樱庭院、沙滩、红叶古寺、滑雪场只在各自实际季节窗口触发；其他地点不受季节限定。
11. 拒绝后可否选择其他角色，必须符合现有邀请 action 规则；不假设无限刷概率；存档读取不重抽本周已决定的结果。
12. 保存／读档后：人际进度不变、地点偏好不变、已结算 Sunday Date 不重复获得 Familiarity 或 Charm。
13. 中英文两种语言以及移动和桌面 UI：逐字文本、speaker、引号、长句换行、立绘状态、场所背景／缺图 fallback 均正确。
