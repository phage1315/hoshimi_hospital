- **开启门槛：** 已完成芹香 Lv0 四阶段正式相识，熟悉度达到 Lv1 门槛（10），满足项目通用个人事件冷却等条件；从她正常出现的影像诊断室进入。未见芹香的日子不强行刷新她。

### 四、作者审阅重点

- **核心话语的转义：** “请把我的名字划掉”并不是她想隐去自己的专业贡献；真正要划掉的是她没有给出的手术背书。终幕保留她的正确报告和外科的责任，才能使 Lv1 落点成立。
- **南条小夜香不当替罪羊：** 她平常认真可靠。这次犯的是具有现实感的“会议摘要把各科意见压缩成一个结论”的归责错误；她主动承担、完整更正，并从失误中学到东西。
- **不可抢跑 Lv2：** 芹香只允许坂口更直接地讨论影像与术前计划。此时绝不自愿上台，不宣布回外科。
- **不让创伤变成自白：** 她对“被别人写进一份不实记录”的过强反应足以令人注意，旧院细节应留给后续个人线，避免此处揭底。

**医学素材参考方向（只供核查剧情用，不做游戏内科普）：** MRCP 能提示胆管走行变异；疑似变异时手术团队仍须根据实际解剖决定安全操作，影像报告不能直接替主刀批准术式。
