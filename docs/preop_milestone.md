# 0.5 / 术前互动原型

## 体验入口

已有住院存档：标题「继续游戏」→ 医院导览 → 住院病房 →「探视 / 继续术前安排」。
新开游戏：门诊完成收住院 → 前往病房 → 探视。

## 本段流程

1. **探视**：详细解释并留时间提问，或简短告知手术安排。患者紧张程度产生区别。
2. **组队**：玩家固定主刀，选择协助医生、器械护士与巡回护士。三个岗位不能重复用人，确认前可以改选。确认后锁定本段分工。
3. **病房准备**：从未进入手术团队的护士中指派一人。现有三位护士下，此时剩余一位可选；想换病房护士，应在确认团队前调整分工。可以让护士按原流程完成，也可以选择由主刀亲手执行灌肠、下腹及会阴备皮和戴手术帽。亲手准备期间患者保持裸体；开腹与盆腔术式的灌肠和备皮默认为需要，跳过时护士会提出异议；乳房、胸腔与心脏术式默认为不需要，仍然执行时患者会质疑多余操作。亲手准备结束后，病房护士用床单遮盖患者并通过担架车送往手术室。
4. **选择额外照顾**：基础准备为必做且合并执行；额外解释、联系家人、陪伴片刻可选 0–2 项。勾选时不计时、不改变情绪；点击执行才生效。
5. **准备完成**：护士按人物口吻回应，显示所选项目结果。进入更衣区。
6. **更衣／刷手**：先换手术服，再完成刷手准备，之后开放进入手术室。
7. **手术台前**：患者仍清醒，可最后安抚一次，再与团队完成术前确认。本段停在「手术还未开始」。

## 轻量反馈

- 患者情绪：紧张 → 仍有些忐忑 → 比较安心。解释和额外照顾减轻紧张；上限／下限有保护。
- 护士照护能力达到内容定义中的阈值时，基础准备额外提供一次安心效果。当前七瀬／中井达到，朝倉尚未达到。不是医疗结果评级。
- 所选医生与护士使用自己的回应。其他团队技能展示供比较，尚未用于手术成败计算。
- 准备项目各消耗几分钟，衣着与刷手各计一次；没有现实等待计时器。

## 存档

所有术前阶段可手动保存，包括未确认团队、勾选但尚未执行的项目、更衣后尚未刷手、入室与最终确认。

存档格式升级为 v2；继续支持读取 v1 门诊存档。v1 加载后保留原病例进度，术前流程从探视开始。写入后为 v2；旧版程序不能读取新版存档。原始存档只有玩家主动保存才会被覆盖，测试使用 work 中独立文件。

各术前事件以类型、岗位、人物或行动 ID 记录。载入时在临时对象中重放，检查住院前置、资格、重复岗位、阶段、最多两项限制、刷手与更衣顺序。任何失败都不改变当前游戏进度。

## 当前美术

新增的是 Godot 原生二维占位：病床患者、更衣柜与刷手台、盖着手术单的手术台患者。情绪用简易脸部变化表示；更衣后显示手术服、帽子与口罩占位。没有生成新图片。

已预留患者 gown / preoperative / operating_room 状态和玩家 default / scrubs 状态。当前没有为每位工作人员制作服装差分，也没有真正的术前患者 CG。占位以验证场景与流程为目的。

## 后续边界

下一段再接：开始前团队对白 → 术中进展与一次紧张事件 → 完成 → 术后交接与探视。本版没有开始手术、麻醉执行、组织操作、术中事件或术后结算。术前事项为剧情抽象，不模拟真实医疗准备技术。
