## 本批素材的验收重点

1. 年轻女性医护：手术帽完全遮盖头发，正面与侧面均无头发露出。
2. 手术台患者：必须戴手术帽；身体由无菌单遮盖，肩膀与腿裸露可见。
3. 表情差分：帽子、遮发范围、铺单与身体露出范围不随表情变化。

此处为项目视觉要求；生成和验收时同时参照 art_direction.md。

## 病房亲手准备 CG 预留

当前流程已为三个步骤保留稳定动作 ID：`ward_enema`、`ward_skin_prep`、`ward_surgical_cap`；非腹盆腔术式仍执行多余操作时分别使用 `ward_enema_unnecessary` 和 `ward_skin_prep_unnecessary`。亲手准备期间患者保持裸体，不再设置换手术袍步骤。以后加入 CG 时按动作 ID 触发，不需要改写患者反应或流程路由。戴帽后的担架车交接属于 `complete_manual_ward_preparation`，适合作为戴帽 CG 结束后的文字过渡，不必另占一张 CG。

## 手术台患者的视角与差分

用户已确定采用「患者躺在手术台上的上方视角」：镜头从患者上方俯视仰卧身体，不使用站姿、坐姿或把站姿立绘旋转代替卧姿。

- 患者层与手术台背景使用同一透视和缩放关系，保持脸部清楚可辨。
- 底部对话框避开患者脸部；最终裁切应结合游戏界面确认。
- 第一批预留紧张、勉强微笑、闭眼三种表情。所有差分保持镜头、身体姿势、帽子、铺单、露肩露腿范围及画布对齐一致。
- 患者层为同一患者 ID 的 operating_room 视觉状态；之后可接入手术室互动。
