# 医院背景包 v2

第二批六张背景使用内置 ImageGen 生成，统一裁切为 1280×800 PNG，并接入标题、序章、医院导览及全部剩余地点。

| 场景 | 文件 | 使用位置 |
|---|---|---|
| 医院大厅 | `assets/backgrounds/v2/lobby.png` | 标题画面、医院导览 |
| 公共走廊 | `assets/backgrounds/v2/hallway.png` | 入职序章 |
| 护士站 | `assets/backgrounds/v2/nurses_station.png` | 护士站及人员页面 |
| 检查室 | `assets/backgrounds/v2/exam_room.png` | 检查室及人员页面 |
| 影像检验区 | `assets/backgrounds/v2/diagnostics.png` | 影像与检验地点 |
| 职员休息室 | `assets/backgrounds/v2/staff_lounge.png` | 职员休息室及人员页面 |

本批继续使用低饱和蓝绿色、暖白、浅木色和春日采光，并保持无人、无可读文字、无标志和水印。所有正式地点现在都有独立背景；原生几何背景保留为缺失资源时的回退。
