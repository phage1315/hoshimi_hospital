# 南条小夜香 Staff-as-Patient 台词待填清单

> 用途：交由写作 GPT 填写小夜香作为 Staff-as-Patient 进入现有 surgery runner 时所需的角色专属台词。本文是写作清单，不是剧情正文；所有台词栏均留空，不能据此自行补写或改动其他事件剧本。

## 写作范围与既定规则

- 角色：南条小夜香（成年医生，27岁）。称呼坂口时遵循项目已有的医护患者称呼上下文；不要把普通患者对“医生”的称呼全局替换成人名。
- 解锁：完成小夜香 Lv5 Part C，并检查 `staff_as_patient_program_authorized` 授权标记。
- 流程：接受邀请后从病房进入术前准备，再进入现有手术流程；不经过门诊，也不需要门诊主诉、门诊问诊或术前诊断对白。
- 邀约时由玩家选择术式；术式必须已解锁。若病房已有未完成患者，小夜香拒绝新邀请。
- Staff-as-Patient 手术不改变正反声望；选错术式或选择无麻醉不触发普通患者的声望惩罚。台词可以表达人物感受，但不得擅自改变此规则。
- 手术耗时及术前准备耗时沿用现有流程。重复奖励提示不是角色剧情对白，可由 UI 呈现。
- 画廊 CG 不在本清单内；后续另行提供的可选 CG 不作为本流程台词前置条件。
- 中文原文与英文对应文本分别填写。英文需覆盖所有实际接入的台词；不要在英文栏留中文占位。

### C3. 麻醉状态覆盖规则

- 全麻：术中患者不说话；只需麻醉状态视觉，不填写清醒互动池台词。
- 硬膜外、局麻、无麻醉：按现有 runner 的清醒患者互动条件触发。无麻醉台词表达疼痛或不安时，不得写成系统声望惩罚提示。
- 对术式不一致：如流程仍允许在确认后更换术式，应有一条角色反应；该反应不改变“声望不增不减”的规则。
