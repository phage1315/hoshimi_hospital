# 第一日序章流程

序章先建立人物印象，再进入医院模拟。玩家从第一人称视角观察神宮寺成美，听取她作为先辈医生对新同事的提醒，并可选择坦白紧张或表示会尽快跟上。两项选择只改变当下回应，不设置隐藏惩罚。

七瀬恋随后带着门诊资料登场，完成自我介绍并直接带玩家先去护士站。第一天的固定早班成员依次登场：中井美佳负责病房护理，朝倉美幸负责门诊护理。序章里的护士站名单固定，不受未来随机排班或新增角色影响，确保初次游玩能够认识当前核心护理团队，并保证第一场手术已有可邀请的医生与护士。完成介绍后，七瀬恋再带玩家去诊室。

两条路线最终汇合到门诊诊室，并通过 `@location:clinic` 对话出口直接打开门诊页面。序章节点使用现有 staff ID、表情差分和数据驱动背景；以后增加人物时，无需改变本段固定介绍，新增人员可通过排班、地点事件和人物事件自然登场。
