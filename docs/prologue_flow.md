# 第一日序章流程

序章保留春日医院走廊画面，用四个短旁白框交代主角的初始位置：坂口隆司刚结束海外研修，履历足以让他选择更显眼的去处；他因医学院时代导师的一句推荐来到星见；只签了一年合同，并暂时把这里视为回国后的落脚点。序章不解释导师的真实用意、具体海外履历、其他医院邀约、导师与星见的关系，也不预告坂口年末是否留下。

随后建立人物印象，再进入医院模拟。玩家从第一人称视角观察神宮寺成美，听取她作为先辈医生对新同事的提醒，并可选择坦白紧张或表示会尽快跟上。两项选择只改变当下回应，不设置隐藏惩罚。

七瀬恋随后带着门诊资料登场，完成自我介绍并直接带玩家先去护士站。第一天的固定早班成员依次登场：中井美佳负责病房护理，朝倉美幸负责门诊护理。序章里的护士站名单固定，不受未来随机排班或新增角色影响，确保初次游玩能够认识当前核心护理团队，并保证第一场手术已有可邀请的医生与护士。完成护理团队介绍后，玩家在前往诊室的走廊转角保证遇见南条小夜香。她以一句“哪里临时缺医生，就可能把我塞到哪里”说明综合诊疗与补位定位，也当场表明高难操作会主动说不。随后七瀬恋再带玩家去诊室。

序章中的相识流程最终进入门诊诊室，并通过 `@location:clinic` 对话出口直接打开门诊页面。序章节点使用现有 staff ID、表情差分和数据驱动背景；以后增加人物时，无需改变本段固定介绍，其他新增人员仍可通过排班、地点事件和人物事件自然登场。

主角办公室的“收藏与纪念物”从开局起保存 `mentor_recommendation_letter`。当前只显示推荐信及一句疑问，详细回忆与中期、年末文案留给后续事件。
